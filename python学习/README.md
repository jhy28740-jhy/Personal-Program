## 🆘 遇到问题怎么办

### 问题类型1：概念不理解

**例如**："什么是列表推导式？"

**解决方法**：
1. 查阅 [Python基础知识速查表.md](参考资料/Python基础知识速查表.md)
2. 在速查表里搜索关键词
3. 看例子，在Python交互环境里试一试
4. 还不懂就记录下来，问我

### 问题类型2：代码看不懂

**例如**："第123行在干什么？"

**解决方法**：
1. 打开对应的讲解文档，搜索"第123行"
2. 如果讲解文档里没有，看看这一行用了什么函数
3. 查阅 [Python基础知识速查表.md](参考资料/Python基础知识速查表.md)
4. 把这行代码拆开，理解每一部分

**举例**：
```python
# 看不懂这行？
df["col"] = df["col"].fillna("").astype(str)

# 拆开理解：
df["col"]           # 取列
.fillna("")         # 填充空值为空字符串
.astype(str)        # 转换为字符串类型
```

### 问题类型3：运行出错

**例如**：`KeyError: '二级场景'`

**解决方法**：
1. 看错误信息的最后一行（这是问题所在）
2. 在 [理解检查题.md](第一步-代码阅读训练/理解检查题.md) 搜索关键词
3. 很多常见错误已经在检查题里讲过了
4. 如果还解决不了，记录：
   - 完整的错误信息
   - 你的输入数据（A表和映射表的列名）
   - 你使用的参数

## 💡 学习建议

### ✅ 推荐的学习方式

1. **每天固定时间学习**（如每晚8-9点）
2. **先理解再动手**（不要一上来就写代码）
3. **及时记录疑问**（当天解决或第二天问我）
4. **用自己的话复述**（能讲出来才是真懂）
5. **结合实际工作**（用学到的知识改进你的脚本）

### ❌ 不推荐的学习方式

1. ❌ 一次性学太多（贪多嚼不烂）
2. ❌ 只看不练（看懂≠会用）
3. ❌ 死记硬背语法（用到时再查）
4. ❌ 遇到问题就跳过（问题会累积）
5. ❌ 学了不用（一周不用就忘）

### 类比帮助理解

| 编程概念 | 数学类比 |
|---------|---------|
| 变量 | 代数中的 x, y |
| 函数 | 映射 f: X → Y |
| 列表 | 序列 {a₁, a₂, a₃, ...} |
| 字典 | 函数图像上的点集 |
| 集合 | 集合论中的 A, B |
| for循环 | 数学归纳法 |
| 列表推导式 | {f(x) \| x ∈ S, P(x)} |
