## 脚本概览

### 这个脚本是做什么的？

这是一个**医疗检索结果统计工具**，用于评估不同检索链路的性能。

**输入**：
- N个A表（Excel文件，包含检索结果和人工标注）
- 1个映射表（query的分类信息）

**输出**：
- 多个Excel表格，包含各种统计指标（good率、NDCG、Authority等）
- 带颜色标记（绿色=最好，红色=最差）

### 三种统计模式

| 模式 | 作用 | 映射表要求 |
|------|------|----------|
| **场景** | 按一级/二级/三级场景分类统计 | 需要场景分类列 |
| **类型** | 按query类型分类统计 | 需要类型列 |
| **普通总计** | 只看总体指标 | 只需要query列 |

## 核心概念理解

### 1. 什么是"链路"？

**链路** = 不同的检索算法版本

比如：
- `1235链路` = 某个算法版本
- `线上权威` = 当前生产环境的算法
- `1236链路` = 另一个实验版本

**从文件名提取**：如果文件叫 `1235更新链路全量测试集_合肥_0617.xlsx`，链路名就是 `1235更新链路全量测试集`（第一个`_`之前的部分）

### 2. 什么是"A表"和"映射表"？

**A表**（标注表）：
| query | title | content | relevance_label | indexName | ... |
|-------|-------|---------|----------------|-----------|-----|
| 高血压治疗 | 高血压指南 | ... | A | 期刊 | ... |
| 高血压治疗 | 高血压常识 | ... | C | 疾病 | ... |
| 糖尿病 | 糖尿病治疗 | ... | B | 指南 | ... |

- 每行 = 一个检索结果（文档）
- `relevance_label` = 人工标注的相关性（A最好，D最差）

**映射表**：
| rawquery | query | 一级场景 | 二级场景 | 三级场景 | 类型 |
|----------|-------|---------|---------|---------|------|
| 高血压怎么治 | 高血压治疗 | 诊疗 | 诊疗-治疗 | ... | 疾病治疗 |
| 糖尿病吃什么药 | 糖尿病用药 | 诊疗 | 诊疗-用药 | ... | 用药咨询 |

- 给每个query分类（属于什么场景、什么类型）

### 3. 核心指标含义

| 指标 | 含义 | 计算方式 | 例子 |
|------|------|---------|------|
| **有结果率** | 有多少query返回了结果 | 有结果的query数 / 总query数 | 900/1000 = 90% |
| **hit_rate** | 有多少rawquery命中了A/B级结果 | 命中的rawquery数 / 总rawquery数 | 800/1000 = 80% |
| **Agood率** | 返回结果中A级文档的比例 | A级文档数 / 总文档数 | 300/1000 = 30% |
| **A+Bgood率** | 返回结果中A+B级文档的比例 | (A+B)级文档数 / 总文档数 | 600/1000 = 60% |
| **NDCG** | 排序质量（0-1，越高越好） | 考虑位置的相关性得分 | 0.85 |
| **Authority** | 权威度（0-1） | 文档来源的权威性 | 0.67（教科书=6分，疾病库=2分） |
| **Timeliness** | 时效性（0-1） | 文档的新鲜程度 | 0.78（用时间衰减公式） |

### 第101-118行：标签映射函数（关键！）

```python
def map_relevance_label(value):
    """A/B/C/D → 4/3/2/1，弃标→0，其他→None"""
    if pd.isna(value) or value is None:
        return None
    if isinstance(value, str):
        v = value.strip()
        if v in ("弃标", ""):
            return 0
        m = {"A": 4, "B": 3, "C": 2, "D": 1}.get(v.upper())
        if m is not None:
            return m
        try:
            return int(v)
        except (ValueError, TypeError):
            return None
    if isinstance(value, (int, float)):
        return int(value)
    return None
```

**逐步分析**：

1. **第103-104行**：如果是空值（NaN或None），返回None
   ```python
   if pd.isna(value) or value is None:
       return None
   ```

2. **第105-115行**：如果是字符串
   ```python
   if isinstance(value, str):
       v = value.strip()  # 去掉首尾空格
   ```
   
   - `"弃标"` 或 `""` → 返回0
   - `"A"` → 4，`"B"` → 3，`"C"` → 2，`"D"` → 1
   - `.upper()`：把"a"/"b"/"c"/"d"也识别为A/B/C/D

### 第121-126行：DCG计算（NDCG的基础）

```python
def dcg(scores, k):
    v = 0.0
    for i in range(1, min(len(scores) + 1, k + 1)):
        if scores[i - 1] > 0:
            v += (2 ** scores[i - 1] - 1) / math.log2(i + 1)
    return v
```

**这是什么**：
DCG = Discounted Cumulative Gain（折损累积增益），用来评估排序质量。

**数学公式**：
```
DCG@k = Σ (2^rel_i - 1) / log₂(i + 1)
```
其中 `rel_i` 是第i个位置的相关性分数。

**举例**：
假设一个query返回了5个文档，相关性分数是 `[4, 3, 2, 1, 0]`（A, B, C, D, 无关）

计算DCG@3（只看前3个）：
```
位置1: (2^4 - 1) / log₂(2) = 15 / 1 = 15.0
位置2: (2^3 - 1) / log₂(3) = 7 / 1.585 = 4.42
位置3: (2^2 - 1) / log₂(4) = 3 / 2 = 1.5
DCG@3 = 15.0 + 4.42 + 1.5 = 20.92
```

**为什么这样算**：
- 位置越靠前，权重越大（`1/log₂(i+1)`是递减的）
- 相关性越高，得分越高（`2^rel - 1`）

**代码细节**：
```python
for i in range(1, min(len(scores) + 1, k + 1)):
```
- `i` 从1开始（位置1、2、3...）
- `min(len(scores) + 1, k + 1)`：如果文档不足k个，只算实际数量

### 第129-133行：MRR计算

```python
def calc_mrr(scores):
    for rank, s in enumerate(scores, 1):
        if s in (3, 4):  # B级或A级
            return 1.0 / rank
    return 0.0
```

**这是什么**：
MRR = Mean Reciprocal Rank（平均倒数排名），找第一个好结果的位置。

**公式**：
```
MRR = 1 / (第一个A/B级文档的位置)
```

**举例**：
| 情况 | 相关性序列 | MRR |
|------|-----------|-----|
| 第1个就是好结果 | [4, 3, 2] | 1/1 = 1.0 |
| 第2个才是好结果 | [2, 4, 1] | 1/2 = 0.5 |
| 第3个才是好结果 | [1, 2, 3] | 1/3 = 0.33 |
| 都不好 | [2, 2, 1] | 0.0 |

**为什么用`s in (3, 4)`**：
- 3 = B级文档
- 4 = A级文档
- 只有A/B才算"好结果"

### 第136-142行：MAP计算

```python
def calc_map(scores):
    pos, prec = [], []
    for k, s in enumerate(scores, 1):
        if s in (3, 4):  # 好结果
            pos.append(k)
            prec.append(len(pos) / k)
    return sum(prec) / len(prec) if prec else 0
```

**这是什么**：
MAP = Mean Average Precision（平均精确率），考虑所有好结果的位置。

**举例**：
相关性序列：`[4, 2, 3, 1, 4]`（A, C, B, D, A）

找出所有A/B的位置：
- 位置1: A → 此时精确率 = 1/1 = 1.0
- 位置3: B → 此时精确率 = 2/3 = 0.67
- 位置5: A → 此时精确率 = 3/5 = 0.6

MAP = (1.0 + 0.67 + 0.6) / 3 = 0.76

**代码解读**：
```python
for k, s in enumerate(scores, 1):  # k=1,2,3...（位置）
    if s in (3, 4):
        pos.append(k)           # 记录这是第几个好结果
        prec.append(len(pos) / k)  # 计算到当前位置的精确率
```

### 第145-157行：时间戳转日期

```python
def ts_to_valid_date(ts):
    """过滤异常时间戳，返回有效日期字符串或 None"""
    try:
        v = int(ts)
        if v <= 0:
            return None
        if v > 1e12:      # 如果是毫秒级时间戳（13位）
            v = v // 1000  # 除以1000变成秒级（10位）
        if v < TS_MIN or v > TS_MAX:  # 不在1970-2030范围内
            return None
        return time.strftime("%Y-%m-%d", time.localtime(v))
    except (ValueError, TypeError, OverflowError):
        return None
```

**这在干什么**：
把时间戳（比如 `1622505600`）转成日期字符串（`"2021-06-01"`）

**为什么要过滤**：
Excel里的时间戳可能是脏数据：
- 负数：`-123456`
- 零：`0`
- 超大数：`9999999999999`
- 非数字：`"abc"`

**时间戳格式**：
- **秒级**（10位）：`1622505600` = 2021-06-01
- **毫秒级**（13位）：`1622505600000` = 2021-06-01

代码第151-152行会自动识别并转换。

**坑**：如果你的时间戳列是日期字符串（`"2021-06-01"`），这个函数会返回None！

### 第160-165行：时间衰减公式

```python
def time_decay(date_str, rate=0.161):
    d = datetime.strptime(date_str, "%Y-%m-%d")
    yr = (datetime.now() - d).days / 365.0  # 计算年龄（单位：年）
    if yr < 0:
        yr = 0
    return math.exp(-rate * yr)  # e^(-0.161 * 年龄)
```

**数学公式**：
```
时效性得分 = e^(-0.161 × 年龄)
```

**举例**：
| 文档发布时间 | 年龄 | 时效性得分 |
|------------|------|-----------|
| 今天 | 0年 | e^0 = 1.0 |
| 1年前 | 1年 | e^(-0.161) ≈ 0.85 |
| 5年前 | 5年 | e^(-0.805) ≈ 0.45 |
| 10年前 | 10年 | e^(-1.61) ≈ 0.20 |

**为什么是0.161**：
这个是经验值，表示"每年衰减16%左右"。

**坑**：如果文档日期在未来（比如2027年），`yr`会是负数，代码第163-164行会强制改成0。
