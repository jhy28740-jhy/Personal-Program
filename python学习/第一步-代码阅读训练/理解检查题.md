### 题目2：DCG计算
看这段代码：
```python
def dcg(scores, k):
    v = 0.0
    for i in range(1, min(len(scores) + 1, k + 1)):
        if scores[i - 1] > 0:
            v += (2 ** scores[i - 1] - 1) / math.log2(i + 1)
    return v
```

**问题**：如果 `scores = [4, 3, 2]`，`k = 3`，第一个位置贡献的分数是多少？

<details>
<summary>答案（点击展开）</summary>

**15.0**

解析：
- 位置1（i=1）：
  - `scores[0] = 4`
  - `(2^4 - 1) / log₂(2) = (16 - 1) / 1 = 15.0`
</details>

```python
def time_decay(date_str, rate=0.161):
    d = datetime.strptime(date_str, "%Y-%m-%d")
    yr = (datetime.now() - d).days / 365.0
    if yr < 0:
        yr = 0
    return math.exp(-rate * yr)
```

**问题**：如果文档发布日期是5年前，时效性得分大约是多少？

<summary>答案（点击展开）</summary>

**大约 0.45**

解析：
- `yr = 5`
- `e^(-0.161 × 5) = e^(-0.805) ≈ 0.447`

### 题目16：优化权威度函数
现在的 `auth_score()` 函数有什么问题？怎么改进？

```python
def auth_score(row):
    idx = str(row.get("indexName", "") or row.get("_indexName", ""))
    auth = str(row.get("authority", ""))
    cat = str(row.get("category", ""))

        if auth in ["双核心", "单核心", "非核心"]:
            return {"双核心": 3, "单核心": 2, "非核心": 1}.get(auth, 0)
        ...
```

<details>
<summary>答案（点击展开）</summary>

**问题**：
1. 如果 `indexName` 是 None，`str(None)` = `"None"`（字符串），不是空字符串
2. `"期刊"` 可能误匹配（如 "非期刊"）
3. 重复的字典定义

**改进**：
```python
def auth_score(row):
    # 改进1：安全地转换
    idx = str(row.get("indexName") or row.get("_indexName") or "")
    auth = str(row.get("authority") or "")
    cat = str(row.get("category") or "")
    
    # 改进2：精确匹配
    if idx == "期刊" or idx.startswith("期刊-"):
        # 改进3：提取常量
        JOURNAL_SCORES = {"双核心": 3, "单核心": 2, "非核心": 1}
        if auth in JOURNAL_SCORES:
            return JOURNAL_SCORES[auth]
        ...
```

### 题目18：性能优化
`run_stats()` 函数处理大数据时很慢，怎么优化？

<details>
<summary>答案（点击展开）</summary>

**瓶颈1：iterrows()** 很慢
```python
# 慢
for _, row in g.iterrows():
    auth_scores.append(auth_score(row))

# 快
auth_scores.extend(g.apply(auth_score, axis=1).tolist())
```

**瓶颈2：重复计算**
```python
# 可以预先计算并缓存
@lru_cache(maxsize=1000)
def auth_score(indexName, authority, category):
    # ... 计算逻辑
    pass
```

**瓶颈3：pandas apply**
某些操作可以向量化：
```python
# 慢
df[rel] = df[rel].apply(map_relevance_label)

# 快（如果逻辑简单）
df[rel] = df[rel].str.upper().map({"A": 4, "B": 3, "C": 2, "D": 1})
```
