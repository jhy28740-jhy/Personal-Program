## 第195-283行：核心统计函数 run_stats()

这是**整个脚本最重要的函数**，90%的计算都在这里完成。

### 函数签名

```python
def run_stats(df_full, query_set, qt, topk, raw_query_map=None):
    """对 query 集合算所有指标

    raw_query_map: dict[rawquery -> set(query)]，用于计算 hit_rate
                   - 分母：raw_query_map 的 key 数（去重 rawquery 数）
                   - 分子：rawquery 拆出的任一 query 在该链路返回了 A/B 级 doc，则该 rawquery hit
    """
```

**参数含义**：
- `df_full`：完整的A表数据（DataFrame）
- `query_set`：要统计的query集合（set）
- `qt`：query总数（int）
- `topk`：只看前k个结果（int，通常是3）
- `raw_query_map`：rawquery到query的映射（dict，可选）

**返回值**：一个字典，包含所有统计指标

### 第202-207行：数据准备

```python
df = df_full[df_full["query"].isin(query_set)].copy()
rel = "relevance_label"
if rel not in df.columns:
    return None
df[rel] = df[rel].apply(map_relevance_label)
df = df[df[rel].notna()].copy()
```

**逐行分析**：

1. **第202行**：筛选数据
   ```python
   df = df_full[df_full["query"].isin(query_set)].copy()
   ```
   - 只保留 `query_set` 里的query
   - `.copy()` 创建副本，避免修改原数据
   - **举例**：如果 `query_set = {"高血压", "糖尿病"}`，只保留这两个query的行

2. **第203-205行**：检查标注列
   ```python
   rel = "relevance_label"
   if rel not in df.columns:
       return None
   ```
   - 如果A表没有 `relevance_label` 列，返回None（无法统计）

3. **第206行**：转换标签
   ```python
   df[rel] = df[rel].apply(map_relevance_label)
   ```
   - 对每个标签应用 `map_relevance_label()` 函数
   - `"A"` → `4`, `"B"` → `3`, `"C"` → `2`, `"D"` → `1`

4. **第207行**：过滤无效标签
   ```python
   df = df[df[rel].notna()].copy()
   ```
   - 只保留标签不是None的行
   - 如果某行标签是 `"弃标"` 或解析失败 → 被排除

### 第209-212行：排序处理

```python
sort_col = "_rank_index" if "_rank_index" in df.columns else (
    "index" if "index" in df.columns else None)
if sort_col:
    df = df.sort_values(["query", sort_col]).reset_index(drop=True)
```

**这在干什么**：
按query分组，然后按排名排序。

**为什么需要排序**：
计算NDCG、MRR、MAP时，文档的顺序很重要！

**举例**：
排序前（乱序）：
| query | title | relevance_label | _rank_index |
|-------|-------|----------------|-------------|
| 高血压 | 文档C | C | 3 |
| 高血压 | 文档A | A | 1 |
| 高血压 | 文档B | B | 2 |

排序后（按_rank_index）：
| query | title | relevance_label | _rank_index |
|-------|-------|----------------|-------------|
| 高血压 | 文档A | A | 1 |
| 高血压 | 文档B | B | 2 |
| 高血压 | 文档C | C | 3 |

**三元表达式解读**：
```python
sort_col = "_rank_index" if "_rank_index" in df.columns else (
    "index" if "index" in df.columns else None)
```
等价于：
```python
if "_rank_index" in df.columns:
    sort_col = "_rank_index"
elif "index" in df.columns:
    sort_col = "index"
else:
    sort_col = None
```

### 第223-253行：主循环（遍历每个query）

```python
for _, g in grouped:
    s = g[rel].astype(int).tolist()
    if not s:
        continue
    qry_count += 1
```

**第223行**：遍历每个query的数据
```python
for _, g in grouped:
```
- `grouped` 是按query分组后的对象
- `g` 是一个query的所有行（DataFrame）
- `_` 表示不关心分组的key（query名称）

**举例**：
假设有3个query，grouped遍历时：
- 第1次：`g` = 高血压的所有行（5行）
- 第2次：`g` = 糖尿病的所有行（3行）
- 第3次：`g` = 感冒的所有行（2行）

**第224行**：提取相关性分数列表
```python
s = g[rel].astype(int).tolist()
```
- `g[rel]` 取这个query所有文档的 `relevance_label` 列
- `.astype(int)` 转成整数
- `.tolist()` 转成Python列表

**举例**：
如果高血压返回了5个文档，标签是 `[4, 3, 2, 1, 0]`（A, B, C, D, 无关），则 `s = [4, 3, 2, 1, 0]`

### 第228-237行：计算NDCG、MRR、MAP

```python
s_topk = s[:topk]
dc = len(s_topk)
gs = sorted(s, reverse=True)
idcg_v = dcg(gs, topk)
ndcg_list.append(dcg(s_topk, topk) / idcg_v if idcg_v > 0 else 0)
mrr_list.append(calc_mrr(s_topk))
m = calc_map(s_topk)
if m > 0:
    map_list.append(m)
```

**逐行分析**：

1. **第228行**：只取前topk个
   ```python
   s_topk = s[:topk]
   ```
   - 如果 `topk=3`，`s = [4,3,2,1,0]` → `s_topk = [4,3,2]`

2. **第229行**：实际文档数
   ```python
   dc = len(s_topk)
   ```
   - 通常 `dc = topk = 3`
   - 但如果这个query只返回了2个文档，`dc = 2`

3. **第230行**：理想排序
   ```python
   gs = sorted(s, reverse=True)
   ```
   - `s = [2, 4, 1, 3]` → `gs = [4, 3, 2, 1]`（从大到小排序）
   - 这是"最好的排序"，用于计算IDCG

4. **第231行**：计算IDCG（理想DCG）
   ```python
   idcg_v = dcg(gs, topk)
   ```
   - IDCG = 如果文档按最佳顺序排列，DCG是多少

5. **第232行**：计算NDCG
   ```python
   ndcg_list.append(dcg(s_topk, topk) / idcg_v if idcg_v > 0 else 0)
   ```
   - NDCG = 实际DCG / 理想DCG
   - 范围：0-1，越大越好
   - **举例**：
     - 实际顺序：`[4, 3, 2]` → DCG = 20.92
     - 理想顺序：`[4, 3, 2]` → IDCG = 20.92
     - NDCG = 20.92 / 20.92 = 1.0（完美！）

6. **第233-237行**：计算MRR和MAP
   ```python
   mrr_list.append(calc_mrr(s_topk))
   m = calc_map(s_topk)
   if m > 0:
       map_list.append(m)
   ```
   - 注意：MAP只有在有好结果时才加入列表

### 第238-243行：计算good率

```python
doc_total += dc
ac = Counter(s_topk)[4]
bc = Counter(s_topk)[3]
a_total += ac
ab_total += (ac + bc)
qa_rates.append(ac / dc)
qab_rates.append((ac + bc) / dc)
```

**第238行**：累加文档总数
```python
doc_total += dc
```
- 所有query的文档数加起来

**第239-240行**：统计A级和B级文档数
```python
ac = Counter(s_topk)[4]  # 数有多少个4（A级）
bc = Counter(s_topk)[3]  # 数有多少个3（B级）
```

**Counter是什么**：
```python
from collections import Counter
s_topk = [4, 3, 2, 4, 1]
c = Counter(s_topk)
# c = {4: 2, 3: 1, 2: 1, 1: 1}
# c[4] = 2（有2个4）
# c[3] = 1（有1个3）
```

**第241-242行**：累加全局计数
```python
a_total += ac        # 所有query的A级文档总数
ab_total += (ac + bc)  # 所有query的A+B级文档总数
```

**第243-244行**：记录每个query的good率
```python
qa_rates.append(ac / dc)          # 这个query的A占比
qab_rates.append((ac + bc) / dc)  # 这个query的A+B占比
```

**举例**：
- 某query返回3个文档：`[4, 3, 2]`（A, B, C）
- `ac = 1`, `bc = 1`, `dc = 3`
- `qa_rates.append(1/3)` → 33.3%
- `qab_rates.append(2/3)` → 66.7%

### 第258-265行：计算hit_rate（关键！）

```python
hit_rate = 0.0
if raw_query_map:
    raw_total = len(raw_query_map)
    if raw_total > 0:
        hit_raw = sum(1 for raw, qs in raw_query_map.items()
                      if qs & query_has_good)
        hit_rate = hit_raw / raw_total
```

**这是在算什么**：
rawquery级别的命中率（不是query级）

**rawquery vs query的区别**：
| rawquery（用户原始输入） | query（标准化后） |
|------------------------|-----------------|
| 高血压怎么治疗 | 高血压治疗 |
| 高血压的治疗方法 | 高血压治疗 |
| 糖尿病吃什么药 | 糖尿病用药 |

- 1个rawquery可能对应多个query
- `raw_query_map` 的结构：
  ```python
  {
      "高血压怎么治疗": {"高血压治疗", "高血压"},
      "糖尿病吃什么药": {"糖尿病用药", "糖尿病"},
  }
  ```

**第263-264行的逻辑**：
```python
hit_raw = sum(1 for raw, qs in raw_query_map.items()
              if qs & query_has_good)
```
- 遍历每个rawquery和它对应的query集合
- `qs & query_has_good`：取交集
- 如果交集不为空（至少有1个query命中了A/B），计数+1

**举例**：
- `raw_query_map = {"高血压怎么治疗": {"高血压治疗", "高血压"}}`
- `query_has_good = {"高血压治疗", "糖尿病"}`
- 交集：`{"高血压治疗", "高血压"} & {"高血压治疗", "糖尿病"} = {"高血压治疗"}` ≠ 空
- 这个rawquery算命中

**第265行**：
```python
hit_rate = hit_raw / raw_total
```
- 命中的rawquery数 / 总rawquery数

### 第267-283行：返回结果字典

```python
return {
    "query_total": qt,
    "有结果query数": qry_count,
    "有结果率": qry_count / qt if qt > 0 else 0,
    "有结果吸收率": qry_with_good / qry_count,
    "hit_rate": hit_rate,
    "产出率": yield_sum / qt if qt > 0 else 0,
    "Agood率": a_total / doc_total if doc_total > 0 else 0,
    "A+Bgood率": ab_total / doc_total if doc_total > 0 else 0,
    "query_Agood率": sum(qa_rates) / len(qa_rates),
    "query_A+Bgood率": sum(qab_rates) / len(qab_rates),
    "NDCG": sum(ndcg_list) / len(ndcg_list),
    "MAP": sum(map_list) / len(map_list) if map_list else 0,
    "MRR": sum(mrr_list) / len(mrr_list),
    "Timeliness": sum(year_scores) / len(year_scores) if year_scores else 0,
    "Authority": sum(auth_scores) / len(auth_scores) / 6 if auth_scores else 0,
}
```

**每个指标的计算**：

| 指标 | 计算公式 | 分子 | 分母 |
|------|---------|------|------|
| 有结果率 | `qry_count / qt` | 有结果的query数 | 总query数 |
| 有结果吸收率 | `qry_with_good / qry_count` | 有A/B的query数 | 有结果的query数 |
| hit_rate | `hit_raw / raw_total` | 命中的rawquery数 | 总rawquery数 |
| 产出率 | `yield_sum / qt` | 产出率总和 | 总query数 |
| Agood率 | `a_total / doc_total` | A级文档数 | 总文档数 |
| A+Bgood率 | `ab_total / doc_total` | A+B级文档数 | 总文档数 |
| query_Agood率 | `mean(qa_rates)` | 每个query的A占比的平均 | - |
| query_A+Bgood率 | `mean(qab_rates)` | 每个query的A+B占比的平均 | - |
| NDCG | `mean(ndcg_list)` | 所有query的NDCG平均 | - |
| MAP | `mean(map_list)` | 所有query的MAP平均 | - |
| MRR | `mean(mrr_list)` | 所有query的MRR平均 | - |
| Timeliness | `mean(year_scores)` | 所有文档的时效性平均 | - |
| Authority | `mean(auth_scores) / 6` | 所有文档的权威度平均 / 6 | - |

**注意**：
- Authority 除以6是为了归一化到0-1（因为最高分是6）
- 所有带 `if ... else 0` 的都是防止除以0

## 关键问题：Agood率 vs query_Agood率 的区别

这是最容易混淆的两个指标！

### Agood率（文档级）

```python
"Agood率": a_total / doc_total
```

**计算方式**：
- 分子：所有A级文档数
- 分母：所有文档数

**举例**：
| query | 文档1 | 文档2 | 文档3 |
|-------|-------|-------|-------|
| 高血压 | A | B | C |
| 糖尿病 | A | A | D |

- A级文档：3个
- 总文档：6个
- **Agood率 = 3/6 = 50%**

### query_Agood率（query级）

```python
"query_Agood率": sum(qa_rates) / len(qa_rates)
```

**计算方式**：
1. 先算每个query的A占比
2. 再求平均

**同样的例子**：
- 高血压：A占比 = 1/3 = 33.3%
- 糖尿病：A占比 = 2/3 = 66.7%
- **query_Agood率 = (33.3% + 66.7%) / 2 = 50%**

**什么时候两者不同？**

| query | 文档数 | A数 | A占比 |
|-------|-------|-----|------|
| 高血压 | 10 | 5 | 50% |
| 糖尿病 | 2 | 1 | 50% |

- **Agood率**：(5+1)/(10+2) = 6/12 = **50%**
- **query_Agood率**：(50% + 50%) / 2 = **50%**

但如果：

| query | 文档数 | A数 | A占比 |
|-------|-------|-----|------|
| 高血压 | 10 | 8 | 80% |
| 糖尿病 | 2 | 0 | 0% |

- **Agood率**：(8+0)/(10+2) = 8/12 = **66.7%**
- **query_Agood率**：(80% + 0%) / 2 = **40%**

**哪个更重要？**
- 如果关心"整体文档质量" → 用 **Agood率**
- 如果关心"每个query的体验" → 用 **query_Agood率**

---

## 总结：run_stats() 做了什么

1. **数据准备**：筛选query、转换标签、排序
2. **按query遍历**：
   - 计算NDCG、MRR、MAP（排序质量）
   - 统计A/B文档数（good率）
   - 提取时间戳和权威度信息
3. **计算hit_rate**：rawquery级命中率
4. **返回所有指标**：16个指标的字典

**关键点**：
- 所有"率"都要防止除以0
- NDCG要用理想排序做归一化
- hit_rate是rawquery级，不是query级
- Authority要除以6归一化
