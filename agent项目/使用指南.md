# 🚀 快速使用指南

## 方式1：双击运行（最简单）

项目根目录有两个 `.bat` 文件，直接双击即可：

- **运行周报生成器.bat** — 双击生成本周周报
- **运行交互式Agent.bat** — 双击启动聊天式 Agent

## 方式2：VSCode 集成（推荐）

### 📋 使用任务菜单

1. 在 VSCode 中打开本项目文件夹
2. 按 `Ctrl+Shift+P`（打开命令面板）
3. 输入 `Tasks: Run Task`
4. 选择你想运行的任务：
   - 🤖 **运行交互式Agent** — 聊天式使用
   - 📊 **生成本周周报** — 自动生成周报
   - 🧪 运行示例1/2/3 — 学习示例

### ⌨️ 使用快捷键（更快）

- `Ctrl+Shift+R` — 生成本周周报
- `Ctrl+Shift+A` — 启动交互式Agent

### 📝 如果快捷键冲突

VSCode 的快捷键可能和其他插件冲突。如果按了没反应：
1. 按 `Ctrl+Shift+P`
2. 输入 `Tasks: Run Task`
3. 手动选择任务

或者修改快捷键：
1. 打开 `.vscode/keybindings.json`
2. 把 `ctrl+shift+r` 改成其他组合（如 `ctrl+alt+r`）

## 🎯 推荐工作流

**日常使用交互式Agent：**
- VSCode 里按 `Ctrl+Shift+A`
- 或双击 `运行交互式Agent.bat`

**每周五生成周报：**
- VSCode 里按 `Ctrl+Shift+R`
- 或双击 `运行周报生成器.bat`
- 打开 `周报输出/` 文件夹中生成的 Excel
- 手动填写工作进度（D列）和下周计划（E列）
