3. 中文乱码 → 加 PYTHONIOENCODING=utf-8 和 sys.stdout重定向

**重要概念（已理解 ✅）**：
- LLM = 大脑（负责思考）
- 框架(CrewAI) = 骨架（负责连接组织）

### 🎉 里程碑4：LangGraph 智能审稿助手 (2026-07-24) ✅

**项目**：`05_langgraph_reviewer.py` — 带条件分支+环的图工作流
**图结构**：
```
START → grammar_check → content_review → ⟨route⟩
                            ↑              ├ score>=7 → END
                            └── revise ────┘ (score<7 且 轮数<3)
```
**核心概念（图论视角，本人是图论组合方向）**：
- Node=函数(state->dict)，返回值合并进全局State(默认覆盖)
- add_edge固定边，add_conditional_edges条件边(路由函数返回下一节点名)
- content_review<->revise 构成有向环
- 三重停机保证：score阈值 + revisions上限 + recursion_limit
- 本质是状态机/带标签转移系统，δ(state)->next_node

**CrewAI vs LangGraph 本质区别**：
- CrewAI：线性链(DAG无环)，固定顺序
- LangGraph：允许环，状态驱动的条件转移，适合"根据结果决定循环/前进"

**运行效果**：差草稿 score=2 → 进环重写1次 → score=9 → END

**工具补充**：装了 langgraph 包

**下一步可选**：
- 用LangGraph重构周报生成器（加"质量不够重新总结"的环）
- 学State的reducer（累加/追加语义，不只是覆盖）
- 做更复杂的多分支图
