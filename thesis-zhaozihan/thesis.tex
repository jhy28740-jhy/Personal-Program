\chapter{续\ \论}
\vspace{0.2cm}
在经典拓扑学的研究中, 研究者们长期聚焦于由拓扑定义的小尺度结构, 如邻域系统、连续性等, 度量空间中连续性的研究便是典型范例. 然而, 在定义度量空间上映射的连续性时, 度量本身蕴含的大量信息往往被忽略. 与经典拓扑学相对, 数学研究有时需关注其对偶情形, 即大尺度几何（亦称粗几何）. 粗几何这一学科现已与拓扑学、指标理论等建立了深刻联系\cite{ref1}. Roe在其专著中对粗几何进行了系统论述\cite{ref2}.

模糊集的概念由Zadeh首创, 在Zadeh的开创性论文中, 模糊集被视为一个函数\hspace{0pt}\penalty0$f:X\to \left ( { 0,1 } \right )$\nobreak\hspace{0pt}, 其值\hspace{0pt}\penalty0$f\left ( { x } \right )$\penalty0\hspace{0pt}通常解释为元素\hspace{0pt}\penalty0$x$\penalty0\hspace{0pt}属于该模糊集的确定程度\cite{ref3}. 众所周知, 模糊集理论已发展成为一个极为活跃的研究领域. 尽管粗几何理论在数学的诸多分支中扮演着重要角色, 但在Zarichnyi于2009年的工作之前\cite{ref4}, 粗几何从未在模糊背景下被系统研究. 据我们所知, 迄今为止关于模糊粗结构本身的研究并不多（近期一些论文探讨了模糊度量空间中的大尺度几何性质, 但其粗结构集本身仍是经典的）. 而且, 现有的模糊粗结构研究多基于单一格\hspace{0pt}\penalty0$L$\nobreak\hspace{0pt}, 这种单格框架在处理某些复杂的渐近行为或需要同时刻画不同层次的不确定性时可能会不够合适\cite{ref5}. 为更精细、更灵活地描述大尺度模糊结构, 亟需引入双格框架.

受严从华和王永超对粗结构模糊化工作的启发\cite{ref6}, 本文将引入\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构的概念, 并给出其等价刻画. 本文的结构如下：在第二节中, 我们列出一些完全分配格、模糊关系、单格模糊粗结构的基本概念与结果. 在第三节中, 我们给出\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构概念和\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗空间之间的态射, 并列举了\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构实例. 在第四节中, 我们引入\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球结构的概念, 并建立其与\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构之间的相互刻画关系.

\section{格论,模糊集的相关知识}
\vspace{0.2cm}
在本文中, 称一个非空集合\hspace{0pt}\penalty0$P$\penalty0\hspace{0pt}为一个偏序集, 如果它中的一个二元关系\hspace{0pt}\penalty0$\leq$\penalty0\hspace{0pt}满足自反性、反对称性和传递性. 称\hspace{0pt}\penalty0$P$\penalty0\hspace{0pt}的子集\hspace{0pt}\penalty0$D$\penalty0\hspace{0pt}为有向的, 如果它是非空的, 并且\hspace{0pt}\penalty0$D$\penalty0\hspace{0pt}的每个有限子集在\hspace{0pt}\penalty0$D$\penalty0\hspace{0pt}中都有上界\cite{ref7}.

本文中, \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}和\hspace{0pt}\penalty0$M$\penalty0\hspace{0pt}都是完全分配格, 它们的最大元记为\hspace{0pt}\penalty0$~\top$\nobreak\hspace{0pt}, 最小元记为\hspace{0pt}\penalty0$\bot$\nobreak\hspace{0pt}. \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}上的一个二元关系\hspace{0pt}\penalty0$\prec$\penalty0\hspace{0pt}定义为, 对\hspace{0pt}\penalty0$\forall a,b\in L$\nobreak\hspace{0pt},\hspace{0pt}\penalty0$a\prec b$\penalty0\hspace{0pt}当且仅当对\hspace{0pt}\penalty0$\forall M\subseteq L$\nobreak\hspace{0pt},\hspace{0pt}\penalty0$b\le \vee M$\nobreak\hspace{0pt}, 存在一个\hspace{0pt}\penalty0$d\in M$\nobreak\hspace{0pt}, 使得\hspace{0pt}\penalty0$a\le d$\nobreak\hspace{0pt}. 映射\hspace{0pt}\penalty0$\beta :L\to 2 ^ { L }$\penalty0\hspace{0pt}定义为\hspace{0pt}\penalty0$\beta(a)=\{b\in L:b\prec a\}$\nobreak\hspace{0pt}, 且满足对\hspace{0pt}\penalty0$\forall \left \{ \begin{array}{l} a_{ i } \end{array} \right \}_{ i\in I } \subseteq L$\nobreak\hspace{0pt},\hspace{0pt}\penalty0$\beta\left(\bigvee_{i\in I}a_i\right)=\bigcup_{i\in I}\beta(a_i)$\penalty0\hspace{0pt}\cite{ref7}.

\textbf{定义2.1.1.}  \hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}上的一个非空子集\hspace{0pt}\penalty0$\mathcal{C}\subseteq L ^ { X\times X }$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵,如果它满足以下性质：

（E1）\hspace{0pt}\penalty0$\Delta _{ X } \in \mathcal{C}$\nobreak\hspace{0pt}；

（E2）如果\hspace{0pt}\penalty0$E\in \mathcal{C}$\nobreak\hspace{0pt},且\hspace{0pt}\penalty0$D\le E$\nobreak\hspace{0pt},则\hspace{0pt}\penalty0$D\in \mathcal{C}$\nobreak\hspace{0pt}；

（E3）\hspace{0pt}\penalty0$\forall E,F\in \mathcal{C}$\nobreak\hspace{0pt},则\hspace{0pt}\penalty0$E\vee F\in \mathcal{C}$\nobreak\hspace{0pt}；

一个\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵\hspace{0pt}\penalty0$\mathcal{C}\subseteq L ^ { X\times X }$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-拟粗结构,如果它又满足（E4）：

（E4）\hspace{0pt}\penalty0$\forall E,F\in \mathcal{C}$\nobreak\hspace{0pt},则\hspace{0pt}\penalty0$E\circ F\in \mathcal{C}$\nobreak\hspace{0pt}；

一个\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵\hspace{0pt}\penalty0$\mathcal{C}\subseteq L ^ { X\times X }$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-半粗结构,如果它又满足（E5）：

（E5）\hspace{0pt}\penalty0$\forall E\in \mathcal{C}$\nobreak\hspace{0pt},则\hspace{0pt}\penalty0$E ^ { -1 } \in \mathcal{C}$\nobreak\hspace{0pt}.

此外, 一个\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵\hspace{0pt}\penalty0$\mathcal{C}\subseteq L ^ { X\times X }$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-粗结构, 如果它既是\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-拟粗结构, 又是\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-半粗结构.相应地, \hspace{0pt}\penalty0$\left ( { X,\mathcal{C} } \right )$\penalty0\hspace{0pt}又分别称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵空间, \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-拟粗空间, \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-半粗空间, \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-粗空间\cite{ref7}.

\textbf{定义2.1.2}  对集合\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}及\hspace{0pt}\penalty0$\forall E,E_{ 1 } ,E_{ 2 } \subseteq X\times X$\nobreak\hspace{0pt}, 我们定义
$$E^{-1}=\{(y,x)\in X\times X:(x,y)\in E\},$$
$$E_{ 1 } \circ E_{ 2 } =\left \{ \begin{array}{l} \left ( { x,y } \right )\in X\times X:\exists z\in X,\left ( { x,z } \right )\in E_{ 1 } ,\left ( { z,y } \right )\in E_{ 2 } \end{array} \right \}.$$
对于上述运算，其单位元是\hspace{0pt}\penalty0$\Delta _{ X } \in L ^ { X\times X }$\nobreak\hspace{0pt}，定义为
$$\Delta_X(x,y)=\begin{cases}\top,&x=y,\\ \bot,&x\ne y,\end{cases}. \text{\cite{ref7}}$$
\textbf{定义2.1.3}  映射\hspace{0pt}\penalty0$R:X\times X\to M$\penalty0\hspace{0pt}是\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}上一个\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊关系, 称为：

（1）自反: \hspace{0pt}\penalty0$R\left ( { x,x } \right )=\top$\nobreak\hspace{0pt}；

（2）对称: \hspace{0pt}\penalty0$R\left ( { x,y } \right )=R\left ( { y,x } \right )$\nobreak\hspace{0pt}；

（3）传递: \hspace{0pt}\penalty0$R\circ R\le R$\nobreak\hspace{0pt}, 其中\hspace{0pt}\penalty0$R\circ R(x,y)=\bigvee_{ z\in X } R(x,z)\wedge R(z,y)$\nobreak\hspace{0pt}.

一个满足自反、对称和传递的\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊关系\hspace{0pt}\penalty0$R$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊等价关系, 如果\hspace{0pt}\penalty0$R:X\times X\to M$\penalty0\hspace{0pt}是\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}上一个\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊关系, 则称\hspace{0pt}\penalty0$\left ( { X,R } \right )$\penalty0\hspace{0pt}为\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊关系空间\cite{ref9}.

\textbf{命题3.2.8.}  设\hspace{0pt}\penalty0$\mathcal{B} =\left ( { X,P,\mathcal{B},\mathcal{N} } \right )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统, \hspace{0pt}\penalty0$\forall r\in P$\nobreak\hspace{0pt}, 定义映射\hspace{0pt}\penalty0$E_{ r } :X\times X\to L$\penalty0\hspace{0pt}为：\hspace{0pt}\penalty0$\forall x,y\in X$\nobreak\hspace{0pt},\hspace{0pt}\penalty0$E_{ r } \left ( { x,y } \right )=\mathcal{B}_{ r } \left ( { x,y } \right )$\nobreak\hspace{0pt}. 显然有\hspace{0pt}\penalty0$\mathcal{E}=\left \{ \begin{array}{l} E_{ r } :r\in P \end{array} \right \}\subset L ^ { X\times X }$\nobreak\hspace{0pt}. 定义映射\hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} } :L ^ { X\times X } \to M$\penalty0\hspace{0pt}为
$$\forall E\in L^{X\times X}, \mathcal{S}_{\mathcal{B}}(E)=\begin{cases}N(\mathcal{B}_r),&E=E_r\in\mathcal{E};\\\bot,&E\notin\mathcal{E}.\end{cases}$$
则\hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵结构的基, 它生成的\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵结构记为\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} }$\nobreak\hspace{0pt}. 此外,

（1）若\hspace{0pt}\penalty0$\mathcal{B}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半球空间, 则\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半粗结构；

（2）若\hspace{0pt}\penalty0$\mathcal{B}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟球空间, 则\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟粗结构；

（3）若\hspace{0pt}\penalty0$\mathcal{B}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球空间, 则\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构.

\textbf{证明：} （B1）\hspace{0pt}\penalty0$\forall r\in P$\nobreak\hspace{0pt}, \hspace{0pt}\penalty0$\forall x\in X$\nobreak\hspace{0pt}, 由\hspace{0pt}\penalty0$E_{ r } \left ( { x,x } \right )=\mathcal{B}_{ r } \left ( { x,x } \right )=\top =\Delta _{ X } \left ( { x,x } \right )$\nobreak\hspace{0pt}, 得
\begin{eqnarray*}\bigvee_{\Delta_X\leq E_r}\mathcal{N}_{\mathcal{B}}(E_r)&=&\bigvee_{\Delta_X\leq B_r}\mathcal{N}(\mathcal{B}_r)\\&=&\top.\end{eqnarray*}
（B2）\hspace{0pt}\penalty0$\forall E_r,E_s\in L^{X\times X}$\nobreak\hspace{0pt}, 有
\begin{eqnarray*}\mathcal{S}_{\mathcal{B}}(E_r)\wedge\mathcal{S}_{\mathcal{B}}(E_s)&=&\mathcal{N}(\mathcal{B}_r)\wedge\mathcal{N}(\mathcal{B}_s)\\&\leq&\mathcal{N}(\mathcal{B}_r\vee\mathcal{B}_s)\\&\leq&\bigvee_{\mathcal{B}_r\vee\mathcal{B}_s\leq\mathcal{B}_t}\mathcal{N}(\mathcal{B}_t)\\&=&\bigvee_{E_r\vee E_s\leq E_t}\mathcal{S}_{\mathcal{B}}(E_t)\\&\leq&\bigvee_{E_r\vee E_s\leq E}\mathcal{S}_{\mathcal{B}}(E),\end{eqnarray*}
故\hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵结构的基.

（1）若\hspace{0pt}\penalty0$\mathcal{B}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半球空间, 则\hspace{0pt}\penalty0$\forall r\in P$\nobreak\hspace{0pt}, 有
$$\mathcal{S}_{\mathcal{B}}(E_r)=\mathcal{N}(\mathcal{B}_r)=\mathcal{N}(\mathcal{B}_r^*)=\mathcal{S}_{\mathcal{B}}(E_r^{-1})\leq\bigvee_{E_r^{-1}\leq E_t}\mathcal{S}_{\mathcal{B}}(E_t)\leq\bigvee_{E_r^{-1}\leq E}\mathcal{S}_{\mathcal{B}}(E),$$
故\hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半粗结构的基, \hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半粗结构.

（2）若\hspace{0pt}\penalty0$\mathcal{B}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟球空间, 则\hspace{0pt}\penalty0$\forall r,s\in P$\nobreak\hspace{0pt}, 有
\begin{eqnarray*}\mathcal{S}_{\mathcal{B}}(E_r)\wedge\mathcal{S}_{\mathcal{B}}(E_s)&=&\mathcal{N}(\mathcal{B}_r)\wedge\mathcal{N}(\mathcal{B}_s)\\&\leq&\mathcal{N}(\mathcal{B}_r\vee\mathcal{B}_s)\leq\mathcal{N}(\mathcal{B}_r\circ\mathcal{B}_s)\\&\leq&\bigvee_{\mathcal{B}_r\circ\mathcal{B}_s\leq\mathcal{B}_t}\mathcal{N}(\mathcal{B}_t)=\bigvee_{E_r\circ E_s\leq E_t}\mathcal{S}_{\mathcal{B}}(E_t)\\&\leq&\bigvee_{E_r\circ E_s\leq E}\mathcal{S}_{\mathcal{B}}(E),\end{eqnarray*}
故\hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟粗结构的基, \hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟粗结构.

（3）若\hspace{0pt}\penalty0$\mathcal{B}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球空间, 则显然\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构.

\textbf{定理3.2.9.}  设\hspace{0pt}\penalty0$\left ( { X,\mathcal{C} } \right )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵空间, 则\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} _{ \mathcal{C} } } =\mathcal{C}$\nobreak\hspace{0pt}.

\textbf{证明：} 设\hspace{0pt}\penalty0$E\in L ^ { X\times X }$\nobreak\hspace{0pt}, 则\hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} _{ \mathcal{C} } } \left ( { F } \right )=\mathcal{N}_{ \mathcal{C} } \left ( { \mathcal{B}_{ F } } \right )=\mathcal{C}\left ( { F } \right )$\nobreak\hspace{0pt}. 于是对任意\hspace{0pt}\penalty0$E\in L ^ { X\times X }$\nobreak\hspace{0pt}, 有
$$\mathcal{B}_{\mathcal{C}}(E)=\bigvee_{E\leq F}\mathcal{S}_{\mathcal{B}_{\mathcal{C}}}(F)=\bigvee_{E\leq F}\mathcal{C}(F)=\mathcal{C}(E),$$
故\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} _{ \mathcal{C} } } =\mathcal{C}$\nobreak\hspace{0pt}.

\textbf{命题3.2.10.}  设\hspace{0pt}\penalty0$\mathcal{B} _{ X } =\left ( { X,P,\mathcal{B}_{ X } ,\mathcal{N}_{ X } } \right )$\penalty0\hspace{0pt}和\hspace{0pt}\penalty0$\mathcal{B} _{ Y } =\left ( { Y,Q,\mathcal{B}_{ Y } ,\mathcal{N}_{ Y } } \right )$\penalty0\hspace{0pt}是\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统, 则\hspace{0pt}\penalty0$f:X\to Y$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球保持映射当且仅当\hspace{0pt}\penalty0$f:(X,\mathcal{C}_{ \mathcal{B} _{ X } } )\to (Y,\mathcal{C}_{ \mathcal{B} _{ Y } } )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊保有界映射.

\textbf{证明：} ``必要性'':对任意\hspace{0pt}\penalty0$E\in L ^ { X\times X }$\nobreak\hspace{0pt}, 有
\begin{eqnarray*}\mathcal{C}_{\mathcal{B}_X}(E)&=&\bigvee_{E\leq F}\mathcal{S}_{\mathcal{B}_X}(E)=\bigvee_{E\leq E_r}\mathcal{N}_X((\mathcal{B}_X)_r)\\&\leq&\bigvee_{f_L^{\to}(E)\leq f_L^{\to}(E_r)}\bigvee_{s\in(P_Y)_r^f}\mathcal{N}_Y((\mathcal{B}_X)_s)\\&\leq&\bigvee_{f_L^{\to}(E)\leq E_s}\mathcal{N}_Y((\mathcal{B}_X)_s)\\&=&\mathcal{C}_{\mathcal{B}_Y}(f_L^{\to}(E)),\end{eqnarray*}
这说明\hspace{0pt}\penalty0$f:(X,\mathcal{C}_{ \mathcal{B} _{ X } } )\to (Y,\mathcal{C}_{ \mathcal{B} _{ Y } } )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊保有界映射.

``充分性'':设\hspace{0pt}\penalty0$r\in P_{ X }$\nobreak\hspace{0pt}, 因
$$\mathcal{N}_X((\mathcal{B}_X)_r)=\mathcal{C}_{\mathcal{B}_X}(E_r)\leq\mathcal{C}_{\mathcal{B}_Y}(f_L^{\to}(E_r))=\bigvee_{f_L^{\to}(E_r)\leq E_s}\mathcal{N}_Y((\mathcal{B}_X)_s)=\bigvee_{s\in(P_Y)_r^f}\mathcal{N}_Y((\mathcal{B}_X)_s),$$
可得\hspace{0pt}\penalty0$f$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球保持映射.

\textbf{命题3.2.11.}  设\hspace{0pt}\penalty0$\mathcal{B} _{ P } =\left ( { X,P,\mathcal{B}_{ P } ,\mathcal{N}_{ P } } \right )$\penalty0\hspace{0pt}和\hspace{0pt}\penalty0$\mathcal{B} _{ Q } =\left ( { X,Q,\mathcal{B}_{ Q } ,\mathcal{N}_{ Q } } \right )$\penalty0\hspace{0pt}为上\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}的\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统, 则\hspace{0pt}\penalty0$\mathcal{B} _{ P } \prec \mathcal{B} _{ Q }$\penalty0\hspace{0pt}当且仅当\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} _{ P } } \le \mathcal{C}_{ \mathcal{B} _{ Q } }$\nobreak\hspace{0pt}.

\textbf{证明：} ``必要性'':因\hspace{0pt}\penalty0$\mathcal{B} _{ P } \prec \mathcal{B} _{ Q }$\nobreak\hspace{0pt}, 对任意\hspace{0pt}\penalty0$r\in P$\nobreak\hspace{0pt}, 有\hspace{0pt}\penalty0$\mathcal{N}_{ P } ((\mathcal{B}_{ P } )_{ r } )\le \bigvee_{ s\in Q_{ r } } \mathcal{N}_{ Q } ((\mathcal{B}_{ Q } )_{ s } )$\nobreak\hspace{0pt}. 对任意\hspace{0pt}\penalty0$E\in L ^ { X\times X }$\nobreak\hspace{0pt},
\begin{eqnarray*}\mathcal{C}_{\mathcal{B}_P}(E)&=&\bigvee_{E\leq F}\mathcal{S}_{\mathcal{B}_P}(F)=\bigvee_{E\leq E_r}\mathcal{S}_{\mathcal{B}_P}(E_r)\\&=&\bigvee_{E\leq E_r}\mathcal{N}_P(\mathcal{B}_r)\leq\bigvee_{E\leq E_r}\bigvee_{s\in Q_r}\mathcal{N}_Q(\mathcal{B}_s)\\&\leq&\bigvee_{E\leq E_s}\mathcal{S}_{\mathcal{B}_Q}(E_s)=\mathcal{C}_{\mathcal{B}_Q}(E),\end{eqnarray*}
这说明\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} _{ P } } \le \mathcal{C}_{ \mathcal{B} _{ Q } }$\nobreak\hspace{0pt}.

``充分性'':对于任意\hspace{0pt}\penalty0$r\in P$\nobreak\hspace{0pt}, 由\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} _{ P } } \le \mathcal{C}_{ \mathcal{B} _{ Q } }$\nobreak\hspace{0pt}, 得
\begin{eqnarray*}\mathcal{N}_P((\mathcal{B}_P)_r)&=&\mathcal{C}_{\mathcal{B}_P}(E_r)\leq\mathcal{C}_{\mathcal{B}_Q}(E_r)\\&=&\bigvee_{E_r\leq F}\mathcal{S}_{\mathcal{B}_Q}(F)=\bigvee_{E_r\leq E_s}\mathcal{S}_{\mathcal{B}_Q}(E_s)\\&=&\bigvee_{E_r\leq E_s}\mathcal{N}_Q((\mathcal{B}_Q)_s)=\bigvee_{s\in Q_r}\mathcal{N}_Q((\mathcal{B}_Q)_s),\end{eqnarray*}
这说明\hspace{0pt}\penalty0$\mathcal{B} _{ P } \prec \mathcal{B} _{ Q }$\nobreak\hspace{0pt}.

\textbf{推论3.2.12.}  设\hspace{0pt}\penalty0$\mathcal{B} _{ P } =\left ( { X,P,\mathcal{B}_{ P } ,\mathcal{N}_{ P } } \right )$\penalty0\hspace{0pt}和\hspace{0pt}\penalty0$\mathcal{B} _{ Q } =\left ( { X,Q,\mathcal{B}_{ Q } ,\mathcal{N}_{ Q } } \right )$\penalty0\hspace{0pt}为上\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}的\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统, 则\hspace{0pt}\penalty0$\mathcal{B} _{ P } \simeq \mathcal{B} _{ Q }$\penalty0\hspace{0pt}当且仅当\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} _{ P } } =\mathcal{C}_{ \mathcal{B} _{ Q } }$\nobreak\hspace{0pt}.

\textbf{定理3.2.13.}  设\hspace{0pt}\penalty0$\mathcal{B} =\left ( { X,P,\mathcal{B},\mathcal{N} } \right )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统, 则\hspace{0pt}\penalty0$\mathcal{B} _{ \mathcal{C}_{ \mathcal{B} } } \simeq \mathcal{B}$\nobreak\hspace{0pt}.

\textbf{证明：} 由定理3.2.9 ,我们有\hspace{0pt}\penalty0$\mathcal{C}_{\mathcal{B}_{\mathcal{C}_{\mathcal{B}}}}=\mathcal{C}_{\mathcal{B}}$\nobreak\hspace{0pt}. 故由推论3.2.12,可得\hspace{0pt}\penalty0$\mathcal{B} _{ \mathcal{C}_{ \mathcal{B} } } \simeq \mathcal{B}$\nobreak\hspace{0pt}.


\chapter{总\ \ 结}
\vspace{0.2cm}
在本文中, 我们提出了\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵结构、\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟粗结构、\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半粗结构和\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构的概念, 并从\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊关系方面给出了例子. 特别是我们通过\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球结构给出了\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统的定义, 并研究了\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统与\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵结构之间的相互刻画关系. 这为格值粗结构的研究提供了一个新的理论框架.
