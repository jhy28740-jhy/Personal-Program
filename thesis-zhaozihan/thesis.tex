\chapter{引\ \ 言}
\vspace{0.2cm}
在经典拓扑学的研究中, 研究者们长期聚焦于由拓扑定义的小尺度结构, 如邻域系统、连续性等, 度量空间中连续性的研究便是典型范例. 然而, 在定义度量空间上映射的连续性时, 度量本身蕴含的大量信息往往被忽略. 与经典拓扑学相对, 数学研究有时需关注其对偶情形, 即大尺度几何（亦称粗几何）. 粗几何这一学科现已与拓扑学、指标理论等建立了深刻联系\cite{ref1}. Roe在其专著中对粗几何进行了系统论述\cite{ref2}.

模糊集的概念由Zadeh首创, 在Zadeh的开创性论文中, 模糊集被视为一个函数\hspace{0pt}\penalty0$f:X\to \left ( { 0,1 } \right )$\nobreak\hspace{0pt}, 其值\hspace{0pt}\penalty0$f\left ( { x } \right )$\penalty0\hspace{0pt}通常解释为元素\hspace{0pt}\penalty0$x$\penalty0\hspace{0pt}属于该模糊集的确定程度\cite{ref3}. 众所周知, 模糊集理论已发展成为一个极为活跃的研究领域. 尽管粗几何理论在数学的诸多分支中扮演着重要角色, 但在Zarichnyi于2009年的工作之前\cite{ref4}, 粗几何从未在模糊背景下被系统研究. 据我们所知, 迄今为止关于模糊粗结构本身的研究并不多（近期一些论文探讨了模糊度量空间中的大尺度几何性质, 但其粗结构集本身仍是经典的）. 而且, 现有的模糊粗结构研究多基于单一格\hspace{0pt}\penalty0$L$\nobreak\hspace{0pt}, 这种单格框架在处理某些复杂的渐近行为或需要同时刻画不同层次的不确定性时可能会不够合适\cite{ref5}. 为更精细、更灵活地描述大尺度模糊结构, 亟需引入双格框架.

受严从华和王永超对粗结构模糊化工作的启发\cite{ref6}, 本文将引入\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构的概念, 并给出其等价刻画. 本文的结构如下：在第二节中, 我们列出一些完全分配格、模糊关系、单格模糊粗结构的基本概念与结果. 在第三节中, 我们给出\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构概念和\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗空间之间的态射, 并列举了\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构实例. 在第四节中, 我们引入\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球结构的概念, 并建立其与\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构之间的相互刻画关系.


\chapter{预备知识}
\vspace{0.2cm}
在本文中, 称一个非空集合\hspace{0pt}\penalty0$P$\penalty0\hspace{0pt}为一个偏序集, 如果它中的一个二元关系\hspace{0pt}\penalty0$\leq$\penalty0\hspace{0pt}满足自反性、反对称性和传递性. 称\hspace{0pt}\penalty0$P$\penalty0\hspace{0pt}的子集\hspace{0pt}\penalty0$D$\penalty0\hspace{0pt}为有向的, 如果它是非空的, 并且\hspace{0pt}\penalty0$D$\penalty0\hspace{0pt}的每个有限子集在\hspace{0pt}\penalty0$D$\penalty0\hspace{0pt}中都有上界\cite{ref7}.

本文中, \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}和\hspace{0pt}\penalty0$M$\penalty0\hspace{0pt}都是完全分配格, 它们的最大元记为\hspace{0pt}\penalty0$~\top$\nobreak\hspace{0pt}, 最小元记为\hspace{0pt}\penalty0$\bot$\nobreak\hspace{0pt}. \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}上的一个二元关系\hspace{0pt}\penalty0$\prec$\penalty0\hspace{0pt}定义为, 对\hspace{0pt}\penalty0$\forall a,b\in L$\nobreak\hspace{0pt},\hspace{0pt}\penalty0$a\prec b$\penalty0\hspace{0pt}当且仅当对\hspace{0pt}\penalty0$\forall M\subseteq L$\nobreak\hspace{0pt},\hspace{0pt}\penalty0$b\le \vee M$\nobreak\hspace{0pt}, 存在一个\hspace{0pt}\penalty0$d\in M$\nobreak\hspace{0pt}, 使得\hspace{0pt}\penalty0$a\le d$\nobreak\hspace{0pt}. 映射\hspace{0pt}\penalty0$\beta :L\to 2 ^ { L }$\penalty0\hspace{0pt}定义为\hspace{0pt}\penalty0$\beta(a)=\{b\in L:b\prec a\}$\nobreak\hspace{0pt}, 且满足对\hspace{0pt}\penalty0$\forall \left \{ \begin{array}{l} a_{ i } \end{array} \right \}_{ i\in I } \subseteq L$\nobreak\hspace{0pt},\hspace{0pt}\penalty0$\beta\left(\bigvee_{i\in I}a_i\right)=\bigcup_{i\in I}\beta(a_i)$\penalty0\hspace{0pt}\cite{ref7}.

\textbf{定义2.1}\cite{ref8}  \hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}上的一个非空子集\hspace{0pt}\penalty0$\mathcal{C}\subseteq L ^ { X\times X }$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵,如果它满足以下性质：

（E1）\hspace{0pt}\penalty0$\Delta _{ X } \in \mathcal{C}$\nobreak\hspace{0pt}；

（E2）如果\hspace{0pt}\penalty0$E\in \mathcal{C}$\nobreak\hspace{0pt},且\hspace{0pt}\penalty0$D\le E$\nobreak\hspace{0pt},则\hspace{0pt}\penalty0$D\in \mathcal{C}$\nobreak\hspace{0pt}；

（E3）\hspace{0pt}\penalty0$\forall E,F\in \mathcal{C}$\nobreak\hspace{0pt},则\hspace{0pt}\penalty0$E\vee F\in \mathcal{C}$\nobreak\hspace{0pt}；

一个\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵\hspace{0pt}\penalty0$\mathcal{C}\subseteq L ^ { X\times X }$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-拟粗结构,如果它又满足（E4）：

（E4）\hspace{0pt}\penalty0$\forall E,F\in \mathcal{C}$\nobreak\hspace{0pt},则\hspace{0pt}\penalty0$E\circ F\in \mathcal{C}$\nobreak\hspace{0pt}；

一个\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵\hspace{0pt}\penalty0$\mathcal{C}\subseteq L ^ { X\times X }$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-半粗结构,如果它又满足（E5）：

（E5）\hspace{0pt}\penalty0$\forall E\in \mathcal{C}$\nobreak\hspace{0pt},则\hspace{0pt}\penalty0$E ^ { -1 } \in \mathcal{C}$\nobreak\hspace{0pt}.

此外, 一个\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵\hspace{0pt}\penalty0$\mathcal{C}\subseteq L ^ { X\times X }$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-粗结构, 如果它既是\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-拟粗结构, 又是\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-半粗结构.相应地, \hspace{0pt}\penalty0$\left ( { X,\mathcal{C} } \right )$\penalty0\hspace{0pt}又分别称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵空间, \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-拟粗空间, \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-半粗空间, \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-粗空间\cite{ref7}.

\textbf{定义2.2}\cite{ref8}对集合\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}及\hspace{0pt}\penalty0$\forall E,E_{ 1 } ,E_{ 2 } \subseteq X\times X$\nobreak\hspace{0pt}, 我们定义

\begin{center}

\end{center}
\begin{center}
\noindent \hspace{0pt}\penalty0$E_{ 1 } \circ E_{ 2 } =\left \{ \begin{array}{l} \left ( { x,y } \right )\in X\times X:\exists z\in X,\left ( { x,z } \right )\in E_{ 1 } ,\left ( { z,y } \right )\in E_{ 2 } \end{array} \right \}$\nobreak\hspace{0pt}.

对于上述运算，其单位元是\hspace{0pt}\penalty0$\Delta _{ X } \in L ^ { X\times X }$\nobreak\hspace{0pt}，定义为

\begin{center}
\noindent \hspace{0pt}\penalty0$\Delta_X(x,y)=\begin{cases}\top,&x=y,\\ \bot,&x\ne y,\end{cases}$\nobreak\hspace{0pt}. \cite{ref7}
\end{center}
\textbf{定义2.}\textbf{3}\cite{ref9}\textbf{  }映射\hspace{0pt}\penalty0$R:X\times X\to M$\penalty0\hspace{0pt}是\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}上一个\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊关系, 称为：

一个满足自反、对称和传递的\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊关系\hspace{0pt}\penalty0$R$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊等价关系, 如果\hspace{0pt}\penalty0$R:X\times X\to M$\penalty0\hspace{0pt}是\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}上一个\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊关系, 则称\hspace{0pt}\penalty0$\left ( { X,R } \right )$\penalty0\hspace{0pt}为\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊关系空间\cite{ref9}.

\textbf{定义3.1}  集合\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}上的一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵结构是一个映射\hspace{0pt}\penalty0$\mathcal{C}$\penalty0\hspace{0pt}\hspace{0pt}\penalty0$:L ^ { X\times X } \to M$\penalty0\hspace{0pt}满足以下条件：

（ME1）\hspace{0pt}\penalty0$\mathcal{C}\left ( { \Delta _{ X } } \right )=\top$\nobreak\hspace{0pt}；

（ME2）\hspace{0pt}\penalty0$\forall E,F\in L ^ { X\times X }$\nobreak\hspace{0pt}, 且\hspace{0pt}\penalty0$E\le F$\nobreak\hspace{0pt},则\hspace{0pt}\penalty0$\mathcal{C}\left ( { F } \right )\le \mathcal{C}\left ( { E } \right )$\nobreak\hspace{0pt}；

（ME3）\hspace{0pt}\penalty0$\forall E,F\in L ^ { X\times X }$\nobreak\hspace{0pt}, 则\hspace{0pt}\penalty0$\mathcal{C}\left ( { E } \right )\wedge \mathcal{C}\left ( { F } \right )\le \mathcal{C}\left ( { E\vee F } \right )$\nobreak\hspace{0pt}；

\quad 一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵结构\hspace{0pt}\penalty0$\mathcal{C}$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟粗结构, 若它又满足（ME4）：

（ME4）\hspace{0pt}\penalty0$\forall E,F\in L^{X\times X}$\nobreak\hspace{0pt}, 则\hspace{0pt}\penalty0$\mathcal{C}\left ( { E } \right )\wedge \mathcal{C}\left ( { F } \right )\le \mathcal{C}\left ( { E\circ F } \right )$\nobreak\hspace{0pt}；

\quad 一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵结构\hspace{0pt}\penalty0$\mathcal{C}$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半粗结构, 若它又满足（ME5）：

（ME5）\hspace{0pt}\penalty0$\forall E\in L^{X\times X}$\nobreak\hspace{0pt}, 则\hspace{0pt}\penalty0$\mathcal{C}\left ( { E } \right )=\mathcal{C}\left ( { E ^ { -1 } } \right )$\nobreak\hspace{0pt}.

若一个\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊熵结构\hspace{0pt}\penalty0$\mathcal{C}$\penalty0\hspace{0pt}既是\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊半粗结构, 又是\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊拟粗结构, 则称为\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊粗结构. 相应地, \hspace{0pt}\penalty0$\left ( { X,\mathcal{C} } \right )$\penalty0\hspace{0pt}分别称为\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊熵空间, \hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊半粗空间, \hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊拟粗空间, \hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊粗空间.

这说明\hspace{0pt}\penalty0$f$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球保持映射.

``充分性'': 对\hspace{0pt}\penalty0$\forall E\in P_{ X }$\penalty0\hspace{0pt}及\hspace{0pt}\penalty0$\forall x,y\in X$\nobreak\hspace{0pt}, 若\hspace{0pt}\penalty0$F\in (P_{ Y } )_{ E } ^{ f }$\nobreak\hspace{0pt}, 则\hspace{0pt}\penalty0$E(x,y)\le F(f(x),f(y))$\nobreak\hspace{0pt}, 即\hspace{0pt}\penalty0$f_{ L } ^{ \to }(E)\le F$\nobreak\hspace{0pt}. 于是\hspace{0pt}\penalty0$\mathcal{C}_{ X } \left ( { E } \right )=\mathcal{N}_{ \mathcal{C}_{ X } } \left ( { \left ( { \mathcal{B}_{ \mathcal{C}_{ X } } } \right )_{ E } } \right )\le \bigvee_{ F\in (P_{ Y } )_{ E } ^{ f } } \mathcal{N}_{ \mathcal{C}_{ Y } } \left ( { \left ( { \mathcal{B}_{ \mathcal{C}_{ Y } } } \right )_{ F } } \right )=\mathcal{N}_{ \mathcal{C}_{ Y } } \left ( { \left ( { \mathcal{B}_{ \mathcal{C}_{ Y } } } \right )_{ f_{ L } ^{ \to }(E) } } \right )=\mathcal{C}_{ Y } \left ( { f_{ L } ^{ \to }(E) } \right )$\nobreak\hspace{0pt}, 故\hspace{0pt}\penalty0$f$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊保有界映射.

命题4.6 说明了一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构可以诱导生成一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球空间. 接下来, 我们从一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球空间构造出一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构.

\textbf{命题4}\textbf{.8  }设\hspace{0pt}\penalty0$\mathcal{B} =\left ( { X,P,\mathcal{B},\mathcal{N} } \right )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统, \hspace{0pt}\penalty0$\forall r\in P$\nobreak\hspace{0pt}, 定义映射\hspace{0pt}\penalty0$E_{ r } :X\times X\to L$\penalty0\hspace{0pt}为：\hspace{0pt}\penalty0$\forall x,y\in X$\nobreak\hspace{0pt},\hspace{0pt}\penalty0$E_{ r } \left ( { x,y } \right )=\mathcal{B}_{ r } \left ( { x,y } \right )$\nobreak\hspace{0pt}. 显然有\hspace{0pt}\penalty0$\mathcal{E}=\left \{ \begin{array}{l} E_{ r } :r\in P \end{array} \right \}\subset L ^ { X\times X }$\nobreak\hspace{0pt}. 定义映射\hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} } :L ^ { X\times X } \to M$\penalty0\hspace{0pt}为

\begin{center}
\noindent \hspace{0pt}\penalty0$\forall E\in L^{X\times X}$\nobreak\hspace{0pt}, \hspace{0pt}\penalty0$\mathcal{S}_{\mathcal{B}}(E)=\begin{cases}N(\mathcal{B}_r),&E=E_r\in\mathcal{E};\\\bot,&E\notin\mathcal{E}.\end{cases}$\penalty0\hspace{0pt}
\end{center}
则\hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵结构的基, 它生成的\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵结构记为\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} }$\nobreak\hspace{0pt}. 此外,

（1）若\hspace{0pt}\penalty0$\mathcal{B}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半球空间, 则\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半粗结构；

（2）若\hspace{0pt}\penalty0$\mathcal{B}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟球空间, 则\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟粗结构；

（3）若\hspace{0pt}\penalty0$\mathcal{B}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球空间, 则\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构.

证明 （B1）\hspace{0pt}\penalty0$\forall r\in P$\nobreak\hspace{0pt}, \hspace{0pt}\penalty0$\forall x\in X$\nobreak\hspace{0pt}, 由\hspace{0pt}\penalty0$E_{ r } \left ( { x,x } \right )=\mathcal{B}_{ r } \left ( { x,x } \right )=\top =\Delta _{ X } \left ( { x,x } \right )$\nobreak\hspace{0pt}, 得\hspace{0pt}\penalty0$\bigvee_{ \Delta _{ X } \le E_{ r } } \mathcal{N}_{ \mathcal{B} } \left ( { E_{ r } } \right )=$\penalty0\hspace{0pt}

\hspace{0pt}\penalty0$\bigvee_{ \Delta _{ X } \le B_{ r } } \mathcal{N}\left ( { \mathcal{B}_{ r } } \right )=\top$\nobreak\hspace{0pt}.

（B2）\hspace{0pt}\penalty0$\forall E_{ r } ,E_{ s } \in L ^ { X\times X }$\nobreak\hspace{0pt}, 有

\begin{center}
\noindent \hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} } \left ( { E_{ r } } \right )\wedge \mathcal{S}_{ \mathcal{B} } \left ( { E_{ s } } \right )=\mathcal{N}\left ( { \mathcal{B}_{ r } } \right )\wedge \mathcal{N}\left ( { \mathcal{B}_{ s } } \right )\le \mathcal{N}\left ( { \mathcal{B}_{ r } \vee \mathcal{B}_{ s } } \right )\le \bigvee_{ \mathcal{B}_{ r } \vee \mathcal{B}_{ s } \le \mathcal{B}_{ t } } \mathcal{N}\left ( { \mathcal{B}_{ t } } \right )=\bigvee_{ E_{ r } \vee E_{ s } \le E_{ t } } \mathcal{S}_{ \mathcal{B} } \left ( { E_{ t } } \right )\le \bigvee_{ E_{ r } \vee E_{ s } \le E } \mathcal{S}_{ \mathcal{B} } \left ( { E } \right )$\nobreak\hspace{0pt},
\end{center}
故\hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵结构的基.

（1）若\hspace{0pt}\penalty0$\mathcal{B}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半球空间, 则\hspace{0pt}\penalty0$\forall r\in P$\nobreak\hspace{0pt}, 有

\begin{center}
\noindent \hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} } \left ( { E_{ r } } \right )=\mathcal{N}\left ( { \mathcal{B}_{ r } } \right )=\mathcal{N}\left ( { \mathcal{B}_{ r } ^ { * } } \right )=\mathcal{S}_{ \mathcal{B} } \left ( { E_{ r } ^ { -1 } } \right )\le \bigvee_{ E_{ r } ^ { -1 } \le E_{ t } } \mathcal{S}_{ \mathcal{B} } \left ( { E_{ t } } \right )\le \bigvee_{ E_{ r } ^ { -1 } \le E } \mathcal{S}_{ \mathcal{B} } \left ( { E } \right )$\nobreak\hspace{0pt},
\end{center}
故\hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半粗结构的基, \hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半粗结构.

（2）若\hspace{0pt}\penalty0$\mathcal{B}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟球空间, 则\hspace{0pt}\penalty0$\forall r,s\in P$\nobreak\hspace{0pt}, 有

\begin{center}
\noindent \resizebox{\linewidth}{!}{$\displaystyle \mathcal{S}_{ \mathcal{B} } \left ( { E_{ r } } \right )\wedge \mathcal{S}_{ \mathcal{B} } \left ( { E_{ s } } \right )=\mathcal{N}\left ( { \mathcal{B}_{ r } } \right )\wedge \mathcal{N}\left ( { \mathcal{B}_{ s } } \right )\le \mathcal{N}\left ( { \mathcal{B}_{ r } \vee \mathcal{B}_{ s } } \right )\le \mathcal{N}\left ( { \mathcal{B}_{ r } \circ \mathcal{B}_{ s } } \right )\le \bigvee_{ \mathcal{B}_{ r } \circ \mathcal{B}_{ s } \le \mathcal{B}_{ t } } \mathcal{N}\left ( { \mathcal{B}_{ t } } \right )=\bigvee_{ E_{ r } \circ E_{ s } \le E_{ t } } \mathcal{S}_{ \mathcal{B} } \left ( { E_{ t } } \right )\le \bigvee_{ E_{ r } \circ E_{ s } \le E } \mathcal{S}_{ \mathcal{B} } \left ( { E } \right )$},
\end{center}
故\hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟粗结构的基, \hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟粗结构.

（3）若\hspace{0pt}\penalty0$\mathcal{B}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球空间, 则显然\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构.

\textbf{定理4}\textbf{.9  }设\hspace{0pt}\penalty0$\left ( { X,\mathcal{C} } \right )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵空间, 则\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} _{ \mathcal{C} } } =\mathcal{C}$\nobreak\hspace{0pt}.

证明 设\hspace{0pt}\penalty0$E\in L ^ { X\times X }$\nobreak\hspace{0pt}, 则\hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} _{ \mathcal{C} } } \left ( { F } \right )=\mathcal{N}_{ \mathcal{C} } \left ( { \mathcal{B}_{ F } } \right )=\mathcal{C}\left ( { F } \right )$\nobreak\hspace{0pt}. 于是对任意\hspace{0pt}\penalty0$E\in L ^ { X\times X }$\nobreak\hspace{0pt}, 有

\begin{center}
\noindent \hspace{0pt}\penalty0$\mathcal{B} _{ \mathcal{C} } \left ( { E } \right )=\bigvee_{ E\le F } \mathcal{S}_{ \mathcal{B} _{ \mathcal{C} } } \left ( { F } \right )=\bigvee_{ E\le F } \mathcal{C}\left ( { F } \right )=\mathcal{C}\left ( { E } \right )$\nobreak\hspace{0pt},
\end{center}
故\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} _{ \mathcal{C} } } =\mathcal{C}$\nobreak\hspace{0pt}.

\textbf{命题4}\textbf{.10  }设\hspace{0pt}\penalty0$\mathcal{B} _{ X } =\left ( { X,P,\mathcal{B}_{ X } ,\mathcal{N}_{ X } } \right )$\penalty0\hspace{0pt}和\hspace{0pt}\penalty0$\mathcal{B} _{ Y } =\left ( { Y,Q,\mathcal{B}_{ Y } ,\mathcal{N}_{ Y } } \right )$\penalty0\hspace{0pt}是\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统, 则\hspace{0pt}\penalty0$f:X\to Y$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球保持映射当且仅当\hspace{0pt}\penalty0$f:(X,\mathcal{C}_{ \mathcal{B} _{ X } } )\to (Y,\mathcal{C}_{ \mathcal{B} _{ Y } } )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊保有界映射.

证明 ``必要性'':对任意\hspace{0pt}\penalty0$E\in L ^ { X\times X }$\nobreak\hspace{0pt}, 有

\begin{center}
\noindent \hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} _{ X } } (E)=\bigvee_{ E\le F } \mathcal{S}_{ \mathcal{B} _{ X } } (E)=\bigvee_{ E\le E_{ r } } \mathcal{N}_{ X } ((\mathcal{B}_{ X } )_{ r } )\le \bigvee_{ f_{ L } ^{ \to }(E)\le f_{ L } ^{ \to }(E_{ r } ) } \bigvee_{ s\in (P_{ Y } )_{ r } ^{ f } } \mathcal{N}_{ Y } ((\mathcal{B}_{ X } )_{ s } )\le \bigvee_{ f_{ L } ^{ \to }(E)\le E_{ s } } \mathcal{N}_{ Y } ((\mathcal{B}_{ X } )_{ s } )=\mathcal{C}_{ \mathcal{B} _{ Y } } (f_{ L } ^{ \to }(E))$\nobreak\hspace{0pt},
\end{center}
这说明\hspace{0pt}\penalty0$f:(X,\mathcal{C}_{ \mathcal{B} _{ X } } )\to (Y,\mathcal{C}_{ \mathcal{B} _{ Y } } )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊保有界映射.

``充分性'':设\hspace{0pt}\penalty0$r\in P_{ X }$\nobreak\hspace{0pt}, 因

\begin{center}
\noindent \hspace{0pt}\penalty0$\mathcal{N}_{ X } ((\mathcal{B}_{ X } )_{ r } )=\mathcal{C}_{ \mathcal{B} _{ X } } (E_{ r } )\le \mathcal{C}_{ \mathcal{B} _{ Y } } (f_{ L } ^{ \to }(E_{ r } ))=\bigvee_{ f_{ L } ^{ \to }(E_{ r } )\le E_{ s } } \mathcal{N}_{ Y } ((\mathcal{B}_{ X } )_{ s } )=\bigvee_{ s\in (P_{ Y } )_{ r } ^{ f } } \mathcal{N}_{ Y } ((\mathcal{B}_{ X } )_{ s } )$\nobreak\hspace{0pt},
\end{center}
可得\hspace{0pt}\penalty0$f$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球保持映射.

\textbf{命题4}\textbf{.11  }设\hspace{0pt}\penalty0$\mathcal{B} _{ P } =\left ( { X,P,\mathcal{B}_{ P } ,\mathcal{N}_{ P } } \right )$\penalty0\hspace{0pt}和\hspace{0pt}\penalty0$\mathcal{B} _{ Q } =\left ( { X,Q,\mathcal{B}_{ Q } ,\mathcal{N}_{ Q } } \right )$\penalty0\hspace{0pt}为上\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}的\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统, 则\hspace{0pt}\penalty0$\mathcal{B} _{ P } \prec \mathcal{B} _{ Q }$\penalty0\hspace{0pt}当且仅当\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} _{ P } } \le \mathcal{C}_{ \mathcal{B} _{ Q } }$\nobreak\hspace{0pt}.

证明 ``必要性'':因\hspace{0pt}\penalty0$\mathcal{B} _{ P } \prec \mathcal{B} _{ Q }$\nobreak\hspace{0pt}, 对任意\hspace{0pt}\penalty0$r\in P$\nobreak\hspace{0pt}, 有\hspace{0pt}\penalty0$\mathcal{N}_{ P } ((\mathcal{B}_{ P } )_{ r } )\le \bigvee_{ s\in Q_{ r } } \mathcal{N}_{ Q } ((\mathcal{B}_{ Q } )_{ s } )$\nobreak\hspace{0pt}. 对任意\hspace{0pt}\penalty0$E\in L ^ { X\times X }$\nobreak\hspace{0pt},

\begin{center}
\noindent \hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} _{ P } } \left ( { E } \right )=\bigvee_{ E\le F } \mathcal{S}_{ \mathcal{B} _{ P } } \left ( { F } \right )=\bigvee_{ E\le E_{ r } } \mathcal{S}_{ \mathcal{B} _{ P } } \left ( { E_{ r } } \right )=\bigvee_{ E\le E_{ r } } \mathcal{N}_{ P } \left ( { \mathcal{B}_{ r } } \right )\le \bigvee_{ E\le E_{ r } } \bigvee_{ s\in Q_{ r } } \mathcal{N}_{ Q } \left ( { \mathcal{B}_{ s } } \right )\le \bigvee_{ E\le E_{ s } } \mathcal{S}_{ \mathcal{B} _{ Q } } \left ( { E_{ s } } \right )=\mathcal{C}_{ \mathcal{B} _{ Q } } \left ( { E } \right )$\nobreak\hspace{0pt},
\end{center}
这说明\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} _{ P } } \le \mathcal{C}_{ \mathcal{B} _{ Q } }$\nobreak\hspace{0pt}.

``充分性'':对于任意\hspace{0pt}\penalty0$r\in P$\nobreak\hspace{0pt}, 由\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} _{ P } } \le \mathcal{C}_{ \mathcal{B} _{ Q } }$\nobreak\hspace{0pt}, 得

\begin{center}
\noindent \hspace{0pt}\penalty0$\mathcal{N}_{ P } \left ( { \left ( { \mathcal{B}_{ P } } \right )_{ r } } \right )=\mathcal{C}_{ \mathcal{B} _{ P } } \left ( { E_{ r } } \right )\le \mathcal{C}_{ \mathcal{B} _{ Q } } \left ( { E_{ r } } \right )=\bigvee_{ E_{ r } \le F } \mathcal{S}_{ \mathcal{B} _{ Q } } \left ( { F } \right )=\bigvee_{ E_{ r } \le E_{ s } } \mathcal{S}_{ \mathcal{B} _{ Q } } \left ( { E_{ s } } \right )=\bigvee_{ E_{ r } \le E_{ s } } \mathcal{N}_{ Q } ((\mathcal{B}_{ Q } )_{ s } )=\bigvee_{ s\in Q_{ r } } \mathcal{N}_{ Q } ((\mathcal{B}_{ Q } )_{ s } )$\nobreak\hspace{0pt},
\end{center}
这说明\hspace{0pt}\penalty0$\mathcal{B} _{ P } \prec \mathcal{B} _{ Q }$\nobreak\hspace{0pt}.

\textbf{推论4}\textbf{.12  }设\hspace{0pt}\penalty0$\mathcal{B} _{ P } =\left ( { X,P,\mathcal{B}_{ P } ,\mathcal{N}_{ P } } \right )$\penalty0\hspace{0pt}和\hspace{0pt}\penalty0$\mathcal{B} _{ Q } =\left ( { X,Q,\mathcal{B}_{ Q } ,\mathcal{N}_{ Q } } \right )$\penalty0\hspace{0pt}为上\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}的\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统, 则\hspace{0pt}\penalty0$\mathcal{B} _{ P } \simeq \mathcal{B} _{ Q }$\penalty0\hspace{0pt}当且仅当\hspace{0pt}\penalty0$\mathcal{C}_{ \mathcal{B} _{ P } } =\mathcal{C}_{ \mathcal{B} _{ Q } }$\nobreak\hspace{0pt}.

\textbf{定理4}\textbf{.1}\textbf{3  }设\hspace{0pt}\penalty0$\mathcal{B} =\left ( { X,P,\mathcal{B},\mathcal{N} } \right )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统, 则\hspace{0pt}\penalty0$\mathcal{B} _{ \mathcal{C}_{ \mathcal{B} } } \simeq \mathcal{B}$\nobreak\hspace{0pt}.

证明 由定理4.9,我们有\hspace{0pt}\penalty0$\mathcal{C}_{\mathcal{B}_{\mathcal{C}_{\mathcal{B}}}}=\mathcal{C}_{\mathcal{B}}$\nobreak\hspace{0pt}. 故由推论4.12,可得\hspace{0pt}\penalty0$\mathcal{B} _{ \mathcal{C}_{ \mathcal{B} } } \simeq \mathcal{B}$\nobreak\hspace{0pt}.
