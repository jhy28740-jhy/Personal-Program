\vspace{0.3cm}{\Large\bf Research on $(L,M)$-Fuzzy Coarse Structures and Related Theories}
\end{center}
\begin{center}
\vspace{0.2cm} {\large \bf Abstract}
\end{center}
\zihao{-4}

This thesis studies double lattice-valued fuzzy coarse structures over completely distributive lattices $L$ and $M$. It introduces $(L,M)$-fuzzy entourage, quasi-coarse, semi-coarse and coarse structures, investigates mappings between the corresponding spaces, and characterizes them by $(L,M)$-fuzzy ball structures. It then defines lattice-valued fuzzifying coarse groups and group ideals and establishes their correspondence. Finally, it studies $(L,M)$-fuzzy coarse proximities, the induced fuzzy neighborhood systems, and their relation to pseudo $(L,M)$-fuzzy asymptotic similarities and fuzzy coarse structures.

\vspace{0.3cm}
{\large\bf Keywords:}\,
$(L,M)$-fuzzy coarse structure; fuzzy ball structure; lattice-valued fuzzifying coarse group; group ideal; coarse proximity

\chapter{绪\ \论}

\section{研究背景}
\vspace{0.2cm}
经典拓扑学主要研究邻域、连续性等局部性质, 与之相对的粗几何则关注空间在大尺度下的渐近结构. Roe对粗空间及粗几何进行了系统研究, 相关理论已经与拓扑学、指标理论和几何群论建立了紧密联系\cite{ref1,ref2,ref3}. 在群这一基本代数对象上, Protasov等人以及Nicas和Rosenthal研究了与群运算相容的粗结构, 并揭示了粗群与群理想之间的对应关系\cite{ref4,ref5}.

Zadeh提出的模糊集理论为刻画不确定性和渐进性提供了基本工具\cite{ref6}. Zarichnyi将粗结构与模糊度量联系起来, 推动了粗几何在模糊环境中的研究\cite{ref7}; 此后, 模糊度量空间的大尺度性质得到进一步讨论\cite{ref8}. 严从华提出幂集上的$(L,*)$-值粗结构\cite{ref9}, 王永超、庞斌和史福贵进一步发展了格值粗结构理论\cite{ref10}. 这些工作表明, 以完全分配格为值域能够更细致地反映粗结构的隶属程度, 也为在双格值框架下同时描述对象层与结构层的不确定性提供了基础. 完全分配格及其远低关系等基本理论可参见文献\cite{ref11}, 格值模糊粗糙近似方面的相关研究可参见文献\cite{ref12}.

\section{研究意义}
\vspace{0.2cm}
现有模糊粗结构研究多集中在单格值框架, 对结构的对象隶属程度与成立程度缺少分层描述. 引入$(L,M)$-模糊粗结构, 可以分别利用格$L$与格$M$刻画模糊关系和粗结构程度, 从而为大尺度模糊结构提供更灵活的统一模型. 在这一框架下进一步研究模糊球结构、粗群、群理想和粗邻近, 一方面能够检验$(L,M)$-模糊粗结构对不同数学对象的适应性, 另一方面能够建立几何、代数与邻近关系之间的联系, 为格值粗几何及模糊拓扑相关理论的后续研究提供基础.

\section{研究内容}
\vspace{0.2cm}
本文围绕$(L,M)$-模糊粗结构及其相关理论展开. 第二章介绍完全分配格、模糊关系、模糊伪度量和格值模糊化粗结构等预备知识. 第三章给出$(L,M)$-模糊熵结构、拟粗结构、半粗结构和粗结构的定义, 研究相应空间之间的映射, 并通过$(L,M)$-模糊球结构建立等价刻画. 第四章把群运算引入格值模糊化粗结构, 研究格值模糊化粗群及其与KM-模糊伪度量的关系, 随后引入格值模糊化群理想并证明其与左、右格值模糊化粗群之间的对应关系. 第五章研究$(L,M)$-模糊粗邻近, 讨论其诱导的模糊邻域系统, 并进一步研究伪$(L,M)$-模糊渐近相似性与$(L,M)$-模糊粗结构之间的构造关系.

\chapter{预备知识}

\section{格论,模糊集的相关知识}
\vspace{0.2cm}
在本文中, 称一个非空集合\hspace{0pt}\penalty0$P$\penalty0\hspace{0pt}为一个偏序集, 如果它中的一个二元关系\hspace{0pt}\penalty0$\leq$\penalty0\hspace{0pt}满足自反性、反对称性和传递性. 称\hspace{0pt}\penalty0$P$\penalty0\hspace{0pt}的子集\hspace{0pt}\penalty0$D$\penalty0\hspace{0pt}为有向的, 如果它是非空的, 并且\hspace{0pt}\penalty0$D$\penalty0\hspace{0pt}的每个有限子集在\hspace{0pt}\penalty0$D$\penalty0\hspace{0pt}中都有上界\cite{ref11}.

本文中, \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}和\hspace{0pt}\penalty0$M$\penalty0\hspace{0pt}都是完全分配格, 它们的最大元记为\hspace{0pt}\penalty0$~\top$\nobreak\hspace{0pt}, 最小元记为\hspace{0pt}\penalty0$\bot$\nobreak\hspace{0pt}. \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}上的一个二元关系\hspace{0pt}\penalty0$\prec$\penalty0\hspace{0pt}定义为, 对\hspace{0pt}\penalty0$\forall a,b\in L$\nobreak\hspace{0pt},\hspace{0pt}\penalty0$a\prec b$\penalty0\hspace{0pt}当且仅当对\hspace{0pt}\penalty0$\forall M\subseteq L$\nobreak\hspace{0pt},\hspace{0pt}\penalty0$b\le \vee M$\nobreak\hspace{0pt}, 存在一个\hspace{0pt}\penalty0$d\in M$\nobreak\hspace{0pt}, 使得\hspace{0pt}\penalty0$a\le d$\nobreak\hspace{0pt}. 映射\hspace{0pt}\penalty0$\beta :L\to 2 ^ { L }$\penalty0\hspace{0pt}定义为\hspace{0pt}\penalty0$\beta(a)=\{b\in L:b\prec a\}$\nobreak\hspace{0pt}, 且满足对\hspace{0pt}\penalty0$\forall \left \{ \begin{array}{l} a_{ i } \end{array} \right \}_{ i\in I } \subseteq L$\nobreak\hspace{0pt},\hspace{0pt}\penalty0$\beta\left(\bigvee_{i\in I}a_i\right)=\bigcup_{i\in I}\beta(a_i)$\penalty0\hspace{0pt}\cite{ref11}.

\textbf{定义2.1.1.}  \hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}上的一个非空子集\hspace{0pt}\penalty0$\mathcal{C}\subseteq L ^ { X\times X }$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵,如果它满足以下性质：

（E1）\hspace{0pt}\penalty0$\Delta _{ X } \in \mathcal{C}$\nobreak\hspace{0pt}；

（E2）如果\hspace{0pt}\penalty0$E\in \mathcal{C}$\nobreak\hspace{0pt},且\hspace{0pt}\penalty0$D\le E$\nobreak\hspace{0pt},则\hspace{0pt}\penalty0$D\in \mathcal{C}$\nobreak\hspace{0pt}；

（E3）\hspace{0pt}\penalty0$\forall E,F\in \mathcal{C}$\nobreak\hspace{0pt},则\hspace{0pt}\penalty0$E\vee F\in \mathcal{C}$\nobreak\hspace{0pt}；

一个\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵\hspace{0pt}\penalty0$\mathcal{C}\subseteq L ^ { X\times X }$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-拟粗结构,如果它又满足（E4）：

（E4）\hspace{0pt}\penalty0$\forall E,F\in \mathcal{C}$\nobreak\hspace{0pt},则\hspace{0pt}\penalty0$E\circ F\in \mathcal{C}$\nobreak\hspace{0pt}；

一个\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵\hspace{0pt}\penalty0$\mathcal{C}\subseteq L ^ { X\times X }$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-半粗结构,如果它又满足（E5）：

（E5）\hspace{0pt}\penalty0$\forall E\in \mathcal{C}$\nobreak\hspace{0pt},则\hspace{0pt}\penalty0$E ^ { -1 } \in \mathcal{C}$\nobreak\hspace{0pt}.

此外, 一个\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵\hspace{0pt}\penalty0$\mathcal{C}\subseteq L ^ { X\times X }$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-粗结构, 如果它既是\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-拟粗结构, 又是\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-半粗结构.相应地, \hspace{0pt}\penalty0$\left ( { X,\mathcal{C} } \right )$\penalty0\hspace{0pt}又分别称为\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-熵空间, \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-拟粗空间, \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-半粗空间, \hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-粗空间\cite{ref11}.

\textbf{定义2.1.2}  对集合\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}及\hspace{0pt}\penalty0$\forall E,E_{ 1 } ,E_{ 2 } \subseteq X\times X$\nobreak\hspace{0pt}, 我们定义
$$E^{-1}=\{(y,x)\in X\times X:(x,y)\in E\},$$
$$E_{ 1 } \circ E_{ 2 } =\left \{ \begin{array}{l} \left ( { x,y } \right )\in X\times X:\exists z\in X,\left ( { x,z } \right )\in E_{ 1 } ,\left ( { z,y } \right )\in E_{ 2 } \end{array} \right \}.$$
对于上述运算，其单位元是\hspace{0pt}\penalty0$\Delta _{ X } \in L ^ { X\times X }$\nobreak\hspace{0pt}，定义为
$$\Delta_X(x,y)=\begin{cases}\top,&x=y,\\ \bot,&x\ne y,\end{cases}. \text{\cite{ref11}}$$
\textbf{定义2.1.3}  映射\hspace{0pt}\penalty0$R:X\times X\to M$\penalty0\hspace{0pt}是\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}上一个\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊关系, 称为：

（1）自反: \hspace{0pt}\penalty0$R\left ( { x,x } \right )=\top$\nobreak\hspace{0pt}；

（2）对称: \hspace{0pt}\penalty0$R\left ( { x,y } \right )=R\left ( { y,x } \right )$\nobreak\hspace{0pt}；

（3）传递: \hspace{0pt}\penalty0$R\circ R\le R$\nobreak\hspace{0pt}, 其中\hspace{0pt}\penalty0$R\circ R(x,y)=\bigvee_{ z\in X } R(x,z)\wedge R(z,y)$\nobreak\hspace{0pt}.

一个满足自反、对称和传递的\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊关系\hspace{0pt}\penalty0$R$\penalty0\hspace{0pt}称为\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊等价关系, 如果\hspace{0pt}\penalty0$R:X\times X\to M$\penalty0\hspace{0pt}是\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}上一个\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊关系, 则称\hspace{0pt}\penalty0$\left ( { X,R } \right )$\penalty0\hspace{0pt}为\hspace{0pt}\penalty0$\left ( { L,M } \right )$\penalty0\hspace{0pt}-模糊关系空间\cite{ref12}.



\section{格值模糊化粗群的相关知识}
\vspace{0.2cm}
在本文中,称一个非空集合\hspace{0pt}$P$为一个偏序集,如果它中的一个二元关系满足自反性、反对称性和传递性.称\hspace{0pt}$P$的子集\hspace{0pt}$D$为有向的,如果它是非空的,并且\hspace{0pt}$D$的每个有限子集在\hspace{0pt}$D$中都有上界\cite{ref11}.

本文中,\hspace{0pt}$L$和\hspace{0pt}$M$都是完全分配格,它们的最大元记为\hspace{0pt}$~\top$\nobreak\hspace{0pt},最小元记为\hspace{0pt}$\bot$\nobreak\hspace{0pt}.\hspace{0pt}$L$上的一个二元关系\hspace{0pt}$\prec$定义为,对\hspace{0pt}$\forall a,b\in L$\nobreak\hspace{0pt},\hspace{0pt}$a\prec b$当且仅当对\hspace{0pt}$\forall M\subseteq L$\nobreak\hspace{0pt},\hspace{0pt}$b\le \vee M$\nobreak\hspace{0pt},则存在一个\hspace{0pt}$d\in M$\nobreak\hspace{0pt},使得\hspace{0pt}$a\le d$\cite{ref11}.

对于完全分配格\hspace{0pt}$\left ( { L,\wedge\allowbreak{} ,\vee\allowbreak{} } \right )$存在一个二元算子\hspace{0pt}$\to :L\times L\to L$\nobreak\hspace{0pt},定义为\hspace{0pt}$\alpha \to\allowbreak{} \beta =\allowbreak{}\vee\allowbreak{} \left \{ \begin{array}{l} \gamma \in\allowbreak{} L:\alpha \wedge\allowbreak{} \gamma \le\allowbreak{} \beta \end{array} \right \}$\nobreak\hspace{0pt},称\hspace{0pt}$\to$为蕴含算子.此外,\hspace{0pt}$\wedge$和\hspace{0pt}$\to$还满足对\hspace{0pt}$\forall \alpha ,\beta ,\gamma \in\allowbreak{} L$\nobreak\hspace{0pt},\hspace{0pt}$\alpha \wedge\allowbreak{} \gamma \le\allowbreak{} \beta \Leftrightarrow \gamma \le\allowbreak{} \left ( { \alpha \to\allowbreak{} \beta } \right )$\cite{ref11}.

\textbf{定义2.2.1.}  \cite{ref13} 非空集\hspace{0pt}$X$上的一个模糊伪度量是一个三元组\hspace{0pt}$\left ( { X,d,\wedge\allowbreak{} } \right )$\nobreak\hspace{0pt},其中\hspace{0pt}$d$是一个映\hspace{0pt}$d:X\times X\times \left [ { 0,\infty } \right )\to\allowbreak{} \left[ 0,1 \right]$\nobreak\hspace{0pt},满足对\hspace{0pt}$\forall x,y,z\in X$及\hspace{0pt}$\forall s,t>0$\nobreak\hspace{0pt}：

（KM1）\hspace{0pt}$d\left ( { x,y,0 } \right )=\allowbreak{}0$\nobreak\hspace{0pt};

（KM2）\hspace{0pt}$d\left ( { x,x,t } \right )=\allowbreak{}1$\nobreak\hspace{0pt};

（KM3）\hspace{0pt}$d\left ( { x,y,t } \right )=\allowbreak{}d\left ( { y,x,t } \right )$\nobreak\hspace{0pt};

（KM4）\hspace{0pt}$d\left ( { x,y,t } \right )\wedge\allowbreak{} d\left ( { y,z,s } \right )\le\allowbreak{} d\left ( { x,z,t+s } \right )$\nobreak\hspace{0pt};

（KM5）\hspace{0pt}$d\left ( { x,y,- } \right ):\left [ { 0,\infty } \right )\to\allowbreak{} \left[ 0,1 \right]$是左连续的;

上述中的模糊伪度量也称为\hspace{0pt}$KM$-模糊伪度量.

为回顾格值模糊化粗结构的定义,我们引入以下定义：对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { X\times X }$\nobreak\hspace{0pt},\newline \hspace{0pt}$E ^ { -1 } \left ( { x,y } \right )=\allowbreak{}E\left ( { y,x } \right )$\nobreak\hspace{0pt},\newline \hspace{0pt}$\left ( { E\circ F } \right )\left ( { x,y } \right )=\allowbreak{}\bigvee_{ z\in\allowbreak{} X } F\left ( { x,z } \right )\wedge\allowbreak{} E\left ( { z,y } \right )$\nobreak\hspace{0pt},\newline \hspace{0pt}$E\left[ x \right]\left ( { y } \right )=\allowbreak{}E\left ( { x,y } \right )$\nobreak\hspace{0pt}.

\textbf{定义2.2.2.}  集合\hspace{0pt}$X$上的一个格值模糊化熵结构是一个映射\hspace{0pt}$\mathcal{C}$\hspace{0pt}$\nobreak\hspace{0pt}:L ^ { X\times X } \to\allowbreak{} M$满足以下条件：

\quad （ME1）\hspace{0pt}$\mathcal{C}\left ( { \Delta _{ X } } \right )=\allowbreak{}\top$\nobreak\hspace{0pt};

\quad （ME2）\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { X\times X }$\nobreak\hspace{0pt},且\hspace{0pt}$E\le F$\nobreak\hspace{0pt},则\hspace{0pt}$\mathcal{C}\left ( { F } \right )\le\allowbreak{} \mathcal{C}\left ( { E } \right )$\nobreak\hspace{0pt};

\quad （ME3）\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { X\times X }$\nobreak\hspace{0pt},则\hspace{0pt}$\mathcal{C}\left ( { E } \right )\wedge\allowbreak{} \mathcal{C}\left ( { F } \right )\le\allowbreak{} \mathcal{C}\left ( { E\vee\allowbreak{} F } \right )$\nobreak\hspace{0pt};

\quad 一个格值模糊化熵结构\hspace{0pt}$\mathcal{C}$称为格值模糊化拟粗结构,如果它又满足（ME4）：

\quad （ME4）\hspace{0pt}$\forall E,F\in L^{X\times X}$\nobreak\hspace{0pt},则\hspace{0pt}$\mathcal{C}\left ( { E } \right )\wedge\allowbreak{} \mathcal{C}\left ( { F } \right )\le\allowbreak{} \mathcal{C}\left ( { E\circ F } \right )$\nobreak\hspace{0pt};

\quad 一个格值模糊化熵结构\hspace{0pt}$\mathcal{C}$称为格值模糊化半粗结构,如果它又满足（ME5）：

\quad （1）弱上乘保持性, 若\hspace{0pt}\penalty0$\forall s,t\in P$\nobreak\hspace{0pt}, \hspace{0pt}\penalty0$\mathcal{N}\left ( { \mathcal{B}_{ s } \vee \mathcal{B}_{ t } } \right )\le \bigvee_{ \mathcal{B}_{ s } \vee \mathcal{B}_{ t } \le \mathcal{B}_{ r } } \mathcal{N}\left ( { \mathcal{B}_{ r } } \right )$\nobreak\hspace{0pt}；

（2）上乘保持性, 若\hspace{0pt}\penalty0$\forall s,t\in P$\nobreak\hspace{0pt}, \hspace{0pt}\penalty0$\mathcal{N}\left ( { \mathcal{B}_{ s } \circ \mathcal{B}_{ t } } \right )\le \bigvee_{ \mathcal{B}_{ s } \circ \mathcal{B}_{ t } \le \mathcal{B}_{ r } } \mathcal{N}\left ( { \mathcal{B}_{ r } } \right )$\nobreak\hspace{0pt}, 其中\hspace{0pt}\penalty0$\mathcal{B}_s\circ\mathcal{B}_t:X\times X\to M$\penalty0\hspace{0pt}定义为: \hspace{0pt}\penalty0$\forall x,y\in X$\nobreak\hspace{0pt}, \hspace{0pt}\penalty0$\left ( { \mathcal{B}_{ s } \circ \mathcal{B}_{ t } } \right )\left ( { x,y } \right )=\bigvee_{ z\in X } \mathcal{B}_{ t } \left ( { x,z } \right )\wedge \mathcal{B}_{ s } \left ( { z,y } \right )$\nobreak\hspace{0pt}；

\textbf{定义3.2.3.}  设\hspace{0pt}\penalty0$\mathcal{B} =\left ( { X,P,\mathcal{B},\mathcal{N} } \right )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统, 则\hspace{0pt}\penalty0$\mathcal{B}$\penalty0\hspace{0pt}被称为:

\textbf{定义3.2.4.}  设\hspace{0pt}\penalty0$\mathcal{B} _{ P } =\left ( { X,P,\mathcal{B}_{ P } ,\mathcal{N}_{ P } } \right )$\penalty0\hspace{0pt}和\hspace{0pt}\penalty0$\mathcal{B} _{ Q } =\left ( { X,Q,\mathcal{B}_{ Q } ,\mathcal{N}_{ Q } } \right )$\penalty0\hspace{0pt}为上\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}的\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统, 记\hspace{0pt}\penalty0$\mathcal{B} _{ P } \prec \mathcal{B} _{ Q }$\nobreak\hspace{0pt}, 若对任意\hspace{0pt}\penalty0$r\in P$\nobreak\hspace{0pt}, 有\hspace{0pt}\penalty0$\mathcal{N}_{ P } ((\mathcal{B}_{ P } )_{ r } )\le \bigvee_{ s\in Q_{ r } } \mathcal{N}_{ Q } ((\mathcal{B}_{ Q } )_{ s } )$\nobreak\hspace{0pt}, 其中

接下来, 我们要建立\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统与\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵结构之间的关系.

\textbf{命题3.2.6.}   设\hspace{0pt}\penalty0$\left ( { X,\mathcal{C} } \right )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵空间, 记\hspace{0pt}\penalty0$P_X=\{E\in L^{X\times X}:\Delta_X\leq E\}$\nobreak\hspace{0pt}, 对\hspace{0pt}\penalty0$\forall E\in P_{ X }$\nobreak\hspace{0pt}, 定义映射\hspace{0pt}\penalty0$\mathcal{B}_{\mathcal{C}}:X\times E\times X\to L$\penalty0\hspace{0pt}为: \hspace{0pt}\penalty0$\forall x,y\in X$\nobreak\hspace{0pt},\hspace{0pt}\penalty0$\forall E\in P_{ X }$\nobreak\hspace{0pt},\hspace{0pt}\penalty0$\mathcal{B}_{ \mathcal{C} } \left ( { x,E,y } \right )=E\left ( { x,y } \right )$\nobreak\hspace{0pt}, 则\hspace{0pt}\penalty0$\mathcal{B}_{ \mathcal{C} }$\penalty0\hspace{0pt}是\hspace{0pt}\penalty0$X$\penalty0\hspace{0pt}上关于\hspace{0pt}\penalty0$P_{ X }$\penalty0\hspace{0pt}的\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-球映射. 进一步, 令\hspace{0pt}\penalty0$R_{ \mathcal{B}_{ \mathcal{C} } } =\left \{ \begin{array}{l} \left ( { \mathcal{B}_{ \mathcal{C} } } \right )_{ E } \in L ^ { X\times X } :E\in P_{ X } \end{array} \right \}$\nobreak\hspace{0pt}.其中对\hspace{0pt}\penalty0$\forall F\in P_{ X }$\nobreak\hspace{0pt}, 定义映射\hspace{0pt}\penalty0$\left ( { \mathcal{B}_{ \mathcal{C} } } \right )_{ F } :X\times X\to L$\penalty0\hspace{0pt}为: \hspace{0pt}\penalty0$\forall x,y\in X$\nobreak\hspace{0pt}, \hspace{0pt}\penalty0$\left ( { \mathcal{B}_{ \mathcal{C} } } \right )_{ F } (x,y)=\mathcal{B}_{ \mathcal{C} } \left ( { x,F,y } \right )$\nobreak\hspace{0pt}. 定义映射\hspace{0pt}\penalty0$N_{\mathcal{C}}:R_{\mathcal{B}_{\mathcal{C}}}\to M$\penalty0\hspace{0pt}为:
$$\forall E\in P_{ X }, \mathcal{N}_{ \mathcal{C} } \left ( { \left ( { \mathcal{B}_{ \mathcal{C} } } \right )_{ E } } \right )=\mathcal{C}\left ( { E } \right ).$$
则\hspace{0pt}\penalty0$\mathcal{B} _{ \mathcal{C} } =\left ( { X,P_{ X } ,\mathcal{B}_{ \mathcal{C} } ,\mathcal{N}_{ \mathcal{C} } } \right )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统, 且\hspace{0pt}\penalty0$\mathcal{B} _{ \mathcal{C} }$\penalty0\hspace{0pt}满足弱上乘保持性. 此外,

（1）若\hspace{0pt}\penalty0$\mathcal{C}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半粗结构, 则\hspace{0pt}\penalty0$\mathcal{B} _{ \mathcal{C} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半球空间；

（2）若\hspace{0pt}\penalty0$\mathcal{C}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟粗结构, 则\hspace{0pt}\penalty0$\mathcal{B} _{ \mathcal{C} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟球空间；

（3）若\hspace{0pt}\penalty0$\mathcal{C}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊粗结构, 则\hspace{0pt}\penalty0$\mathcal{B} _{ \mathcal{C} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球空间.

\textbf{证明：} 对任意\hspace{0pt}\penalty0$E\in P_{ X }$\nobreak\hspace{0pt}, 由\hspace{0pt}\penalty0$\Delta _{ X } \le E\in L ^ { X\times X }$\nobreak\hspace{0pt}, 得\hspace{0pt}\penalty0$\left(\mathcal{B}_{\mathcal{C}}\right)_E(x,x)=E(x,x)\geq\Delta_X(x,x)=\top$\nobreak\hspace{0pt}, 这说明\hspace{0pt}\penalty0$\left ( { \mathcal{B}_{ \mathcal{C} } } \right )_{ E }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$L$\penalty0\hspace{0pt}-球映射, 对任意\hspace{0pt}\penalty0$E,F\in P_{ X }$\nobreak\hspace{0pt}, 由\hspace{0pt}\penalty0$\left ( { X,\mathcal{C} } \right )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊熵空间, 得
\begin{eqnarray*}\mathcal{N}_{\mathcal{C}}((\mathcal{B}_{\mathcal{C}})_E)\wedge\mathcal{N}_{\mathcal{C}}((\mathcal{B}_{\mathcal{C}})_F)&=&\mathcal{C}(E)\wedge\mathcal{C}(F)\\&=&\mathcal{C}(E\vee F)\\&=&\mathcal{N}_{\mathcal{C}}((\mathcal{B}_{\mathcal{C}})_{E\vee F})\\&=&\mathcal{N}_{\mathcal{C}}((\mathcal{B}_{\mathcal{C}})_E\vee(\mathcal{B}_{\mathcal{C}})_F),\end{eqnarray*}
故\hspace{0pt}\penalty0$\mathcal{N}_{ \mathcal{C} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球结构, 因此, \hspace{0pt}\penalty0$\mathcal{B} _{ \mathcal{C} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统.

对任意\hspace{0pt}\penalty0$E,F\in P_{ X }$\nobreak\hspace{0pt}, 有\hspace{0pt}\penalty0$E\vee F\in P_X$\nobreak\hspace{0pt}, 且对任意\hspace{0pt}\penalty0$H\in P$\nobreak\hspace{0pt}, 当\hspace{0pt}\penalty0$E\vee F\le H$\penalty0\hspace{0pt}时, 有\hspace{0pt}\penalty0$(\mathcal{B}_{\mathcal{C}})_{E\vee F}\leq(\mathcal{B}_{\mathcal{C}})_H$\nobreak\hspace{0pt}. 由
\begin{eqnarray*}\mathcal{N}_{\mathcal{C}}((\mathcal{B}_{\mathcal{C}})_E\vee(\mathcal{B}_{\mathcal{C}})_F)&=&\mathcal{N}_{\mathcal{C}}((\mathcal{B}_{\mathcal{C}})_{E\vee F})\\&\leq&\bigvee_{E\vee F\leq H\in P}\mathcal{N}_{\mathcal{C}}((\mathcal{B}_{\mathcal{C}})_H)\\&=&\bigvee_{(\mathcal{B}_{\mathcal{C}})_{E\vee F}\leq(\mathcal{B}_{\mathcal{C}})_H}\mathcal{N}_{\mathcal{C}}((\mathcal{B}_{\mathcal{C}})_H),\end{eqnarray*}
知\hspace{0pt}\penalty0$\mathcal{B} _{ \mathcal{C} }$\penalty0\hspace{0pt}满足弱上乘保持性.

（1）若\hspace{0pt}\penalty0$\mathcal{C}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半粗结构, 则对\hspace{0pt}\penalty0$\forall E\in P$\nobreak\hspace{0pt},
$$\mathcal{N}_{ \mathcal{C} } \left ( { \left ( { \mathcal{B}_{ \mathcal{C} } } \right )_{ E } } \right )=\mathcal{C}\left ( { E } \right )\le \mathcal{C}\left ( { E ^ { -1 } } \right )=\mathcal{N}_{ \mathcal{C} } \left ( { \left ( { \mathcal{B}_{ \mathcal{C} } } \right )_{ E } ^ { * } } \right ),$$
故\hspace{0pt}\penalty0$\mathcal{B} _{ \mathcal{C} }$\penalty0\hspace{0pt}满足上对称性, 因此\hspace{0pt}\penalty0$\mathcal{B} _{ \mathcal{C} }$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半球空间.

（2）若\hspace{0pt}\penalty0$\mathcal{C}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊拟粗结构, 对\hspace{0pt}\penalty0$\forall E,F\in P$\nobreak\hspace{0pt}, 显然有\hspace{0pt}\penalty0$E\circ F\in P$\nobreak\hspace{0pt}, 由
\begin{eqnarray*}\left(\left(\mathcal{B}_{\mathcal{C}}\right)_E\circ\left(\mathcal{B}_{\mathcal{C}}\right)_F\right)(x,y)&=&\bigvee_{z\in X}\left(\mathcal{B}_{\mathcal{C}}\right)_F(x,z)\wedge\left(\mathcal{B}_{\mathcal{C}}\right)_E(z,y)\\&=&\bigvee_{z\in X}F(x,z)\wedge E(z,y)\\&=&(E\circ F)(x,y)=\left(\mathcal{B}_{\mathcal{C}}\right)_{E\circ F}(x,y)\end{eqnarray*}
知\hspace{0pt}\penalty0$\left ( { \mathcal{B}_{ \mathcal{C} } } \right )_{ E } \circ \left ( { \mathcal{B}_{ \mathcal{C} } } \right )_{ F } =\left ( { \mathcal{B}_{ \mathcal{C} } } \right )_{ E\circ F }$\nobreak\hspace{0pt}, 于是
\begin{eqnarray*}\mathcal{N}_{\mathcal{C}}((\mathcal{B}_{\mathcal{C}})_E\circ(\mathcal{B}_{\mathcal{C}})_F)&=&\mathcal{N}_{\mathcal{C}}((\mathcal{B}_{\mathcal{C}})_{E\circ F})\\&\leq&\bigvee_{E\circ F\leq H\in P}\mathcal{N}_{\mathcal{C}}((\mathcal{B}_{\mathcal{C}})_H)\\&=&\bigvee_{(\mathcal{B}_{\mathcal{C}})_{E\circ F}\leq(\mathcal{B}_{\mathcal{C}})_H}\mathcal{N}_{\mathcal{C}}((\mathcal{B}_{\mathcal{C}})_H),\end{eqnarray*}

\textbf{命题3.2.8.}  设\hspace{0pt}\penalty0$\mathcal{B} =\left ( { X,P,\mathcal{B},\mathcal{N} } \right )$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊球系统, \hspace{0pt}\penalty0$\forall r\in P$\nobreak\hspace{0pt}, 定义映射\hspace{0pt}\penalty0$E_{ r } :X\times X\to L$\penalty0\hspace{0pt}为：\hspace{0pt}\penalty0$\forall x,y\in X$\nobreak\hspace{0pt},\hspace{0pt}\penalty0$E_{ r } \left ( { x,y } \right )=\mathcal{B}_{ r } \left ( { x,y } \right )$\nobreak\hspace{0pt}. 显然有\hspace{0pt}\penalty0$\mathcal{E}=\left \{ \begin{array}{l} E_{ r } :r\in P \end{array} \right \}\subset L ^ { X\times X }$\nobreak\hspace{0pt}. 定义映射\hspace{0pt}\penalty0$\mathcal{S}_{ \mathcal{B} } :L ^ { X\times X } \to M$\penalty0\hspace{0pt}为

（1）若\hspace{0pt}\penalty0$\mathcal{B}$\penalty0\hspace{0pt}是一个\hspace{0pt}\penalty0$(L,M)$\penalty0\hspace{0pt}-模糊半球空间, 则\hspace{0pt}\penalty0$\forall r\in P$\nobreak\hspace{0pt}, 有

\textbf{注4.1.2.}  由于\hspace{0pt}$E\le GE$\nobreak\hspace{0pt},则\hspace{0pt}$\mathcal{C}\left ( { GE } \right )\le\allowbreak{} \mathcal{C}\left ( { E } \right )$\nobreak\hspace{0pt},即若\hspace{0pt}$\left ( { G,\mathcal{C} } \right )$称为一个左格值模糊化粗群,那么\hspace{0pt}$\mathcal{C}\left ( { E } \right )=\allowbreak{}\mathcal{C}\left ( { GE } \right )$\nobreak\hspace{0pt}.

\textbf{命题4.1.3.}  \hspace{0pt}$d:G\times G\times \left[ 0,\infty \right]\to\allowbreak{} \left[ 0,1 \right]$是一个KM-模糊伪度量,定义\hspace{0pt}$\mathcal{C}_{ d } :L ^ { G\times G } \to\allowbreak{} \left[ 0,1 \right]$满足
$$\mathcal{C}_{ d } \left ( { E } \right )=\bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { E\left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ),$$
若\hspace{0pt}$d$是左不变的,则\hspace{0pt}$\left ( { G,\mathcal{C}_{ d } } \right )$是一个左[0,1]-模糊粗群;

若\hspace{0pt}$d$是右不变的,则\hspace{0pt}$\left ( { G,\mathcal{C}_{ d } } \right )$是一个右[0,1]-模糊粗群;

若\hspace{0pt}$d$是不变的,则\hspace{0pt}$\left ( { G,\mathcal{C}_{ d } } \right )$是一个[0,1]-模糊粗群.

\textbf{证明：} 先证\hspace{0pt}$\mathcal{C}_{ d } :L ^ { G\times G } \to\allowbreak{} \left[ 0,1 \right]$是一个格值模糊化粗结构：

由已知条件可知
\begin{eqnarray*} \mathcal{C}_{ d } \left ( { \Delta _{ G } } \right ) &=& \bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { \Delta _{ G } \left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \left ( { \bigwedge_{ x=y } \left ( { ~\top \to d\left ( { x,x,t } \right ) } \right )\wedge \bigwedge_{ x\ne y } \left ( { ~\bot \to d\left ( { x,y,t } \right ) } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \left ( { \bigwedge_{ x=y } d\left ( { x,x,t } \right )\wedge \bigwedge_{ x\ne y } \top } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ x\in G } d\left ( { x,x,t } \right )=\top; \end{eqnarray*}
对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$E\le F$\nobreak\hspace{0pt},由于\hspace{0pt}$F\left ( { x,y } \right )\to\allowbreak{} d\left ( { x,y,t } \right )\le\allowbreak{} E\left ( { x,y } \right )\to\allowbreak{} d\left ( { x,y,t } \right )$\nobreak\hspace{0pt},则显然\hspace{0pt}$\mathcal{C}_{ d } \left ( { E } \right )\ge\allowbreak{} \mathcal{C}_{ d } \left ( { F } \right )$\nobreak\hspace{0pt};

对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},由于
\begin{eqnarray*} \mathcal{C}_{ d } \left ( { E } \right ) &=& \bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { E\left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ), \\ \mathcal{C}_{ d } \left ( { F } \right ) &=& \bigvee_{ s>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { F\left ( { x,y } \right )\to d\left ( { x,y,s } \right ) } \right ) , \end{eqnarray*}
对\hspace{0pt}$\forall a\prec \mathcal{C}_{ d } \left ( { E } \right )\wedge\allowbreak{} \mathcal{C}_{ d } \left ( { F } \right )$\nobreak\hspace{0pt},\hspace{0pt}$\exists t,s>0$\nobreak\hspace{0pt},使得\hspace{0pt}$a\le\allowbreak{} \bigwedge_{ \left ( { x,y } \right )\in\allowbreak{} G\times G } \left ( { E\left ( { x,y } \right )\to\allowbreak{} d\left ( { x,y,t } \right ) } \right )$\nobreak\hspace{0pt},\hspace{0pt}$a\le\allowbreak{} \bigwedge_{ \left ( { x,y } \right )\in\allowbreak{} G\times G } \left ( { F\left ( { x,y } \right )\to\allowbreak{} d\left ( { x,y,s } \right ) } \right )$ ,

则对\hspace{0pt}$\forall x,y\in G$\nobreak\hspace{0pt},\hspace{0pt}$a\wedge E(x,y)\leq d(x,y,t)$且\hspace{0pt}$a\wedge F(x,y)\leq d(x,y,s)$\nobreak\hspace{0pt},令\newline \hspace{0pt}$r=\allowbreak{}max\left \{ \begin{array}{l} s,t \end{array} \right \}$\nobreak\hspace{0pt},则
\begin{eqnarray*} a\wedge \left ( { E\left ( { x,y } \right )\vee F\left ( { x,y } \right ) } \right ) &=& a\wedge \left ( { E\vee F } \right )\left ( { x,y } \right ) \\  &\le& d\left ( { x,y,t } \right )\wedge d\left ( { x,y,s } \right )\le d\left ( { x,y,r } \right ), \end{eqnarray*}
故\hspace{0pt}$a\le\allowbreak{} \left ( { E\vee\allowbreak{} F } \right )\left ( { x,y } \right )\to\allowbreak{} d\left ( { x,y,r } \right )$\nobreak\hspace{0pt},即\newline \hspace{0pt}$a\le\allowbreak{} \bigvee_{ r>0 } \bigwedge_{ \left ( { x,y } \right )\in\allowbreak{} G\times G } \left ( { \left ( { E\vee\allowbreak{} F } \right )\left ( { x,y } \right )\to\allowbreak{} d\left ( { x,y,r } \right ) } \right )$\nobreak\hspace{0pt},得证;

对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$\forall a\prec \mathcal{C}_{ d } \left ( { E } \right )\wedge\allowbreak{} \mathcal{C}_{ d } \left ( { F } \right )$\nobreak\hspace{0pt},\hspace{0pt}$\exists t>0,s>0$\nobreak\hspace{0pt},使得
\begin{eqnarray*} a &\le& \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { E\left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ),a \\  &\le& \bigwedge_{ \left ( { y,z } \right )\in G\times G } \left ( { F\left ( { y,z } \right )\to d\left ( { y,z,s } \right ) } \right ), \end{eqnarray*}
则对\hspace{0pt}$\forall x,y,z\in G$\nobreak\hspace{0pt},有\hspace{0pt}$a\wedge E(x,y)\leq d(x,y,t)$\nobreak\hspace{0pt},\hspace{0pt}$a\wedge F(y,z)\leq d(y,z,s)$\nobreak\hspace{0pt},故
\begin{eqnarray*} a\wedge \left ( { E\left ( { x,y } \right )\wedge F\left ( { x,y } \right ) } \right ) &\le& d\left ( { x,y,t } \right )\wedge d\left ( { x,y,s } \right ) \\  &\le& d\left ( { x,z,t+s } \right ),a\wedge \bigvee_{ y\in G } \left ( { E\left ( { x,y } \right )\wedge F\left ( { y,z } \right ) } \right ) \\  &\le& d\left ( { x,z,t+s } \right ), \end{eqnarray*}
\begin{eqnarray*} a &\le& \left ( { E\circ F } \right )\left ( { x,z } \right )\to d\left ( { x,z,t+s } \right ),a \\  &\le& \bigvee_{ r>0 } \bigwedge_{ \left ( { x,z } \right )\in G\times G } \left ( { E\circ F } \right )\left ( { x,z } \right )\to d\left ( { x,z,r } \right ), \end{eqnarray*}
得证\hspace{0pt}$\mathcal{C}_{ d } \left ( { E } \right )\wedge\allowbreak{} \mathcal{C}_{ d } \left ( { F } \right )\le\allowbreak{} \mathcal{C}_{ d } \left ( { E\circ F } \right )$\nobreak\hspace{0pt};

（5）对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},
\begin{eqnarray*} \mathcal{C}_{ d } \left ( { E ^ { -1 } } \right ) &=& \bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { E ^ { -1 } \left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ \left ( { y,x } \right )\in G\times G } \left ( { E\left ( { y,x } \right )\to d\left ( { y,x,t } \right ) } \right ) \\  &=& \mathcal{C}_{ d } \left ( { E } \right )\text{；} \end{eqnarray*}
下证\hspace{0pt}$\left ( { G,\mathcal{C}_{ d } } \right )$是一个左（右）[0,1]-模糊粗群,若\hspace{0pt}$d$是左不变的,则
\begin{eqnarray*} \mathcal{C}_{ d } \left ( { GE } \right ) &=& \bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { GE\left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { \bigvee_{ g\in G } E\left ( { gx,gy } \right )\to d\left ( { x,y,t } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { \bigwedge_{ g\in G } \left ( { E\left ( { gx,gy } \right )\to d\left ( { x,y,t } \right ) } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \left ( { \bigwedge_{ g\in G } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { E\left ( { gx,gy } \right )\to d\left ( { x,y,t } \right ) } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \left ( { \bigwedge_{ g\in G } \bigwedge_{ \left ( { x',y' } \right )\in G\times G } \left ( { E\left ( { x',y' } \right )\to d\left ( { g ^ { -1 } x',g ^ { -1 } y',t } \right ) } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \left ( { \bigwedge_{ \left ( { x',y' } \right )\in G\times G } \left ( { E\left ( { x',y' } \right )\to d\left ( { x',y',t } \right ) } \right ) } \right ) \\  &=& \mathcal{C}_{ d } \left ( { E } \right ); \end{eqnarray*}
若\hspace{0pt}$d$是右不变的,则同理.

\textbf{定义4.1.4.}  \hspace{0pt}$\left ( { X,\mathcal{C}_{ X } } \right )$和\hspace{0pt}$\left ( { Y,\mathcal{C}_{ Y } } \right )$是两个格值模糊化粗群,\newline \hspace{0pt}$\left \{ \begin{array}{l} f_{ i } :\left ( { X,\mathcal{C}_{ X } } \right )\to\allowbreak{} \left ( { Y,\mathcal{C}_{ Y } } \right ) \end{array} \right \}_{ i\in\allowbreak{} I }$是一族映射,\hspace{0pt}$\left \{ \begin{array}{l} f_{ i } \end{array} \right \}_{ i\in\allowbreak{} I }$称为一致格值模糊化保有界的,若对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { X\times X }$\nobreak\hspace{0pt},\hspace{0pt}$\exists F\in\allowbreak{} L ^ { Y\times Y }$\nobreak\hspace{0pt},使得\hspace{0pt}$\mathcal{C}_{ X } \left ( { E } \right )\le\allowbreak{} \mathcal{C}_{ Y } \left ( { F } \right )$\nobreak\hspace{0pt},且对\hspace{0pt}$\forall i\in I$\nobreak\hspace{0pt},\hspace{0pt}$\left ( { f_{ i } \times f_{ i } } \right )\left ( { E } \right )\le\allowbreak{} F$\nobreak\hspace{0pt}.

\textbf{命题4.1.5.}  \hspace{0pt}$G$是一个群,\hspace{0pt}$\mathcal{C}$是\hspace{0pt}$G$上一个格值模糊化粗结构,则:

（1）\hspace{0pt}$\left ( { G,\mathcal{C} } \right )$是一个左格值模糊化粗群当且仅当\hspace{0pt}$s_{ G } ^{ \lambda }=\allowbreak{}\left \{ \begin{array}{l} s_{ g } ^{ \lambda }:g\in\allowbreak{} G \end{array} \right \}$是一致格值模糊化保有界的;

（2）\hspace{0pt}$\left ( { G,\mathcal{C} } \right )$是一个右格值模糊化粗群当且仅当\hspace{0pt}$s_{ G } ^{ \rho }=\allowbreak{}\left \{ \begin{array}{l} s_{ g } ^{ \rho }:g\in\allowbreak{} G \end{array} \right \}$是一致格值模糊化保有界的.

\textbf{证明：} （1）必要性 对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},由于\hspace{0pt}$\left ( { G,\mathcal{C} } \right )$是一个左格值模糊化粗群,则\hspace{0pt}$\mathcal{C}\left ( { E } \right )\le\allowbreak{} \mathcal{C}\left ( { GE } \right )$\nobreak\hspace{0pt},而对\hspace{0pt}$\forall g\in G$\nobreak\hspace{0pt},\hspace{0pt}$\left ( { s_{ g } ^{ \lambda }\times s_{ g } ^{ \lambda } } \right )\left ( { E } \right )\le\allowbreak{} GE$\nobreak\hspace{0pt},故\hspace{0pt}$s_{ G } ^{ \lambda }=\allowbreak{}\left \{ \begin{array}{l} s_{ g } ^{ \lambda }:g\in\allowbreak{} G \end{array} \right \}$是一致格值模糊化保有界的;

充分性 由于\hspace{0pt}$s_{ G } ^{ \lambda }=\allowbreak{}\left \{ \begin{array}{l} s_{ g } ^{ \lambda }:g\in\allowbreak{} G \end{array} \right \}$是一致格值模糊化保有界的,即对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$\exists F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},使得对\hspace{0pt}$\forall g\in G$\nobreak\hspace{0pt},\hspace{0pt}$\mathcal{C}\left ( { E } \right )\le\allowbreak{} \mathcal{C}\left ( { F } \right )$\nobreak\hspace{0pt},且\hspace{0pt}$\left ( { s_{ g } ^{ \lambda }\times s_{ g } ^{ \lambda } } \right )\left ( { E } \right )\le\allowbreak{} F$\nobreak\hspace{0pt},故
\begin{eqnarray*} GE\left ( { x,y } \right ) &=& \bigvee_{ g\in G } E\left ( { gx,gy } \right )=\bigvee_{ g\in G } \left ( { s_{ g } ^{ \lambda }\times s_{ g } ^{ \lambda } } \right )E\left ( { x,y } \right ) \\  &\le& F\left ( { x,y } \right ), \end{eqnarray*}
则\hspace{0pt}$\mathcal{C}\left ( { E } \right )\le\allowbreak{} \mathcal{C}\left ( { F } \right )\le\allowbreak{} \mathcal{C}\left ( { GE } \right )$\nobreak\hspace{0pt};

（2）与（1）的证明同理.


\section{格值模糊化群理想}
\vspace{0.2cm}
上一节中我们从粗结构出发定义了格值模糊化粗群,但一个自然的问题随之而来：是否存在一种代数对象能够完全刻画这类结构？受经典粗群理论中``群理想决定粗结构''这一深刻结论的启发,我们将在本节引入格值模糊化群理想的全新概念,并探索其与模糊粗群之间的内在联系.

\textbf{定义4.2.1.}  \hspace{0pt}$G$是一个群,\hspace{0pt}$G$上一个格值模糊化群理想是映射\hspace{0pt}$I:L ^ { G } \to M$\nobreak\hspace{0pt},满足：

（IM1）\hspace{0pt}$I\left ( { \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } } \right )=\allowbreak{}\top$\nobreak\hspace{0pt};

（IM2）\hspace{0pt}$\forall A,B\in L ^ { G }$\nobreak\hspace{0pt},\hspace{0pt}$A\le B$\nobreak\hspace{0pt},有\hspace{0pt}$I(B)\leq I(A)$\nobreak\hspace{0pt};

（IM3）\hspace{0pt}$\forall A,B\in L ^ { G }$\nobreak\hspace{0pt},\hspace{0pt}$I\left ( { A } \right )\wedge\allowbreak{} I\left ( { B } \right )\le\allowbreak{} I\left ( { A\vee\allowbreak{} B } \right )$\nobreak\hspace{0pt};

（IM4）\hspace{0pt}$\forall A,B\in L ^ { G }$\nobreak\hspace{0pt},\hspace{0pt}$I\left ( { A } \right )\wedge\allowbreak{} I\left ( { B } \right )\le\allowbreak{} I\left ( { AB } \right )$\nobreak\hspace{0pt},其中\newline \hspace{0pt}$AB\left ( { z } \right )=\allowbreak{}\bigvee_{ x,y\in\allowbreak{} G,xy=\allowbreak{}z } \left ( { A\left ( { x } \right )\wedge\allowbreak{} B\left ( { y } \right ) } \right )$\nobreak\hspace{0pt};

（IM5）\hspace{0pt}$\forall A\in L ^ { G }$\nobreak\hspace{0pt},\hspace{0pt}$I\left ( { A } \right )=\allowbreak{}I\left ( { A ^ { -1 } } \right )$\nobreak\hspace{0pt},其中\hspace{0pt}$A ^ { -1 } \left ( { x } \right )=\allowbreak{}A\left ( { x ^ { -1 } } \right )$\nobreak\hspace{0pt}.

\textbf{命题4.2.2.}  \hspace{0pt}$G$是一个群,\hspace{0pt}$I$是\hspace{0pt}$G$上一个格值模糊化群理想,定义\hspace{0pt}$\mathcal{C}_{ I } ^{ \lambda }:L ^ { G\times G } \to\allowbreak{} M$满足对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$\mathcal{C}_{ I } ^{ \lambda }\left ( { E } \right )=\allowbreak{}\bigvee_{ E\le\allowbreak{} E_{ A } ^{ \lambda } } I\left ( { A } \right )$\nobreak\hspace{0pt},其中\hspace{0pt}$E_{ A } ^{ \lambda }\left ( { x,y } \right )=\allowbreak{}A\left ( { x ^ { -1 } y } \right )$\nobreak\hspace{0pt},则\hspace{0pt}$\left ( { G,\mathcal{C}_{ I } ^{ \lambda } } \right )$构成一个左格值模糊化粗群.

\textbf{证明：} （ME1）由于
\begin{eqnarray*} E_{ \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } } ^{ \lambda }\left ( { x,y } \right ) \\  &=& \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } \left ( { x ^ { -1 } y } \right ), \end{eqnarray*}
当\hspace{0pt}$x=y$时,\hspace{0pt}$x ^ { -1 } y=e$\nobreak\hspace{0pt},则\hspace{0pt}$\chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } =\allowbreak{}\top$\nobreak\hspace{0pt},当\hspace{0pt}$x\ne y$时,\hspace{0pt}$x ^ { -1 } y\ne e$\nobreak\hspace{0pt},则\hspace{0pt}$\chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } =\allowbreak{}\bot$\nobreak\hspace{0pt},故\hspace{0pt}$E_{ \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } } ^{ \lambda }=\allowbreak{}\Delta _{ G }$\nobreak\hspace{0pt},则
\begin{eqnarray*} \mathcal{C}_{ I } ^{ \lambda }\left ( { \Delta _{ G } } \right ) &=& \bigvee_{ \Delta _{ G } \le E_{ A } ^{ \lambda } } I\left ( { A } \right ) \\  &=& \bigvee_{ E_{ \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } } ^{ \lambda }\le E_{ A } ^{ \lambda } } I\left ( { A } \right ) \\  &\ge& I\left ( { \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } } \right )=\top; \end{eqnarray*}


（ME2）对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$E\le F$\nobreak\hspace{0pt},由于\hspace{0pt}$\mathcal{C}_{ I } ^{ \lambda }\left ( { F } \right )=\allowbreak{}\bigvee_{ F\le\allowbreak{} E_{ A } ^{ \lambda } } I\left ( { A } \right )$\nobreak\hspace{0pt},且\hspace{0pt}$F\le E_{ A } ^{ \lambda }$\nobreak\hspace{0pt},则\hspace{0pt}$E\le\allowbreak{} F\le\allowbreak{} E_{ A } ^{ \lambda }$\nobreak\hspace{0pt},故\hspace{0pt}$\bigvee_{ E\le\allowbreak{} E_{ A } ^{ \lambda } } I\left ( { A } \right )\ge\allowbreak{} \bigvee_{ F\le\allowbreak{} E_{ A } ^{ \lambda } } I\left ( { A } \right )$\nobreak\hspace{0pt},即证\hspace{0pt}$\mathcal{C}_{ I } ^{ \lambda }\left ( { E } \right )\ge\allowbreak{} \mathcal{C}_{ I } ^{ \lambda }\left ( { F } \right )$\nobreak\hspace{0pt};

（ME3）对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},令\hspace{0pt}$E\le E_{ A } ^{ \lambda }$且\hspace{0pt}$F\le E_{ B } ^{ \lambda }$\nobreak\hspace{0pt},由于
\begin{eqnarray*} \left ( { E_{ A } ^{ \lambda }\vee E_{ B } ^{ \lambda } } \right )\left ( { x,y } \right ) &=& E_{ A } ^{ \lambda }\left ( { x,y } \right ) \\ \vee E_{ B } ^{ \lambda }\left ( { x,y } \right ) &=& A\left ( { x ^ { -1 } y } \right )\vee B\left ( { x ^ { -1 } y } \right ) \\  &=& \left ( { A\vee B } \right )\left ( { x ^ { -1 } y } \right )=E_{ A\vee B } ^{ \lambda }\left ( { x,y } \right ), \end{eqnarray*}
则\hspace{0pt}$E\vee\allowbreak{} F\le\allowbreak{} E_{ A } ^{ \lambda }\vee\allowbreak{} E_{ B } ^{ \lambda }=\allowbreak{}E_{ A\vee\allowbreak{} B } ^{ \lambda }$\nobreak\hspace{0pt},故
\begin{eqnarray*} \mathcal{C}_{ I } ^{ \lambda }\left ( { E\vee F } \right ) &=& \bigvee_{ E\vee F\le E_{ A\vee B } ^{ \lambda } } I\left ( { A\vee B } \right ) \\  &\ge& \bigvee_{ E\vee F\le E_{ A\vee B } ^{ \lambda } } \left ( { I\left ( { A } \right )\wedge I\left ( { B } \right ) } \right ) \\  &\ge& \bigvee_{ E\le E_{ A } ^{ \lambda },F\le E_{ B } ^{ \lambda } } \left ( { I\left ( { A } \right )\wedge I\left ( { B } \right ) } \right ) \\  &=& \bigvee_{ E\le E_{ A } ^{ \lambda } } I\left ( { A } \right )\wedge \bigvee_{ F\le E_{ B } ^{ \lambda } } I\left ( { B } \right ) \\  &=& \mathcal{C}_{ I } ^{ \lambda }\left ( { E } \right )\wedge \mathcal{C}_{ I } ^{ \lambda }\left ( { F } \right ); \end{eqnarray*}
（ME4）对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},令\hspace{0pt}$E\le E_{ A } ^{ \lambda }$且\hspace{0pt}$F\le E_{ B } ^{ \lambda }$\nobreak\hspace{0pt},由于
\begin{eqnarray*} \left ( { E_{ A } ^{ \lambda }\circ E_{ B } ^{ \lambda } } \right )\left ( { x,z } \right ) \\  &=& \bigvee_{ y\in G } \left ( { E_{ B } ^{ \lambda }\left ( { x,y } \right )\wedge E_{ A } ^{ \lambda }\left ( { y,z } \right ) } \right ) \\  &=& \bigvee_{ y\in G } \left ( { B\left ( { x ^ { -1 } y } \right )\wedge A\left ( { y ^ { -1 } z } \right ) } \right ) \\  &=& \bigvee_{ y\in G } \left ( { B\left ( { x ^ { -1 } y } \right )\wedge A\left ( { \left ( { x ^ { -1 } y } \right ) ^ { -1 } \left ( { x ^ { -1 } z } \right ) } \right ) } \right ) \\  &=& \bigvee_{ w\in G } \left ( { B\left ( { w } \right )\wedge A\left ( { w ^ { -1 } \left ( { x ^ { -1 } z } \right ) } \right ) } \right ) \\  &=& \left ( { AB } \right )\left ( { x ^ { -1 } z } \right )=E_{ AB } ^{ \lambda }\left ( { x,z } \right ), \end{eqnarray*}
则\hspace{0pt}$E\circ F\le\allowbreak{} E_{ A } ^{ \lambda }\circ E_{ B } ^{ \lambda }=\allowbreak{}E_{ AB } ^{ \lambda }$\nobreak\hspace{0pt},故\hspace{0pt}$I(A)\wedge\allowbreak{} I(B)\leq\allowbreak{} I(AB)\leq\allowbreak{}\bigvee_{E\circ F\leq\allowbreak{} E_{AB}^{\lambda}}I(AB)=\allowbreak{}\mathcal{C}_{I}^{\lambda}(E\circ F)$\nobreak\hspace{0pt},则

\begin{eqnarray*} I_{ d } \left ( { AB } \right ) &=& \bigvee_{ t>0 } \bigwedge_{ x\in G } \left ( { \left ( { AB } \right )\left ( { x } \right )\to d\left ( { e,x,t } \right ) } \right ) \\  &\ge& \bigvee_{ t>0 } \bigwedge_{ \substack{ yz=x \\ y,z\in G } } \left ( { \left ( { A\left ( { y } \right )\to d\left ( { e,y,\frac { t } { 2 } } \right ) } \right )\wedge \left ( { B\left ( { z } \right )\to d\left ( { e,z,\frac { t } { 2 } } \right ) } \right ) } \right ) \\  &\ge& I_{ d } \left ( { A } \right )\wedge I_{ d } \left ( { B } \right ); \end{eqnarray*}
（IM5）由于\hspace{0pt}$A ^ { -1 } \left ( { x } \right )=\allowbreak{}A\left ( { x ^ { -1 } } \right )$\nobreak\hspace{0pt}，则

\begin{eqnarray*} I_{ d } \left ( { A ^ { -1 } } \right ) &=& \bigvee_{ t>0 } \bigwedge_{ x\in G } \left ( { A ^ { -1 } \left ( { x } \right )\to d\left ( { e,x,t } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ x\in G } \left ( { A\left ( { x ^ { -1 } } \right )\to d\left ( { e,x,t } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ x ^ { -1 } \in G } \left ( { A\left ( { x ^ { -1 } } \right )\to d\left ( { e,x ^ { -1 } ,t } \right ) } \right ) \\  &=& I_{ d } \left ( { A } \right ). \end{eqnarray*}


\textbf{命题4.2.8.}  \hspace{0pt}$d:G\times G\times \left[ 0,\infty \right]\to\allowbreak{} \left[ 0,1 \right]$是一个左不变KM-模糊伪度量,则\hspace{0pt}$\mathcal{C}_{ d } =\allowbreak{}\mathcal{C}_{ I_{ d } } ^{ \lambda }$\nobreak\hspace{0pt},其中对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$\mathcal{C}_{ d } \left ( { E } \right )=\allowbreak{}\bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in\allowbreak{} G\times G } \left ( { E\left ( { x,y } \right )\to\allowbreak{} d\left ( { x,y,t } \right ) } \right )$\nobreak\hspace{0pt}.

\textbf{证明：} 由于
\begin{eqnarray*} \mathcal{C}_{ I_{ d } } \left ( { E } \right ) &=& \bigvee_{ E\le E_{ A } ^{ \lambda } } I_{ d } \left ( { A } \right ) \\  &=& \bigvee_{ E\le E_{ A } ^{ \lambda } } \bigvee_{ t>0 } \bigwedge_{ z\in G } \left ( { A\left ( { z } \right )\to d\left ( { e,z,t } \right ) } \right ), \end{eqnarray*}
即证对\hspace{0pt}$\forall t>0$\nobreak\hspace{0pt},有
\begin{eqnarray*} \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { E\left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ) \\  &=& \bigvee_{ E\le E_{ A } ^{ \lambda } } \bigwedge_{ z\in G } \left ( { A\left ( { z } \right )\to d\left ( { e,z,t } \right ) } \right ), \end{eqnarray*}
（充分性）对\hspace{0pt}$\forall A\in L ^ { G }$\nobreak\hspace{0pt},令\hspace{0pt}$A\left ( { z } \right )=\allowbreak{}GE\left ( { e,z } \right )$\nobreak\hspace{0pt}，其中\hspace{0pt}$GE\left ( { x,y } \right )=\allowbreak{}\bigvee_{ g\in\allowbreak{} G } E\left ( { gx,gy } \right )$\nobreak\hspace{0pt},由于\hspace{0pt}$GE$是左不变的，则\hspace{0pt}$GE\left ( { x,y } \right )=\allowbreak{}GE\left ( { e,x ^ { -1 } y } \right )=\allowbreak{}A\left ( { x ^ { -1 } y } \right )=\allowbreak{}E_{ A } ^{ \lambda }\left ( { x,y } \right )$\nobreak\hspace{0pt},因此\hspace{0pt}$E\le GE=E_{ A } ^{ \lambda }$\nobreak\hspace{0pt},又由于\hspace{0pt}$\mathcal{C}_{ d } \left ( { E } \right )=\allowbreak{}\mathcal{C}_{ d } \left ( { GE } \right )$\nobreak\hspace{0pt},则
\begin{eqnarray*} I_{ d } \left ( { A } \right ) &=& \bigvee_{ t>0 } \bigwedge_{ z\in G } \left ( { A\left ( { z } \right )\to d\left ( { e,z,t } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ z\in G } \left ( { GE\left ( { e,z } \right )\to d\left ( { e,z,t } \right ) } \right ), \end{eqnarray*}
令\hspace{0pt}$z=x ^ { -1 } y$\nobreak\hspace{0pt}，则\hspace{0pt}$d\left ( { e,z,t } \right )=\allowbreak{}d\left ( { x,y,t } \right )$且\hspace{0pt}$GE\left ( { e,z } \right )=\allowbreak{}GE\left ( { x,y } \right )$\nobreak\hspace{0pt},故
\begin{eqnarray*} \bigwedge_{ z\in G } \left ( { GE\left ( { e,z } \right )\to d\left ( { e,z,t } \right ) } \right ) \\  &=& \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { GE\left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ), \end{eqnarray*}
上式两边对\hspace{0pt}$t$取上确界,则\hspace{0pt}$I_{ d } \left ( { A } \right )=\allowbreak{}\mathcal{C}_{ d } \left ( { GE } \right )=\allowbreak{}\mathcal{C}_{ d } \left ( { E } \right )$\nobreak\hspace{0pt},故\hspace{0pt}$\mathcal{C}_{ I_{ d } } ^{ \lambda }\left ( { E } \right )=\allowbreak{}\bigvee_{ E\le\allowbreak{} E_{ A } ^{ \lambda } } I_{ d } \left ( { A } \right )\ge\allowbreak{} \mathcal{C}_{ d }$\nobreak\hspace{0pt};

（必要性）对\hspace{0pt}$\forall A\in L ^ { G }$\nobreak\hspace{0pt},若满足\hspace{0pt}$E\le E_{ A } ^{ \lambda }$\nobreak\hspace{0pt},则对\hspace{0pt}$\forall x,y\in G$\nobreak\hspace{0pt}，\hspace{0pt}$E\left ( { x,y } \right )\le\allowbreak{} E_{ A } ^{ \lambda }\left ( { x,y } \right )=\allowbreak{}A\left ( { x ^ { -1 } y } \right )$\nobreak\hspace{0pt},由于\hspace{0pt}$d\left ( { e,x ^ { -1 } y,t } \right )=\allowbreak{}d\left ( { x,y,t } \right )$\nobreak\hspace{0pt},因此对\hspace{0pt}$\forall t>0$\nobreak\hspace{0pt},
\begin{eqnarray*} \bigwedge_{ z\in G } \left ( { A\left ( { z } \right )\to d\left ( { e,z,t } \right ) } \right ) \\  &\le& A\left ( { x ^ { -1 } y } \right )\to d\left ( { e,x ^ { -1 } y,t } \right )\le E\left ( { x,y } \right )\to d\left ( { x,y,t } \right ), \end{eqnarray*}
\begin{eqnarray*} \bigwedge_{ z\in G } \left ( { A\left ( { z } \right )\to d\left ( { e,z,t } \right ) } \right ) \\  &\le& \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { E\left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ), \end{eqnarray*}
两边对\hspace{0pt}$t>0$取上确界，则\hspace{0pt}$I_{ d } \left ( { A } \right )\le\allowbreak{} \mathcal{C}_{ d } \left ( { E } \right )$\nobreak\hspace{0pt},故\hspace{0pt}$\mathcal{C}_{ I_{ d } } ^{ \lambda }\left ( { E } \right )=\allowbreak{}\bigvee_{ E\le\allowbreak{} E_{ A } ^{ \lambda } } I_{ d } \left ( { A } \right )\le\allowbreak{} \mathcal{C}_{ d }$\nobreak\hspace{0pt}.


\chapter{粗邻近及其相关结构}
\section{$(L,M)$-模糊粗邻近}
\vspace{0.2cm}
\textbf{定义5.1.1.}  集合\hspace{0pt}$X$上的一个\hspace{0pt}$\left ( { L,M } \right )$-模糊囿结构是一个映射\hspace{0pt}$\mathcal{B} :L ^ { X } \to M$\nobreak\hspace{0pt}，满足：

对\hspace{0pt}$\forall x\in X$\nobreak\hspace{0pt}，\hspace{0pt}$\mathcal{B} \left ( { \mathcal{X}_{ \left \{ \begin{array}{l} x \end{array} \right \} } } \right )=\allowbreak{}\top$\nobreak\hspace{0pt}；

对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$A\le B$\nobreak\hspace{0pt}，\hspace{0pt}$\mathcal{B} \left ( { B } \right )\le\allowbreak{} \mathcal{B} \left ( { A } \right )$\nobreak\hspace{0pt}；

对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$\mathcal{B} \left ( { A\vee\allowbreak{} B } \right )\ge\allowbreak{} \mathcal{B} \left ( { A } \right )\wedge\allowbreak{} \mathcal{B} \left ( { B } \right )$\nobreak\hspace{0pt}.

则\hspace{0pt}$\left ( { X,\mathcal{B} } \right )$称为\hspace{0pt}$\left ( { L,M } \right )$-模糊囿空间，\hspace{0pt}$\mathcal{B}$中的元素成为有界的。

\textbf{注5.1.2.}  （1）一个\hspace{0pt}$\left ( { L,M } \right )$-模糊囿结构满足\hspace{0pt}$\mathcal{B} \left ( { \top _{ M } } \right )=\allowbreak{}\bot$\nobreak\hspace{0pt}，则称为\hspace{0pt}$\left ( { L,M } \right )$-模糊真囿结构；

（2）由定义5.1.1可知，对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$\mathcal{B} \left ( { A\vee\allowbreak{} B } \right )=\allowbreak{}\mathcal{B} \left ( { A } \right )\wedge\allowbreak{} \mathcal{B} \left ( { B } \right )$也成立。

\textbf{例5.1.3.}  设\hspace{0pt}$\left ( { X,d } \right )$是一个经典的度量空间，对\hspace{0pt}$\forall x_{ 0 } \in X$\nobreak\hspace{0pt}，定义\hspace{0pt}$\mathcal{B} :\left[ 0,1 \right] ^ { X } \to\allowbreak{} \left[ 0,1 \right]$\nobreak\hspace{0pt}，
$$\mathcal{B} \left ( { A } \right )=\bigvee_{ r>0 } \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r } A'\left ( { x } \right )\text{，}$$
则\hspace{0pt}$\left ( { X,\mathcal{B} } \right )$称为\hspace{0pt}$\left ( { L,M } \right )$-模糊囿空间。

\textbf{证明：} （1）对\hspace{0pt}$\forall y\in X$\nobreak\hspace{0pt}，取\hspace{0pt}$r_{ 0 } =\allowbreak{}d\left ( { y,x_{ 0 } } \right )+1$\nobreak\hspace{0pt}，满足对\hspace{0pt}$\forall x\in X$\nobreak\hspace{0pt}，\hspace{0pt}$d\left ( { x,x_{ 0 } } \right )>r_{ 0 }$\nobreak\hspace{0pt}，则\hspace{0pt}$x\ne y$\nobreak\hspace{0pt}，故\hspace{0pt}$\mathcal{X}_{ \left \{ \begin{array}{l} y \end{array} \right \} } \left ( { x } \right )=\allowbreak{}0$\nobreak\hspace{0pt}，则\hspace{0pt}$\mathcal{X}_{ \left \{ \begin{array}{l} y \end{array} \right \} } '\left ( { x } \right )=\allowbreak{}1$\nobreak\hspace{0pt}，即\hspace{0pt}$\bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r } \mathcal{X}_{ \left \{ \begin{array}{l} y \end{array} \right \} } '\left ( { x } \right )=\allowbreak{}1$\nobreak\hspace{0pt}，
\begin{eqnarray*} \mathcal{B} \left ( { \mathcal{X}_{ \left \{ \begin{array}{l} y \end{array} \right \} } } \right ) \\  &=& \bigvee_{ r>0 } \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r } \mathcal{X}_{ \left \{ \begin{array}{l} y \end{array} \right \} } '\left ( { x } \right )=1\text{；} \end{eqnarray*}


（2）对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$A\le B$\nobreak\hspace{0pt}，则对\hspace{0pt}$\forall x\in X$\nobreak\hspace{0pt}，\hspace{0pt}$A\left ( { x } \right )\le\allowbreak{} B\left ( { x } \right )$\nobreak\hspace{0pt}，则\hspace{0pt}$A'\left ( { x } \right )\ge\allowbreak{} B'\left ( { x } \right )$\nobreak\hspace{0pt}，所以对给定的\hspace{0pt}$r>0$\nobreak\hspace{0pt}，\hspace{0pt}$\bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r } A'\left ( { x } \right )\ge\allowbreak{} \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r } B'\left ( { x } \right )$\nobreak\hspace{0pt}，故
\begin{eqnarray*} \mathcal{B} \left ( { A } \right ) &=& \bigvee_{ r>0 } \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r } A'\left ( { x } \right ) \\  &\ge& \bigvee_{ r>0 } \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r } B'\left ( { x } \right )=\mathcal{B} \left ( { B } \right )\text{；} \end{eqnarray*}
（3）对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，由于
\begin{eqnarray*} \mathcal{B} \left ( { A } \right )\wedge \mathcal{B} \left ( { B } \right ) &=& \left ( { \bigvee_{ r_{ 1 } >0 } \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r_{ 1 } } A'\left ( { x } \right ) } \right ) \\ \wedge \left ( { \bigvee_{ r_{ 2 } >0 } \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r_{ 2 } } B'\left ( { x } \right ) } \right ) \\  &=& \bigvee_{ r_{ 1 } >0 } \bigvee_{ r_{ 2 } >0 } \left ( { \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r_{ 1 } } A'\left ( { x } \right )\wedge \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r_{ 2 } } B'\left ( { x } \right ) } \right ) \end{eqnarray*}
取\hspace{0pt}$r=\allowbreak{}max\left \{ \begin{array}{l} r_{ 1 } ,r_{ 2 } \end{array} \right \}$\nobreak\hspace{0pt}，则
\begin{eqnarray*} \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r_{ 1 } } A'\left ( { x } \right )\wedge \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r_{ 2 } } B'\left ( { x } \right ) \\  &\le& \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r } A'\left ( { x } \right )\wedge \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r } B'\left ( { x } \right ) \\  &\le& \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r } \left ( { A'\left ( { x } \right )\wedge B'\left ( { x } \right ) } \right ) \\  &=& \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r } \left ( { A\vee B } \right )'\left ( { x } \right ) \end{eqnarray*}
故
\begin{eqnarray*} \mathcal{B} \left ( { A } \right )\wedge \mathcal{B} \left ( { B } \right ) &=& \bigvee_{ r_{ 1 } >0 } \bigvee_{ r_{ 2 } >0 } \left ( { \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r_{ 1 } } A'\left ( { x } \right )\wedge \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r_{ 2 } } B'\left ( { x } \right ) } \right ) \\  &\le& \bigvee_{ r>0 } \bigwedge_{ d\left ( { x,x_{ 0 } } \right )>r } \left ( { A\vee B } \right )'\left ( { x } \right )=\mathcal{B} \left ( { A\vee B } \right )\text{。} \end{eqnarray*}


\textbf{定义5.1.4.}  \hspace{0pt}$\left ( { X,\mathcal{B} } \right )$是一个\hspace{0pt}$\left ( { L,M } \right )$-模糊囿空间，定义映射\hspace{0pt}$\delta :L ^ { X } \times L ^ { X } \to\allowbreak{} M$是\hspace{0pt}$X$上的一个\hspace{0pt}$\left ( { L,M } \right )$-模糊粗邻近，若它满足：

对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$\delta \left ( { A,B } \right )=\allowbreak{}\delta \left ( { B,A } \right )$\nobreak\hspace{0pt}；

对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$\delta \left ( { A,B } \right )\le\allowbreak{} \mathcal{B} '\left ( { A } \right )\wedge\allowbreak{} \mathcal{B} '\left ( { B } \right )$\nobreak\hspace{0pt}；

对\hspace{0pt}$\forall A,B,C\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$\delta \left ( { A\vee\allowbreak{} B,C } \right )\le\allowbreak{} \delta \left ( { A,C } \right )\vee\allowbreak{} \delta \left ( { B,C } \right )$\nobreak\hspace{0pt}；

对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$\delta \left ( { A,B } \right )\ge\allowbreak{} \bigwedge_{ D\in\allowbreak{} L ^ { X } } \left ( { \delta \left ( { A,D } \right )\vee\allowbreak{} \delta \left ( { D',B } \right ) } \right )$\nobreak\hspace{0pt}；

对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$\delta '\left ( { A,B } \right )\le\allowbreak{} \mathcal{B} \left ( { A\wedge\allowbreak{} B } \right )$\nobreak\hspace{0pt}.

则\hspace{0pt}$\left ( { X,\mathcal{B} ,\delta } \right )$称为\hspace{0pt}$\left ( { L,M } \right )$-模糊粗邻近空间。

\textbf{注5.1.5.}  若\hspace{0pt}$L=\allowbreak{}\left \{ \begin{array}{l} 0,1 \end{array} \right \}$\nobreak\hspace{0pt}，\hspace{0pt}$M$保留为一般的完全分配格，则退化为石老师定义的L-值粗邻近；若\hspace{0pt}$L,M=\allowbreak{}\left \{ \begin{array}{l} 0,1 \end{array} \right \}$\nobreak\hspace{0pt}，则退化为经典意义下的粗邻近

\textbf{注5.1.6.}  设\hspace{0pt}$\left ( { X,\mathcal{B} ,\delta } \right )$为一个\hspace{0pt}$\left ( { L,M } \right )$-模糊粗邻近空间，若\hspace{0pt}$\mathcal{B} \left ( { A } \right )=\allowbreak{}\top$\nobreak\hspace{0pt}，则对\hspace{0pt}$\forall B\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$\delta \left ( { A,B } \right )=\allowbreak{}\bot$\nobreak\hspace{0pt}；特别地，若\hspace{0pt}$\mathcal{B} \left ( { \top _{ M } } \right )=\allowbreak{}\top$\nobreak\hspace{0pt}，则\hspace{0pt}$\delta$恒为\hspace{0pt}$\bot$\nobreak\hspace{0pt}。

\textbf{例5.1.7.}  设\hspace{0pt}$\mathcal{B} :L ^ { X } \to M$为非空集合\hspace{0pt}$X$上的一个\hspace{0pt}$\left ( { L,M } \right )$-模糊真囿结构，定义\hspace{0pt}$\delta _{ 1 } ,\delta _{ 2 } :L ^ { X } \times L ^ { X } \to\allowbreak{} M$分别为，对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，
\begin{eqnarray*} \delta _{ 1 } \left ( { A,B } \right ) &=& \mathcal{B} '\left ( { A\wedge B } \right )\text{，}\delta _{ 2 } \left ( { A,B } \right )=\mathcal{B} '\left ( { A } \right ) \\ \wedge \mathcal{B} '\left ( { B } \right )\text{，} \end{eqnarray*}
则称\hspace{0pt}$\delta _{ 1 }$为\hspace{0pt}$\left ( { L,M } \right )$-模糊离散粗邻近，\hspace{0pt}$\delta _{ 2 }$为\hspace{0pt}$\left ( { L,M } \right )$-模糊平凡粗邻近。

\textbf{命题5.1.8.}  设\hspace{0pt}$\left ( { X,\mathcal{B} ,\delta } \right )$为一个\hspace{0pt}$\left ( { L,M } \right )$-模糊粗邻近空间，对\hspace{0pt}$\forall A,B,C,D\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$A\le C$\nobreak\hspace{0pt}，\hspace{0pt}$B\le D$\nobreak\hspace{0pt}，则\hspace{0pt}$\delta \left ( { A,B } \right )\le\allowbreak{} \delta \left ( { C,D } \right )$\nobreak\hspace{0pt}。

\textbf{证明：} 由于\hspace{0pt}$A\le C$\nobreak\hspace{0pt}，\hspace{0pt}$B\le D$\nobreak\hspace{0pt}，则\hspace{0pt}$A\vee C=C$\nobreak\hspace{0pt}，\hspace{0pt}$B\vee D=D$\nobreak\hspace{0pt}，故
$$\delta \left ( { C,D } \right )=\delta \left ( { A\vee C,D } \right )=\delta \left ( { A,D } \right )\vee \delta \left ( { C,D } \right )\text{，}$$
所以\hspace{0pt}$\delta \left ( { A,D } \right )\le\allowbreak{} \delta \left ( { C,D } \right )$\nobreak\hspace{0pt}，同理可得\hspace{0pt}$\delta \left ( { A,B } \right )\le\allowbreak{} \delta \left ( { A,D } \right )$\nobreak\hspace{0pt}，故\hspace{0pt}$\delta \left ( { A,B } \right )\le\allowbreak{} \delta \left ( { C,D } \right )$\nobreak\hspace{0pt}。

\textbf{命题5.1.9.}  设\hspace{0pt}$\left ( { X,\mathcal{B} ,\delta } \right )$为一个\hspace{0pt}$\left ( { L,M } \right )$-模糊粗邻近空间，对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，有
$$\delta \left ( { A,B } \right )\le \bigwedge_{ D\in L ^ { X } } \left ( { \delta \left ( { A,D } \right )\vee \delta \left ( { D',B } \right ) } \right )\text{。}$$
\textbf{证明：} 对\hspace{0pt}$\forall D\in L ^ { X }$\nobreak\hspace{0pt}，由于\hspace{0pt}$B\le\allowbreak{} D\vee\allowbreak{} \left ( { B\wedge\allowbreak{} D' } \right )$\nobreak\hspace{0pt}，则
\begin{eqnarray*} \delta \left ( { A,B } \right ) &\le& \delta \left ( { A,D\vee \left ( { B\wedge D' } \right ) } \right )=\delta \left ( { A,D } \right ) \\ \vee \delta \left ( { A,B\wedge D' } \right )\text{，} \end{eqnarray*}
而\hspace{0pt}$\delta '\left ( { B,D' } \right )\le\allowbreak{} \mathcal{B} \left ( { B\wedge\allowbreak{} D' } \right )$\nobreak\hspace{0pt}，则\hspace{0pt}$\delta \left ( { B,D' } \right )\ge\allowbreak{} \mathcal{B} '\left ( { B\wedge\allowbreak{} D' } \right )$\nobreak\hspace{0pt}，所以
\begin{eqnarray*} \delta \left ( { A,B\wedge D' } \right ) &\le& \mathcal{B} '\left ( { A } \right )\wedge \mathcal{B} '\left ( { B\wedge D' } \right ) \\  &\le& \mathcal{B} '\left ( { B\wedge D' } \right )\le \delta \left ( { B,D' } \right )\text{，} \end{eqnarray*}
故\hspace{0pt}$\delta \left ( { A,B } \right )\le\allowbreak{} \delta \left ( { A,D } \right )\vee\allowbreak{} \delta \left ( { D',B } \right )$\nobreak\hspace{0pt}，得证。

\textbf{定义5.1.10.}  设\hspace{0pt}$\left ( { X,\mathcal{B} ,\delta } \right )$为一个\hspace{0pt}$\left ( { L,M } \right )$-模糊粗邻近空间，\newline 定义映射\hspace{0pt}$N_{ \delta } :L ^ { X } \times L ^ { X } \to\allowbreak{} M$\nobreak\hspace{0pt}，对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$N_{ \delta } \left ( { A,B } \right )=\allowbreak{}\left ( { \delta \left ( { A,B' } \right ) } \right )'$\nobreak\hspace{0pt}，\hspace{0pt}$N_{ \delta }$称为由\hspace{0pt}$\delta$诱导的\hspace{0pt}$\left ( { L,M } \right )$-模糊粗邻域。

\textbf{定理5.1.11.}  设\hspace{0pt}$\left ( { X,\mathcal{B} ,\delta } \right )$为一个\hspace{0pt}$\left ( { L,M } \right )$-模糊粗邻近空间，\newline \hspace{0pt}$N_{ \delta }$称为由\hspace{0pt}$\delta$诱导的\hspace{0pt}$\left ( { L,M } \right )$-模糊粗邻域，\newline 则：对\hspace{0pt}$\forall A,B,C\in L ^ { X }$

（1）\hspace{0pt}$\mathcal{B} \left ( { A } \right )\le\allowbreak{} N_{ \delta } \left ( { A,B } \right )$\nobreak\hspace{0pt}；

（2）\hspace{0pt}$N_{ \delta } \left ( { A,B } \right )\le\allowbreak{} \mathcal{B} \left ( { A\wedge\allowbreak{} B' } \right )$\nobreak\hspace{0pt}；

（3）若\hspace{0pt}$A\le B$\nobreak\hspace{0pt}，则\hspace{0pt}$N_{ \delta } \left ( { B,C } \right )\le\allowbreak{} N_{ \delta } \left ( { A,C } \right )$\nobreak\hspace{0pt}；

（4）若\hspace{0pt}$B\le C$\nobreak\hspace{0pt}，则\hspace{0pt}$N_{ \delta } \left ( { A,B } \right )\le\allowbreak{} N_{ \delta } \left ( { A,C } \right )$\nobreak\hspace{0pt}；

（5）\hspace{0pt}$\mathcal{B} \left ( { A\wedge\allowbreak{} B' } \right )\wedge\allowbreak{} N_{ \delta } \left ( { B,C } \right )\le\allowbreak{} N_{ \delta } \left ( { A,C } \right )$\nobreak\hspace{0pt}；

（6）\hspace{0pt}$N_{ \delta } \left ( { A,B } \right )\wedge\allowbreak{} N_{ \delta } \left ( { B,C } \right )\le\allowbreak{} N_{ \delta } \left ( { A,C } \right )$\nobreak\hspace{0pt}；

（7）\hspace{0pt}$N_{ \delta } \left ( { A,B } \right )\wedge\allowbreak{} N_{ \delta } \left ( { A,B' } \right )\le\allowbreak{} \mathcal{B} \left ( { A } \right )$\nobreak\hspace{0pt}；

（8）\hspace{0pt}$N_{ \delta } \left ( { A,B } \right )=\allowbreak{}N_{ \delta } \left ( { B',A' } \right )$\nobreak\hspace{0pt}。

\textbf{证明：} （1）对\hspace{0pt}$\forall A,B'\in L ^ { X }$\nobreak\hspace{0pt}，由于\hspace{0pt}$\delta \left ( { A,B' } \right )\le\allowbreak{} \mathcal{B} '\left ( { A } \right )\wedge\allowbreak{} \mathcal{B} '\left ( { B' } \right )$\nobreak\hspace{0pt}，所以\hspace{0pt}$\delta \left ( { A,B' } \right )\le\allowbreak{} \mathcal{B} '\left ( { A } \right )$\nobreak\hspace{0pt}，故
$$N_{ \delta } \left ( { A,B } \right )=\left ( { \delta \left ( { A,B' } \right ) } \right )'\ge \mathcal{B} \left ( { A } \right )\text{；}$$
（2）对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，由于\hspace{0pt}$\delta '\left ( { A,B } \right )\le\allowbreak{} \mathcal{B} \left ( { A\wedge\allowbreak{} B } \right )$\nobreak\hspace{0pt}，则\newline \hspace{0pt}$N_{ \delta } \left ( { A,B } \right )=\allowbreak{}\delta '\left ( { A,B' } \right )\le\allowbreak{} \mathcal{B} \left ( { A\wedge\allowbreak{} B' } \right )$\nobreak\hspace{0pt}；

（3）对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$A\le B$\nobreak\hspace{0pt}，则\hspace{0pt}$\delta \left ( { A,C' } \right )\le\allowbreak{} \delta \left ( { B,C' } \right )$\nobreak\hspace{0pt}，故
$$N_{ \delta } \left ( { A,C } \right )=\delta '\left ( { A,C' } \right )\ge \delta '\left ( { B,C' } \right )=N_{ \delta } \left ( { B,C } \right )\text{；}$$
（4）与（3）同理；

（5）对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，由于\hspace{0pt}$A\le\allowbreak{} B\vee\allowbreak{} \left ( { A\wedge\allowbreak{} B' } \right )$\nobreak\hspace{0pt}，则
\begin{eqnarray*} \delta \left ( { A,C' } \right ) &\le& \delta \left ( { B\vee \left ( { A\wedge B' } \right ),C' } \right )=\delta \left ( { B,C' } \right ) \\ \vee \delta \left ( { A\wedge B',C' } \right ) \end{eqnarray*}
又
\begin{eqnarray*} \delta \left ( { A\wedge B',C' } \right ) &\le& \mathcal{B} '\left ( { A\wedge B' } \right )\wedge \mathcal{B} '\left ( { C' } \right ) \\  &\le& \mathcal{B} '\left ( { A\wedge B' } \right )\text{，} \end{eqnarray*}
则\hspace{0pt}$\delta \left ( { A,C' } \right )\le\allowbreak{} \delta \left ( { B,C' } \right )\vee\allowbreak{} \mathcal{B} '\left ( { A\wedge\allowbreak{} B' } \right )$\nobreak\hspace{0pt}，即
\begin{eqnarray*} N_{ \delta } \left ( { A,C } \right ) &=& \delta '\left ( { A,C' } \right )\ge \delta '\left ( { B,C' } \right )\wedge \mathcal{B} \left ( { A\wedge B' } \right ) \\  &=& N_{ \delta } \left ( { B,C } \right )\wedge \mathcal{B} \left ( { A\wedge B' } \right )\text{；} \end{eqnarray*}
（6）对\hspace{0pt}$\forall A,B,C\in L ^ { X }$\nobreak\hspace{0pt}，由于\hspace{0pt}$\delta \left ( { A,C' } \right )=\allowbreak{}\bigwedge_{ E\in\allowbreak{} L ^ { X } } \left ( { \delta \left ( { A,E } \right )\vee\allowbreak{} \delta \left ( { E',C' } \right ) } \right )$\nobreak\hspace{0pt}，取\hspace{0pt}$E=B'$\nobreak\hspace{0pt}，则\hspace{0pt}$\delta \left ( { A,C' } \right )\le\allowbreak{} \delta \left ( { A,B' } \right )\vee\allowbreak{} \delta \left ( { B,C' } \right )$\nobreak\hspace{0pt}，故
\begin{eqnarray*} N_{ \delta } \left ( { A,C } \right ) &=& \delta '\left ( { A,C' } \right )\ge \delta '\left ( { A,B' } \right )\wedge \delta '\left ( { B,C' } \right ) \\  &=& N_{ \delta } \left ( { A,B } \right )\wedge N_{ \delta } \left ( { B,C } \right )\text{；} \end{eqnarray*}
（7）由于\hspace{0pt}$N_{ \delta } \left ( { A,B } \right )\wedge\allowbreak{} N_{ \delta } \left ( { B,A' } \right )\le\allowbreak{} N_{ \delta } \left ( { A,A' } \right )$\nobreak\hspace{0pt}，而\newline \hspace{0pt}$N_{ \delta } \left ( { B,A' } \right )=\allowbreak{}\delta '\left ( { B,A } \right )=\allowbreak{}\delta '\left ( { A,B } \right )$\nobreak\hspace{0pt}，同理\newline \hspace{0pt}$N_{ \delta } \left ( { A,B' } \right )=\allowbreak{}\delta '\left ( { A,B } \right )$\nobreak\hspace{0pt}，则\newline \hspace{0pt}$N_{ \delta } \left ( { A,B' } \right )=\allowbreak{}N_{ \delta } \left ( { B,A' } \right )$\nobreak\hspace{0pt}，故\newline \hspace{0pt}$N_{ \delta } \left ( { A,B } \right )\wedge\allowbreak{} N_{ \delta } \left ( { A,B' } \right )\le\allowbreak{} N_{ \delta } \left ( { A,A' } \right )$\nobreak\hspace{0pt}，又由于\newline \hspace{0pt}$N_{ \delta } \left ( { A,A' } \right )=\allowbreak{}\delta '\left ( { A,A } \right )\le\allowbreak{} \mathcal{B} \left ( { A\wedge\allowbreak{} A } \right )=\allowbreak{}\mathcal{B} \left ( { A } \right )$\nobreak\hspace{0pt}，则\newline \hspace{0pt}$N_{ \delta } \left ( { A,B } \right )\wedge\allowbreak{} N_{ \delta } \left ( { A,B' } \right )\le\allowbreak{} \mathcal{B} \left ( { A } \right )$\nobreak\hspace{0pt}；

（8）对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$N_{ \delta } \left ( { B',A' } \right )=\allowbreak{}\delta '\left ( { B',A } \right )=\allowbreak{}\delta '\left ( { A,B' } \right )=\allowbreak{}N_{ \delta } \left ( { A,B } \right )$\nobreak\hspace{0pt}。

\textbf{注5.1.12.}  设\hspace{0pt}$\left ( { X,\mathcal{B} ,\delta } \right )$为一个\hspace{0pt}$\left ( { L,M } \right )$-模糊粗邻近空间，\hspace{0pt}$N_{ \delta } :L ^ { X } \times L ^ { X } \to\allowbreak{} M$是由\hspace{0pt}$\delta$诱导的\hspace{0pt}$\left ( { L,M } \right )$-模糊粗邻域，则对\hspace{0pt}$\forall A,B,D\in L ^ { X }$\nobreak\hspace{0pt}，\hspace{0pt}$\mathcal{B} \left ( { D } \right )\wedge\allowbreak{} N_{ \delta } \left ( { A,B } \right )\le\allowbreak{} N_{ \delta } \left ( { A\vee\allowbreak{} D,B } \right )$\nobreak\hspace{0pt}。

\textbf{证明：} （1）推（2）：对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，由于\hspace{0pt}$\delta \left ( { A,B' } \right )\ge\allowbreak{} \bigwedge_{ D\in\allowbreak{} L ^ { X } } \left ( { \delta \left ( { A,D } \right )\vee\allowbreak{} \delta \left ( { D',B' } \right ) } \right )$\nobreak\hspace{0pt}，则\hspace{0pt}$\delta '\left ( { A,B' } \right )\le\allowbreak{} \bigvee_{ D\in\allowbreak{} L ^ { X } } \left ( { \delta '\left ( { A,D } \right )\vee\allowbreak{} \delta '\left ( { D',B' } \right ) } \right )$\nobreak\hspace{0pt}，所以
\begin{eqnarray*} N_{ \delta } \left ( { A,B } \right ) &\le& \bigvee_{ D\in L ^ { X } } \left ( { N_{ \delta } \left ( { A,D' } \right )\wedge N_{ \delta } \left ( { D',B } \right ) } \right ) \\  &\le& \bigvee_{ C\in L ^ { X } } \left ( { N_{ \delta } \left ( { A,C } \right )\wedge N_{ \delta } \left ( { C,B } \right ) } \right )\text{；} \end{eqnarray*}
（2）推（1）：对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}，由于\hspace{0pt}$N_{ \delta } \left ( { A,B' } \right )\le\allowbreak{} \bigvee_{ C\in\allowbreak{} L ^ { X } } \left ( { N_{ \delta } \left ( { A,C } \right )\wedge\allowbreak{} N_{ \delta } \left ( { C,B' } \right ) } \right )$\nobreak\hspace{0pt}，则\hspace{0pt}$\delta '\left ( { A,B } \right )\le\allowbreak{} \bigvee_{ C\in\allowbreak{} L ^ { X } } \left ( { \delta '\left ( { A,C' } \right )\vee\allowbreak{} \delta '\left ( { C,B } \right ) } \right )$\nobreak\hspace{0pt}，所以
\begin{eqnarray*} \delta \left ( { A,B } \right ) &\ge& \bigwedge_{ C\in L ^ { X } } \left ( { \delta \left ( { A,C' } \right )\vee \delta \left ( { C,B } \right ) } \right ) \\  &\ge& \bigwedge_{ D\in L ^ { X } } \left ( { \delta \left ( { A,D } \right )\vee \delta \left ( { D',B } \right ) } \right )\text{。} \end{eqnarray*}
\section{伪$(L,M)$-模糊渐近相似性}
\vspace{0.2cm}
\textbf{定义5.2.1.}  设\hspace{0pt}$X$为一个非空集合。映射\hspace{0pt}$\varnothing :L ^ { X } \times L ^ { X } \to\allowbreak{} M$称为\hspace{0pt}$L ^ { X }$上的一个\hspace{0pt}$\left ( { L,M } \right )$-模糊等价关系，若它满足以下条件：对\hspace{0pt}$\forall A,B,C\in L ^ { X }$\nobreak\hspace{0pt}，

（1）自反性：\hspace{0pt}$\varnothing \left ( { A,A } \right )=\allowbreak{}\top$\nobreak\hspace{0pt}；

（2）对称性：\hspace{0pt}$\varnothing \left ( { A,B } \right )=\allowbreak{}\varnothing \left ( { B,A } \right )$\nobreak\hspace{0pt}；

（3）传递性：\hspace{0pt}$\varnothing \left ( { A,B } \right )\wedge\allowbreak{} \varnothing \left ( { B,C } \right )\le\allowbreak{} \varnothing \left ( { A,C } \right )$\nobreak\hspace{0pt}。

我们称\hspace{0pt}$L ^ { X }$上的一个\hspace{0pt}$\left ( { L,M } \right )$-模糊等价关系\hspace{0pt}$\varnothing$为\hspace{0pt}$X$上的一个伪\hspace{0pt}$\left ( { L,M } \right )$-模糊渐近相似性，若它满足以下条件：

（4）对\hspace{0pt}$\forall A,B,C,D\in L ^ { X }$\nobreak\hspace{0pt}，
$$\varnothing \left ( { A,B } \right )\wedge \varnothing \left ( { C,D } \right )\le \varnothing \left ( { A\vee C,B\vee D } \right )\text{。}$$
进一步地，称伪\hspace{0pt}$\left ( { L,M } \right )$-模糊渐近相似性\hspace{0pt}$\varnothing$为\hspace{0pt}$X$上的一个\hspace{0pt}$\left ( { L,M } \right )$-模糊渐近相似性，若它满足以下分解条件：

（5）对\hspace{0pt}$\forall A_{ 1 } ,A_{ 2 } ,B_{ 1 } ,B_{ 2 } \in\allowbreak{} L ^ { X }$\nobreak\hspace{0pt}，
\begin{eqnarray*} \varnothing \left ( { A_{ 1 } \vee A_{ 2 } ,B } \right ) &\le& \bigvee_{ B_{ 1 } \vee B_{ 2 } =B } \varnothing \left ( { A_{ 1 } ,B_{ 1 } } \right ) \\ \wedge \varnothing \left ( { A_{ 2 } ,B_{ 2 } } \right )\text{。} \end{eqnarray*}
\textbf{例5.2.2.}  设\hspace{0pt}$X$为一个非空集合，定义映射\hspace{0pt}$\varnothing _{ D } ,\varnothing _{ I } :L ^ { X } \times L ^ { X } \to\allowbreak{} M$为，对\hspace{0pt}$\forall A,B\in L ^ { X }$\nobreak\hspace{0pt}：
\begin{eqnarray*} \varnothing _{ D } \left ( { A,B } \right ) &=& \begin{cases} \begin{array}{c} \bot ,A\ne B \end{array} \end{cases}\text{；}\varnothing _{ I } \left ( { A,B } \right ) \\  &=& \top\text{，} \end{eqnarray*}
则\hspace{0pt}$\varnothing _{ D } ,\varnothing _{ I }$都是\hspace{0pt}$L ^ { X }$上的一个\hspace{0pt}$\left ( { L,M } \right )$-模糊渐近相似性，它们分别称为\hspace{0pt}$L ^ { X }$上的离散/平凡\hspace{0pt}$\left ( { L,M } \right )$-模糊渐近相似性。

\textbf{定理5.2.3.}  设\hspace{0pt}$\left ( { X,\mathcal{B} ,\delta } \right )$为一个\hspace{0pt}$\left ( { L,M } \right )$-模糊粗邻近空间，\newline 定义映射\hspace{0pt}$\varnothing _{ \delta } :L ^ { X } \times L ^ { X } \to\allowbreak{} M$满足：
\begin{eqnarray*} \varnothing _{ \delta } \left ( { A,B } \right ) &=& \left ( { \bigwedge_{ A_{ 1 } \le A } \mathcal{B} \left ( { A_{ 1 } } \right )\vee \delta \left ( { A_{ 1 } ,B } \right ) } \right ) \\ \wedge \left ( { \bigwedge_{ B_{ 1 } \le B } \mathcal{B} \left ( { B_{ 1 } } \right )\vee \delta \left ( { A,B_{ 1 } } \right ) } \right )\text{，} \end{eqnarray*}
则\hspace{0pt}$\varnothing _{ \delta }$称为\hspace{0pt}$X$上的一个伪\hspace{0pt}$\left ( { L,M } \right )$-模糊渐近相似性\textbf{。}

\textbf{证明：} 先证\hspace{0pt}$\varnothing _{ \delta }$为\hspace{0pt}$L ^ { X }$上的一个\hspace{0pt}$\left ( { L,M } \right )$-模糊等价关系：对\hspace{0pt}$\forall A,B,C,D\in L ^ { X }$\nobreak\hspace{0pt}，

（1）由于\hspace{0pt}$\delta \left ( { A,B } \right )=\allowbreak{}\delta \left ( { B,A } \right )$\nobreak\hspace{0pt}，所以显然\hspace{0pt}$\varnothing _{ \delta } \left ( { A,B } \right )=\allowbreak{}\varnothing _{ \delta } \left ( { B,A } \right )$\nobreak\hspace{0pt}；

（2）对\hspace{0pt}$\forall A_{ 1 } \le A$\nobreak\hspace{0pt}，由于\hspace{0pt}$\delta '\left ( { A_{ 1 } ,A } \right )\le\allowbreak{} \mathcal{B} \left ( { A_{ 1 } \wedge\allowbreak{} A } \right )=\allowbreak{}\mathcal{B} \left ( { A_{ 1 } } \right )$\nobreak\hspace{0pt}，则\hspace{0pt}$\delta \left ( { A_{ 1 } ,A } \right )\ge\allowbreak{} \mathcal{B} '\left ( { A_{ 1 } } \right )$\nobreak\hspace{0pt}，故
\begin{eqnarray*} \mathcal{B} \left ( { A_{ 1 } } \right )\vee \delta \left ( { A_{ 1 } ,A } \right ) &\ge& \mathcal{B} \left ( { A_{ 1 } } \right ) \\ \vee \mathcal{B} '\left ( { A_{ 1 } } \right ) &=& \top\text{，} \end{eqnarray*}
同理，\hspace{0pt}$\mathcal{B} \left ( { A } \right )\vee\allowbreak{} \delta \left ( { A,A_{ 1 } } \right )=\allowbreak{}\top$\nobreak\hspace{0pt}，则\hspace{0pt}$\varnothing _{ \delta } \left ( { A,A } \right )=\allowbreak{}\top$\nobreak\hspace{0pt}；

（3）对\hspace{0pt}$\forall A_{ 1 } \le A$\nobreak\hspace{0pt}，由于\hspace{0pt}$B\le\allowbreak{} D\vee\allowbreak{} \left ( { B\wedge\allowbreak{} D' } \right )$\nobreak\hspace{0pt}，则
\begin{eqnarray*} \delta \left ( { A_{ 1 } ,B } \right ) &\le& \delta \left ( { A_{ 1 } ,D\vee \left ( { B\wedge D' } \right ) } \right )=\delta \left ( { A_{ 1 } ,D } \right ) \\ \vee \delta \left ( { A_{ 1 } ,B\wedge D' } \right )\text{，} \end{eqnarray*}
又因为
\begin{eqnarray*} \delta \left ( { A_{ 1 } ,B\wedge D' } \right ) &\le& \mathcal{B} '\left ( { A_{ 1 } } \right )\wedge \mathcal{B} '\left ( { B\wedge D' } \right ) \\  &\le& \mathcal{B} '\left ( { B\wedge D' } \right )\text{，} \end{eqnarray*}
所以\hspace{0pt}$\delta \left ( { A_{ 1 } ,B } \right )\le\allowbreak{} \delta \left ( { A_{ 1 } ,D } \right )\vee\allowbreak{} \mathcal{B} '\left ( { B\wedge\allowbreak{} D' } \right )$\nobreak\hspace{0pt}，则
\begin{eqnarray*} \varnothing _{ \delta } \left ( { A,B } \right ) &=& \left ( { \bigwedge_{ A_{ 1 } \le A } \mathcal{B} \left ( { A_{ 1 } } \right )\vee \delta \left ( { A_{ 1 } ,B } \right ) } \right ) \\ \wedge \left ( { \bigwedge_{ B_{ 1 } \le B } \mathcal{B} \left ( { B_{ 1 } } \right )\vee \delta \left ( { A,B_{ 1 } } \right ) } \right ) \\  &\le& \mathcal{B} \left ( { A_{ 1 } } \right )\vee \delta \left ( { A_{ 1 } ,B } \right )\le \mathcal{B} \left ( { A_{ 1 } } \right ) \\ \vee \delta \left ( { A_{ 1 } ,D } \right )\vee \mathcal{B} '\left ( { B\wedge D' } \right )\text{，} \end{eqnarray*}
由于\hspace{0pt}$B\wedge D'\le B$\nobreak\hspace{0pt}，则
\begin{eqnarray*} \varnothing _{ \delta } \left ( { B,C } \right ) &=& \left ( { \bigwedge_{ B_{ 1 } \le B } \mathcal{B} \left ( { B_{ 1 } } \right )\vee \delta \left ( { B_{ 1 } ,C } \right ) } \right ) \\ \wedge \left ( { \bigwedge_{ C_{ 1 } \le C } \mathcal{B} \left ( { C_{ 1 } } \right )\vee \delta \left ( { B,C_{ 1 } } \right ) } \right ) \\  &\le& \mathcal{B} \left ( { B\wedge D' } \right )\vee \delta \left ( { B\wedge D',C } \right )\text{，} \end{eqnarray*}
而\hspace{0pt}$B\wedge D'\le D'$\nobreak\hspace{0pt}，则\hspace{0pt}$\delta \left ( { B\wedge\allowbreak{} D',C } \right )\le\allowbreak{} \delta \left ( { D',C } \right )$\nobreak\hspace{0pt}，故\hspace{0pt}$\varnothing _{ \delta } \left ( { B,C } \right )\le\allowbreak{} \mathcal{B} \left ( { B\wedge\allowbreak{} D' } \right )\vee\allowbreak{} \delta \left ( { D',C } \right )$\nobreak\hspace{0pt}，将上面得到的两个式子相交可得：
\begin{eqnarray*} \varnothing _{ \delta } \left ( { A,B } \right )\wedge \varnothing _{ \delta } \left ( { B,C } \right ) \\  &\le& \left ( { \mathcal{B} \left ( { A_{ 1 } } \right )\vee \delta \left ( { A_{ 1 } ,D } \right )\vee \mathcal{B} '\left ( { B\wedge D' } \right ) } \right ) \\ \wedge \left ( { \mathcal{B} \left ( { B\wedge D' } \right )\vee \delta \left ( { D',C } \right ) } \right )\text{，} \end{eqnarray*}
故
\begin{eqnarray*} \varnothing _{ \delta } \left ( { A,B } \right )\wedge \varnothing _{ \delta } \left ( { B,C } \right ) &\le& \mathcal{B} \left ( { A_{ 1 } } \right ) \\ \vee \delta \left ( { A_{ 1 } ,D } \right )\vee \delta \left ( { D',C } \right )\text{，} \end{eqnarray*}
则
\begin{eqnarray*} \varnothing _{ \delta } \left ( { A,B } \right )\wedge \varnothing _{ \delta } \left ( { B,C } \right ) &\le& \mathcal{B} \left ( { A_{ 1 } } \right ) \\ \vee \bigvee_{ D\in L ^ { X } } \left ( { \delta \left ( { A_{ 1 } ,D } \right )\vee \delta \left ( { D',C } \right ) } \right ) \\  &=& \mathcal{B} \left ( { A_{ 1 } } \right )\vee \delta \left ( { A_{ 1 } ,C } \right )\text{，} \end{eqnarray*}
同理可得，都\hspace{0pt}$\forall C_{ 1 } \le C$\nobreak\hspace{0pt}，
\begin{eqnarray*} \varnothing _{ \delta } \left ( { A,B } \right )\wedge \varnothing _{ \delta } \left ( { B,C } \right ) &\le& \mathcal{B} \left ( { C_{ 1 } } \right ) \\ \vee \delta \left ( { A,C_{ 1 } } \right )\text{，} \end{eqnarray*}
则
\begin{eqnarray*} \varnothing _{ \delta } \left ( { A,B } \right )\wedge \varnothing _{ \delta } \left ( { B,C } \right ) \\  &\le& \left ( { \bigwedge_{ A_{ 1 } \le A } \mathcal{B} \left ( { A_{ 1 } } \right )\vee \delta \left ( { A_{ 1 } ,C } \right ) } \right ) \\ \wedge \left ( { \bigwedge_{ C_{ 1 } \le C } \mathcal{B} \left ( { C_{ 1 } } \right )\vee \delta \left ( { A,C_{ 1 } } \right ) } \right ) \\  &=& \varnothing _{ \delta } \left ( { A,C } \right )\text{，} \end{eqnarray*}
得证\hspace{0pt}$\varnothing _{ \delta }$为\hspace{0pt}$L ^ { X }$上的一个\hspace{0pt}$\left ( { L,M } \right )$-模糊等价关系；

\quad 下证对\hspace{0pt}$\forall A,B,C,D\in L ^ { X }$\nobreak\hspace{0pt}，
\begin{eqnarray*} \varnothing _{ \delta } \left ( { A,B } \right )\wedge \varnothing _{ \delta } \left ( { C,D } \right ) \\  &\le& \varnothing _{ \delta } \left ( { A\vee C,B\vee D } \right )\text{：} \end{eqnarray*}


令\hspace{0pt}$A\vee C=U$\nobreak\hspace{0pt}，\hspace{0pt}$B\vee D=V$\nobreak\hspace{0pt}，对\hspace{0pt}$\forall U_{ 1 } \le U$\nobreak\hspace{0pt}，由于\hspace{0pt}$U_{ 1 } =\allowbreak{}\left ( { U_{ 1 } \wedge\allowbreak{} A } \right )\vee\allowbreak{} \left ( { U_{ 1 } \wedge\allowbreak{} C } \right )$\nobreak\hspace{0pt}，记\hspace{0pt}$U_{ A } =\allowbreak{}U_{ 1 } \wedge\allowbreak{} A\le\allowbreak{} A$\nobreak\hspace{0pt}，\hspace{0pt}$U_{ C } =\allowbreak{}U_{ 1 } \wedge\allowbreak{} C\le\allowbreak{} C$\nobreak\hspace{0pt}，则
\begin{eqnarray*} \varnothing _{ \delta } \left ( { A,B } \right ) &=& \left ( { \bigwedge_{ A_{ 1 } \le A } \mathcal{B} \left ( { A_{ 1 } } \right )\vee \delta \left ( { A_{ 1 } ,B } \right ) } \right ) \\ \wedge \left ( { \bigwedge_{ B_{ 1 } \le B } \mathcal{B} \left ( { B_{ 1 } } \right )\vee \delta \left ( { A,B_{ 1 } } \right ) } \right ) \\  &\le& \mathcal{B} \left ( { U_{ A } } \right )\vee \delta \left ( { U_{ A } ,B } \right )\text{，} \end{eqnarray*}
\begin{eqnarray*} \varnothing _{ \delta } \left ( { C,D } \right ) &=& \left ( { \bigwedge_{ C_{ 1 } \le C } \mathcal{B} \left ( { C_{ 1 } } \right )\vee \delta \left ( { C_{ 1 } ,D } \right ) } \right ) \\ \wedge \left ( { \bigwedge_{ D_{ 1 } \le D } \mathcal{B} \left ( { D_{ 1 } } \right )\vee \delta \left ( { C,D_{ 1 } } \right ) } \right ) \\  &\le& \mathcal{B} \left ( { U_{ C } } \right )\vee \delta \left ( { U_{ C } ,D } \right )\text{，} \end{eqnarray*}
又由于\hspace{0pt}$B\le V$\nobreak\hspace{0pt}，\hspace{0pt}$D\le V$\nobreak\hspace{0pt}，则\hspace{0pt}$\delta \left ( { U_{ A } ,B } \right )\le\allowbreak{} \delta \left ( { U_{ A } ,V } \right )$\nobreak\hspace{0pt}，\hspace{0pt}$\delta \left ( { U_{ C } ,D } \right )\le\allowbreak{} \delta \left ( { U_{ C } ,V } \right )$\nobreak\hspace{0pt}，两式相交可得
\begin{eqnarray*} \varnothing _{ \delta } \left ( { A,B } \right )\wedge \varnothing _{ \delta } \left ( { C,D } \right ) \\  &\le& \left ( { \mathcal{B} \left ( { U_{ A } } \right )\vee \delta \left ( { U_{ A } ,V } \right ) } \right ) \\ \wedge \left ( { \mathcal{B} \left ( { U_{ C } } \right )\vee \delta \left ( { U_{ C } ,V } \right ) } \right ) \\  &=& \left ( { \mathcal{B} \left ( { U_{ A } } \right )\wedge \mathcal{B} \left ( { U_{ C } } \right ) } \right ) \\ \vee \left ( { \mathcal{B} \left ( { U_{ A } } \right )\wedge \delta \left ( { U_{ C } ,V } \right ) } \right ) \\ \vee \left ( { \delta \left ( { U_{ A } ,V } \right )\wedge \mathcal{B} \left ( { U_{ C } } \right ) } \right ) \\ \vee \left ( { \delta \left ( { U_{ A } ,V } \right )\wedge \delta \left ( { U_{ C } ,V } \right ) } \right ) \\  &\le& \left ( { \mathcal{B} \left ( { U_{ A } } \right )\wedge \mathcal{B} \left ( { U_{ C } } \right ) } \right )\vee \delta \left ( { U_{ C } ,V } \right ) \\ \vee \delta \left ( { U_{ A } ,V } \right ) \end{eqnarray*}
又因为
\begin{eqnarray*} \mathcal{B} \left ( { U_{ A } } \right )\wedge \mathcal{B} \left ( { U_{ C } } \right ) &=& \mathcal{B} \left ( { U_{ A } \vee U_{ C } } \right ) \\  &=& \mathcal{B} \left ( { U_{ 1 } } \right )\text{，}\delta \left ( { U_{ C } ,V } \right )\vee \delta \left ( { U_{ A } ,V } \right ) \\  &=& \delta \left ( { U_{ C } \vee U_{ A } ,V } \right )=\delta \left ( { U_{ 1 } ,V } \right )\text{，} \end{eqnarray*}
则
\begin{eqnarray*} \varnothing _{ \delta } \left ( { A,B } \right )\wedge \varnothing _{ \delta } \left ( { C,D } \right ) &\le& \mathcal{B} \left ( { U_{ 1 } } \right ) \\ \vee \delta \left ( { U_{ 1 } ,V } \right )\text{，} \end{eqnarray*}
同理对\hspace{0pt}$\forall V_{ 1 } \le V$\nobreak\hspace{0pt}，
\begin{eqnarray*} \varnothing _{ \delta } \left ( { A,B } \right )\wedge \varnothing _{ \delta } \left ( { C,D } \right ) &\le& \mathcal{B} \left ( { V_{ 1 } } \right ) \\ \vee \delta \left ( { U,V_{ 1 } } \right )\text{，} \end{eqnarray*}
故得证
\begin{eqnarray*} \varnothing _{ \delta } \left ( { A,B } \right )\wedge \varnothing _{ \delta } \left ( { C,D } \right ) &\le& \varnothing _{ \delta } \left ( { U,V } \right ) \\  &=& \varnothing _{ \delta } \left ( { A\vee C,B\vee D } \right )\text{。} \end{eqnarray*}
\textbf{定理5.2.4.}  \hspace{0pt}$L ^ { X }$上的一个\hspace{0pt}$\left ( { L,M } \right )$-模糊等价关系\hspace{0pt}$\varnothing$为\hspace{0pt}$X$上的一个伪\hspace{0pt}$\left ( { L,M } \right )$-模糊渐近相似性，定义\hspace{0pt}$\mathcal{C}_{ \varnothing } :L ^ { X\times X } \to\allowbreak{} M$满足，对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { X\times X }$\nobreak\hspace{0pt}，\hspace{0pt}$\mathcal{C}_{ \varnothing } \left ( { E } \right )=\allowbreak{}\bigwedge_{ F\le\allowbreak{} E } \varnothing \left ( { D_{ F } ,R_{ F } } \right )$\nobreak\hspace{0pt}，其中\hspace{0pt}$D_{ F } \left ( { x } \right )=\allowbreak{}\bigvee_{ y\in\allowbreak{} X } F\left ( { x,y } \right )$\nobreak\hspace{0pt}，\hspace{0pt}$R_{ F } \left ( { y } \right )=\allowbreak{}\bigvee_{ x\in\allowbreak{} X } F\left ( { x,y } \right )$\nobreak\hspace{0pt}，则称\hspace{0pt}$\mathcal{C}_{ \varnothing }$为\hspace{0pt}$L ^ { X }$上的一个\hspace{0pt}$\left ( { L,M } \right )$-模糊粗结构。

\textbf{证明：} （1）由于\hspace{0pt}$\Delta_X=\Delta_X ^ { -1 }$\nobreak\hspace{0pt}，则
\begin{eqnarray*} \mathcal{C}_{ \varnothing } \left ( { \Delta_X } \right ) &=& \bigwedge_{ F\le \Delta_X ^ { -1 } } \varnothing \left ( { D_{ F } ,R_{ F } } \right ) \\  &=& \bigwedge_{ F\le \Delta_X } \varnothing \left ( { D_{ F } ,R_{ F } } \right )\text{，} \end{eqnarray*}
对\hspace{0pt}$\forall F\le \Delta_X$\nobreak\hspace{0pt}，则\hspace{0pt}$F\left ( { x,y } \right )\le\allowbreak{} \Delta_X\left ( { x,y } \right )$\nobreak\hspace{0pt}，当\hspace{0pt}$x\ne y$时，\hspace{0pt}$\Delta_X\left ( { x,y } \right )=\allowbreak{}\bot$\nobreak\hspace{0pt}，则\hspace{0pt}$F\left ( { x,y } \right )=\allowbreak{}\bot$\nobreak\hspace{0pt}，\hspace{0pt}$\mathcal{C}_{ \varnothing } \left ( { \Delta_X } \right )=\allowbreak{}\varnothing \left ( { \bot ,\bot } \right )=\allowbreak{}\top$\nobreak\hspace{0pt}；当\hspace{0pt}$x=y$时，\hspace{0pt}$D_{ F } \left ( { x } \right )=\allowbreak{}\bigvee_{ y\in\allowbreak{} X } F\left ( { x,y } \right )=\allowbreak{}F\left ( { x,x } \right )$\nobreak\hspace{0pt}，\hspace{0pt}$R_{ F } \left ( { y } \right )=\allowbreak{}\bigvee_{ x\in\allowbreak{} X } F\left ( { x,y } \right )=\allowbreak{}F\left ( { x,x } \right )$\nobreak\hspace{0pt}，则\hspace{0pt}$\varnothing \left ( { D_{ F } ,R_{ F } } \right )=\allowbreak{}\top$\nobreak\hspace{0pt}，故\hspace{0pt}$\mathcal{C}_{ \varnothing } \left ( { \Delta_X } \right )=\allowbreak{}\top$\nobreak\hspace{0pt}；

（2）对\hspace{0pt}$\forall E,G\in\allowbreak{} L ^ { X\times X }$\nobreak\hspace{0pt}，\hspace{0pt}$E\le G$\nobreak\hspace{0pt}，即\hspace{0pt}$\forall F\le E$\nobreak\hspace{0pt}，一定有\hspace{0pt}$F\le G$\nobreak\hspace{0pt}，显然\hspace{0pt}$\mathcal{C}_{ \varnothing } \left ( { E } \right )\ge\allowbreak{} \mathcal{C}_{ \varnothing } \left ( { G } \right )$\nobreak\hspace{0pt}；

（3）由于\hspace{0pt}$\mathcal{C}_{ \varnothing } \left ( { E\vee\allowbreak{} G } \right )=\allowbreak{}\bigwedge_{ F\le\allowbreak{} E\vee\allowbreak{} G } \varnothing \left ( { D_{ F } ,R_{ F } } \right )$\nobreak\hspace{0pt}，对\hspace{0pt}$\forall F\le E\vee G$\nobreak\hspace{0pt}，令\hspace{0pt}$F_{ E } =F\wedge E$\nobreak\hspace{0pt}，\hspace{0pt}$F_{ G } =F\wedge G$\nobreak\hspace{0pt}，则\hspace{0pt}$F_{ E } \le E$\nobreak\hspace{0pt}，\hspace{0pt}$F_{ G } \le G$\nobreak\hspace{0pt}，且\hspace{0pt}$F=\allowbreak{}F\wedge\allowbreak{} \left ( { E\vee\allowbreak{} G } \right )=\allowbreak{}F_{ E } \vee\allowbreak{} F_{ G }$\nobreak\hspace{0pt}，则\hspace{0pt}$D_{ F } =\allowbreak{}D_{ F_{ E } \vee\allowbreak{} F_{ G } } =\allowbreak{}D_{ F_{ E } } \vee\allowbreak{} D_{ F_{ G } }$\nobreak\hspace{0pt}，\hspace{0pt}$R_{ F } =\allowbreak{}R_{ F_{ E } \vee\allowbreak{} F_{ G } } =\allowbreak{}R_{ F_{ E } } \vee\allowbreak{} R_{ F_{ G } }$\nobreak\hspace{0pt}，故
\begin{eqnarray*} \varnothing \left ( { D_{ F_{ E } } ,R_{ F_{ E } } } \right )\wedge \varnothing \left ( { D_{ F_{ G } } ,R_{ F_{ G } } } \right ) \\  &\le& \varnothing \left ( { D_{ F_{ E } } \vee D_{ F_{ G } } ,R_{ F_{ E } } \vee R_{ F_{ G } } } \right )=\varnothing \left ( { D_{ F } ,R_{ F } } \right )\text{，} \end{eqnarray*}
由于\hspace{0pt}$F_{ E } \le E$\nobreak\hspace{0pt}，\hspace{0pt}$F_{ G } \le G$\nobreak\hspace{0pt}，则\hspace{0pt}$\mathcal{C}_{ \varnothing } \left ( { E } \right )\le\allowbreak{} \varnothing \left ( { D_{ F_{ E } } ,R_{ F_{ E } } } \right )$\nobreak\hspace{0pt}，\hspace{0pt}$\mathcal{C}_{ \varnothing } \left ( { G } \right )\le\allowbreak{} \varnothing \left ( { D_{ F_{ G } } ,R_{ F_{ G } } } \right )$\nobreak\hspace{0pt}，故
\begin{eqnarray*} \mathcal{C}_{ \varnothing } \left ( { E } \right )\wedge \mathcal{C}_{ \varnothing } \left ( { G } \right ) \\  &\le& \varnothing \left ( { D_{ F_{ E } } ,R_{ F_{ E } } } \right )\wedge \varnothing \left ( { D_{ F_{ G } } ,R_{ F_{ G } } } \right ) \\  &\le& \varnothing \left ( { D_{ F } ,R_{ F } } \right )\text{，} \end{eqnarray*}
\begin{eqnarray*} \mathcal{C}_{ \varnothing } \left ( { E } \right )\wedge \mathcal{C}_{ \varnothing } \left ( { G } \right ) \\  &\le& \bigwedge_{ F\le E\vee G } \varnothing \left ( { D_{ F } ,R_{ F } } \right )=\mathcal{C}_{ \varnothing } \left ( { E\vee G } \right )\text{；} \end{eqnarray*}
（4）对\hspace{0pt}$\forall F\le E\circ G$\nobreak\hspace{0pt}，即\hspace{0pt}$F\left ( { x,y } \right )\le\allowbreak{} \bigvee_{ z\in\allowbreak{} X } \left ( { E\left ( { x,z } \right )\wedge\allowbreak{} G\left ( { z,y } \right ) } \right )$\nobreak\hspace{0pt}，令
\begin{eqnarray*} F_{ E } \left ( { x,z } \right ) &=& \bigvee_{ y\in X } \left ( { F\left ( { x,y } \right )\wedge E\left ( { x,z } \right )\wedge G\left ( { z,y } \right ) } \right )\text{，}F_{ G } \left ( { z,y } \right ) \\  &=& \bigvee_{ x\in X } \left ( { F\left ( { x,y } \right )\wedge E\left ( { x,z } \right )\wedge G\left ( { z,y } \right ) } \right )\text{，} \end{eqnarray*}
显然\hspace{0pt}$F_{ E } \le E$\nobreak\hspace{0pt}，\hspace{0pt}$F_{ G } \le G$\nobreak\hspace{0pt}，又因为
\begin{eqnarray*} D_{ F_{ E } } \left ( { x } \right ) &=& \bigvee_{ z\in X } F_{ E } \left ( { x,z } \right ) \\  &=& \bigvee_{ z,y\in X } \left ( { F\left ( { x,y } \right )\wedge E\left ( { x,z } \right )\wedge G\left ( { z,y } \right ) } \right ) \\  &=& \bigvee_{ y\in X } F\left ( { x,y } \right )=D_{ F } \left ( { x } \right )\text{，} \end{eqnarray*}
所以\hspace{0pt}$D_{ F_{ E } } =D_{ F }$\nobreak\hspace{0pt}，同理可得\hspace{0pt}$R_{ F_{ G } } =R_{ F }$\nobreak\hspace{0pt}，又因为
\begin{eqnarray*} R_{ F_{ E } } \left ( { z } \right ) &=& \bigvee_{ x\in X } F_{ E } \left ( { x,z } \right ) \\  &=& \bigvee_{ x,y\in X } \left ( { F\left ( { x,y } \right )\wedge E\left ( { x,z } \right )\wedge G\left ( { z,y } \right ) } \right )\text{，} \end{eqnarray*}
\begin{eqnarray*} D_{ F_{ G } } \left ( { z } \right ) &=& \bigvee_{ y\in X } F_{ G } \left ( { z,y } \right ) \\  &=& \bigvee_{ x,y\in X } \left ( { F\left ( { x,y } \right )\wedge E\left ( { x,z } \right )\wedge G\left ( { z,y } \right ) } \right )\text{，} \end{eqnarray*}
则\hspace{0pt}$R_{ F_{ E } } =D_{ F_{ G } }$\nobreak\hspace{0pt}，由于\hspace{0pt}$F_{ E } \le E$及\hspace{0pt}$F_{ G } \le G$\nobreak\hspace{0pt}，则
\begin{eqnarray*} \mathcal{C}_{ \varnothing } \left ( { E } \right ) &\le& \varnothing \left ( { D_{ F_{ E } } ,R_{ F_{ E } } } \right ) \\  &=& \varnothing \left ( { D_{ F } ,R_{ F_{ E } } } \right )\text{，}\mathcal{C}_{ \varnothing } \left ( { G } \right ) \\  &\le& \varnothing \left ( { D_{ F_{ G } } ,R_{ F_{ G } } } \right )=\varnothing \left ( { D_{ F_{ G } } ,R_{ F } } \right )\text{，} \end{eqnarray*}
故
\begin{eqnarray*} \mathcal{C}_{ \varnothing } \left ( { E } \right )\wedge \mathcal{C}_{ \varnothing } \left ( { G } \right ) \\  &\le& \varnothing \left ( { D_{ F } ,R_{ F_{ E } } } \right )\wedge \varnothing \left ( { D_{ F_{ G } } ,R_{ F } } \right ) \\  &\le& \varnothing \left ( { D_{ F } ,R_{ F } } \right )\text{，} \end{eqnarray*}
则
\begin{eqnarray*} \mathcal{C}_{ \varnothing } \left ( { E } \right )\wedge \mathcal{C}_{ \varnothing } \left ( { G } \right ) \\  &\le& \bigwedge_{ F\le E\circ G } \varnothing \left ( { D_{ F } ,R_{ F } } \right )=\mathcal{C}_{ \varnothing } \left ( { E\circ G } \right )\text{；} \end{eqnarray*}
（5）对\hspace{0pt}$F\leq E^{-1}$\nobreak\hspace{0pt}，有\hspace{0pt}$F\left ( { x,y } \right )\le\allowbreak{} E ^ { -1 } \left ( { x,y } \right )$\nobreak\hspace{0pt}，则\hspace{0pt}$F ^ { -1 } \left ( { y,x } \right )\le\allowbreak{} E ^ { -1 } \left ( { x,y } \right )=\allowbreak{}E\left ( { y,x } \right )$\nobreak\hspace{0pt}，即\hspace{0pt}$F ^ { -1 } \le E$\nobreak\hspace{0pt}，而
\begin{eqnarray*} R_{ F ^ { -1 } } \left ( { y } \right ) &=& \bigvee_{ x\in X } F ^ { -1 } \left ( { x,y } \right )=\bigvee_{ x\in X } F\left ( { y,x } \right ) \\  &=& D_{ F } \left ( { y } \right )\text{，} \end{eqnarray*}
则
\begin{eqnarray*} \varnothing \left ( { D_{ F } ,R_{ F } } \right ) &=& \varnothing \left ( { R_{ F ^ { -1 } } ,D_{ F ^ { -1 } } } \right ) \\  &=& \varnothing \left ( { D_{ F ^ { -1 } } ,R_{ F ^ { -1 } } } \right )\text{，} \end{eqnarray*}
故
\begin{eqnarray*} \mathcal{C}_{ \varnothing } \left ( { E ^ { -1 } } \right ) &=& \bigwedge_{ F\le E ^ { -1 } } \varnothing \left ( { D_{ F } ,R_{ F } } \right ) \\  &=& \bigwedge_{ F ^ { -1 } \le E } \varnothing \left ( { D_{ F ^ { -1 } } ,R_{ F ^ { -1 } } } \right )=\mathcal{C}_{ \varnothing } \left ( { E } \right )\text{。} \end{eqnarray*}


\chapter{总\ \ 结}
\vspace{0.2cm}
本文在完全分配格$L$和$M$的框架下系统研究了$(L,M)$-模糊粗结构及其相关理论. 首先提出$(L,M)$-模糊熵结构、拟粗结构、半粗结构和粗结构, 并利用$(L,M)$-模糊球系统给出相互刻画. 其次将群运算引入该框架, 建立格值模糊化粗群与格值模糊化群理想之间的对应关系. 最后研究$(L,M)$-模糊粗邻近及其诱导的模糊邻域系统, 并讨论伪$(L,M)$-模糊渐近相似性与模糊粗结构之间的构造联系. 这些结果从关系、球结构、代数结构和邻近结构等不同角度扩展了格值粗几何的研究框架.
