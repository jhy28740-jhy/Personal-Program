\vspace{0.2cm} {\large \bf Abstract}

\zihao{-4}

Based on completely distributive lattices $L$ and $M$, this paper gives an axiomatic definition of lattice-valued fuzzifying coarse groups and studies the structures induced by KM-fuzzy pseudometrics. It then introduces lattice-valued fuzzifying group ideals and establishes their one-to-one correspondence with left and right lattice-valued fuzzifying coarse groups.

lattice-valued fuzzifying coarse structure; lattice-valued fuzzifying coarse group; group ideal

\chapter{绪\ \论}
\vspace{0.2cm}
粗几何,研究空间在大尺度视角下的整体结构与形状,其核心概念粗结构由John Roe系统提出,用以刻画空间在无穷远处的等价性,即粗等价\cite{ref1}.这一理论超越了经典拓扑的局部视角，成为连接分析、拓扑与几何的重要桥梁.而群作为基础代数对象,其上的粗结构研究自然催生了粗群的概念.Protasov、Nicas、Rosenthal等人的工作表明,群上的粗结构若能与群运算（如左乘、右乘等）相容,则可由一个特殊的子集族--群理想唯一确定,从而揭示了代数结构与粗几何的深刻联系\cite{ref4}.

随着模糊数学的发展,传统数学结构逐渐被推广至模糊环境.Zadeh提出的模糊集理论为处理不确定性和渐进性提供了强有力的工具\cite{ref6}.近年来,学者们开始尝试将粗几何进行``模糊化'',以适应更复杂、更具现实意义的场景.Zarichnyi首次探讨了模糊度量空间的粗结构,而严从华则正式提出了\hspace{0pt}$\left ( { L,* } \right )$-值粗结构的概念,开启了模糊粗结构的系统研究\cite{ref7}.随后,史福贵,庞斌,王永超等人进一步发展了基于完全分配格\hspace{0pt}$L$的\hspace{0pt}$L$-粗结构理论,形成了更为丰富的格值粗空间理论体系\cite{ref9}.然而，现有的模糊粗结构研究大多基于单一格，而双格值框架下的模糊粗群尚未被系统研究，限制了该理论在更复杂不确定性场景中的应用。

本文正是在上述研究背景下展开的.我们基于完全分配格\hspace{0pt}$L$与\hspace{0pt}$M$\nobreak\hspace{0pt},首次提出了格值模糊化粗群的完整定义,并深入探讨了其代数与大尺度几何性质,本文的主要结构如下：在第二节中首先回顾了完全分配格、蕴含算子、格值模糊化粗结构等概念和定义;第三节中,我们给出了格值模糊化粗群的公理化定义,并利用左乘与右乘映射,建立了其与一致格值模糊化保有界映射之间的等价刻画;第四节中,我们引入了格值模糊化群理想的概念,并建立了格值模糊化粗群与格值模糊化群理想之间的一一对应关系.



\chapter{预备知识}

\section{格值模糊化粗群的相关知识}
\vspace{0.2cm}
在本文中,称一个非空集合\hspace{0pt}$P$为一个偏序集,如果它中的一个二元关系满足自反性、反对称性和传递性.称\hspace{0pt}$P$的子集\hspace{0pt}$D$为有向的,如果它是非空的,并且\hspace{0pt}$D$的每个有限子集在\hspace{0pt}$D$中都有上界\cite{ref10}.

本文中,\hspace{0pt}$L$和\hspace{0pt}$M$都是完全分配格,它们的最大元记为\hspace{0pt}$~\top$\nobreak\hspace{0pt},最小元记为\hspace{0pt}$\bot$\nobreak\hspace{0pt}.\hspace{0pt}$L$上的一个二元关系\hspace{0pt}$\prec$定义为,对\hspace{0pt}$\forall a,b\in L$\nobreak\hspace{0pt},\hspace{0pt}$a\prec b$当且仅当对\hspace{0pt}$\forall M\subseteq L$\nobreak\hspace{0pt},\hspace{0pt}$b\le \vee M$\nobreak\hspace{0pt},则存在一个\hspace{0pt}$d\in M$\nobreak\hspace{0pt},使得\hspace{0pt}$a\le d$\cite{ref10}.

对于完全分配格\hspace{0pt}$\left ( { L,\wedge\allowbreak{} ,\vee\allowbreak{} } \right )$存在一个二元算子\hspace{0pt}$\to :L\times L\to L$\nobreak\hspace{0pt},定义为\hspace{0pt}$\alpha \to\allowbreak{} \beta =\allowbreak{}\vee\allowbreak{} \left \{ \begin{array}{l} \gamma \in\allowbreak{} L:\alpha \wedge\allowbreak{} \gamma \le\allowbreak{} \beta \end{array} \right \}$\nobreak\hspace{0pt},称\hspace{0pt}$\to$为蕴含算子.此外,\hspace{0pt}$\wedge$和\hspace{0pt}$\to$还满足对\hspace{0pt}$\forall \alpha ,\beta ,\gamma \in\allowbreak{} L$\nobreak\hspace{0pt},\hspace{0pt}$\alpha \wedge\allowbreak{} \gamma \le\allowbreak{} \beta \Leftrightarrow \gamma \le\allowbreak{} \left ( { \alpha \to\allowbreak{} \beta } \right )$\cite{ref10}.

\textbf{定义2.1.1.}  \cite{ref11} 非空集\hspace{0pt}$X$上的一个模糊伪度量是一个三元组\hspace{0pt}$\left ( { X,d,\wedge\allowbreak{} } \right )$\nobreak\hspace{0pt},其中\hspace{0pt}$d$是一个映\hspace{0pt}$d:X\times X\times \left [ { 0,\infty } \right )\to\allowbreak{} \left[ 0,1 \right]$\nobreak\hspace{0pt},满足对\hspace{0pt}$\forall x,y,z\in X$及\hspace{0pt}$\forall s,t>0$\nobreak\hspace{0pt}：

（KM1）\hspace{0pt}$d\left ( { x,y,0 } \right )=\allowbreak{}0$\nobreak\hspace{0pt};

（KM2）\hspace{0pt}$d\left ( { x,x,t } \right )=\allowbreak{}1$\nobreak\hspace{0pt};

（KM3）\hspace{0pt}$d\left ( { x,y,t } \right )=\allowbreak{}d\left ( { y,x,t } \right )$\nobreak\hspace{0pt};

（KM4）\hspace{0pt}$d\left ( { x,y,t } \right )\wedge\allowbreak{} d\left ( { y,z,s } \right )\le\allowbreak{} d\left ( { x,z,t+s } \right )$\nobreak\hspace{0pt};

（KM5）\hspace{0pt}$d\left ( { x,y,- } \right ):\left [ { 0,\infty } \right )\to\allowbreak{} \left[ 0,1 \right]$是左连续的;

上述中的模糊伪度量也称为\hspace{0pt}$KM$-模糊伪度量.

为回顾格值模糊化粗结构的定义,我们引入以下定义：对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { X\times X }$\nobreak\hspace{0pt},\newline \hspace{0pt}$E ^ { -1 } \left ( { x,y } \right )=\allowbreak{}E\left ( { y,x } \right )$\nobreak\hspace{0pt},\newline \hspace{0pt}$\left ( { E\circ F } \right )\left ( { x,y } \right )=\allowbreak{}\bigvee_{ z\in\allowbreak{} X } F\left ( { x,z } \right )\wedge\allowbreak{} E\left ( { z,y } \right )$\nobreak\hspace{0pt},\newline \hspace{0pt}$E\left[ x \right]\left ( { y } \right )=\allowbreak{}E\left ( { x,y } \right )$\nobreak\hspace{0pt}.

\textbf{定义2.1.2.}  集合\hspace{0pt}$X$上的一个格值模糊化熵结构是一个映射\hspace{0pt}$\mathcal{C}$\hspace{0pt}$\nobreak\hspace{0pt}:L ^ { X\times X } \to\allowbreak{} M$满足以下条件：

\quad （ME1）\hspace{0pt}$\mathcal{C}\left ( { \Delta _{ X } } \right )=\allowbreak{}\top$\nobreak\hspace{0pt};

\quad （ME2）\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { X\times X }$\nobreak\hspace{0pt},且\hspace{0pt}$E\le F$\nobreak\hspace{0pt},则\hspace{0pt}$\mathcal{C}\left ( { F } \right )\le\allowbreak{} \mathcal{C}\left ( { E } \right )$\nobreak\hspace{0pt};

\quad （ME3）\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { X\times X }$\nobreak\hspace{0pt},则\hspace{0pt}$\mathcal{C}\left ( { E } \right )\wedge\allowbreak{} \mathcal{C}\left ( { F } \right )\le\allowbreak{} \mathcal{C}\left ( { E\vee\allowbreak{} F } \right )$\nobreak\hspace{0pt};

\quad 一个格值模糊化熵结构\hspace{0pt}$\mathcal{C}$称为格值模糊化拟粗结构,如果它又满足（ME4）：

\quad （ME4）\hspace{0pt}$\forall E,F\in L^{X\times X}$\nobreak\hspace{0pt},则\hspace{0pt}$\mathcal{C}\left ( { E } \right )\wedge\allowbreak{} \mathcal{C}\left ( { F } \right )\le\allowbreak{} \mathcal{C}\left ( { E\circ F } \right )$\nobreak\hspace{0pt};

\quad 一个格值模糊化熵结构\hspace{0pt}$\mathcal{C}$称为格值模糊化半粗结构,如果它又满足（ME5）：

\quad （ME5）\hspace{0pt}$\forall E\in L^{X\times X}$\nobreak\hspace{0pt},则\hspace{0pt}$\mathcal{C}\left ( { E } \right )=\allowbreak{}\mathcal{C}\left ( { E ^ { -1 } } \right )$\nobreak\hspace{0pt}.

\quad 若一个格值模糊化熵结构\hspace{0pt}$\mathcal{C}$既是格值模糊化半粗结构,又是格值模糊化拟粗结构,则称为格值模糊化粗结构.相应地,\hspace{0pt}$\left ( { X,\mathcal{C} } \right )$分别称为格值模糊化熵空间, 格值模糊化半粗空间, 格值模糊化拟粗空间, 格值模糊化粗空间.


\chapter{格值模糊化粗群的刻画}
\section{格值模糊化粗群}
\vspace{0.2cm}
\quad 基于前文所述的格值模糊化粗结构框架,我们现在将群的代数结构融入其中,在本节中,我将给出格值模糊化粗群的定义,并探讨格值模糊化粗群和一些群运算之间的关系.

\quad 若\hspace{0pt}$G$是一个群且\hspace{0pt}$g\in G$\nobreak\hspace{0pt},定义左乘\hspace{0pt}$s_{ g } ^{ \lambda }:G\to G$\nobreak\hspace{0pt},右乘\hspace{0pt}$s_{ g } ^{ \rho }:G\to G$为：对\hspace{0pt}$\forall x\in G$\nobreak\hspace{0pt},\hspace{0pt}$s_{ g } ^{ \lambda }\left ( { x } \right )=\allowbreak{}gx$\nobreak\hspace{0pt},\hspace{0pt}$s_{ g } ^{ \rho }\left ( { x } \right )=\allowbreak{}xg$\nobreak\hspace{0pt}.

对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},我们定义\hspace{0pt}$GE\left ( { x,y } \right )=\allowbreak{}\bigvee_{ g\in\allowbreak{} G } E\left ( { gx,gy } \right )$\nobreak\hspace{0pt},\newline \hspace{0pt}$EG\left ( { x,y } \right )=\allowbreak{}\bigvee_{ g\in\allowbreak{} G } E\left ( { xg,yg } \right )$\nobreak\hspace{0pt}.

\textbf{定义3.1.1.}  \hspace{0pt}$G$是一个群,\hspace{0pt}$\mathcal{C}$是\hspace{0pt}$G$上的一个格值模糊化粗结构,\hspace{0pt}$\left ( { G,\mathcal{C} } \right )$称为

一个左格值模糊化粗群,若对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$\mathcal{C}\left ( { E } \right )\le\allowbreak{} \mathcal{C}\left ( { GE } \right )$\nobreak\hspace{0pt};

一个右格值模糊化粗群,若对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$\mathcal{C}\left ( { E } \right )\le\allowbreak{} \mathcal{C}\left ( { EG } \right )$\nobreak\hspace{0pt};

一个格值模糊化粗群,若它既是左格值模糊化粗群,又是右格值模糊化粗群.

此时\hspace{0pt}$\mathcal{C}$分别称为左格值模糊化群粗结构,右格值模糊化群粗结构和格值模糊化群粗结构.

\textbf{注3.1.2.}  由于\hspace{0pt}$E\le GE$\nobreak\hspace{0pt},则\hspace{0pt}$\mathcal{C}\left ( { GE } \right )\le\allowbreak{} \mathcal{C}\left ( { E } \right )$\nobreak\hspace{0pt},即若\hspace{0pt}$\left ( { G,\mathcal{C} } \right )$称为一个左格值模糊化粗群,那么\hspace{0pt}$\mathcal{C}\left ( { E } \right )=\allowbreak{}\mathcal{C}\left ( { GE } \right )$\nobreak\hspace{0pt}.

\textbf{命题3.1.3.}  \hspace{0pt}$d:G\times G\times \left[ 0,\infty \right]\to\allowbreak{} \left[ 0,1 \right]$是一个KM-模糊伪度量,定义\hspace{0pt}$\mathcal{C}_{ d } :L ^ { G\times G } \to\allowbreak{} \left[ 0,1 \right]$满足
$$\mathcal{C}_{ d } \left ( { E } \right )=\bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { E\left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ),$$
若\hspace{0pt}$d$是左不变的,则\hspace{0pt}$\left ( { G,\mathcal{C}_{ d } } \right )$是一个左[0,1]-模糊粗群;

若\hspace{0pt}$d$是右不变的,则\hspace{0pt}$\left ( { G,\mathcal{C}_{ d } } \right )$是一个右[0,1]-模糊粗群;

若\hspace{0pt}$d$是不变的,则\hspace{0pt}$\left ( { G,\mathcal{C}_{ d } } \right )$是一个[0,1]-模糊粗群.

\textbf{证明：} 先证\hspace{0pt}$\mathcal{C}_{ d } :L ^ { G\times G } \to\allowbreak{} \left[ 0,1 \right]$是一个格值模糊化粗结构：

由已知条件可知
\begin{eqnarray*} \mathcal{C}_{ d } \left ( { \Delta _{ G } } \right ) &=& \bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { \Delta _{ G } \left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \left ( { \bigwedge_{ x=y } \left ( { ~\top \to d\left ( { x,x,t } \right ) } \right )\wedge \bigwedge_{ x\ne y } \left ( { ~\bot \to d\left ( { x,y,t } \right ) } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \left ( { \bigwedge_{ x=y } d\left ( { x,x,t } \right )\wedge \bigwedge_{ x\ne y } \top } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ x\in G } d\left ( { x,x,t } \right )=\top; \end{eqnarray*}
对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$E\le F$\nobreak\hspace{0pt},由于\hspace{0pt}$F\left ( { x,y } \right )\to\allowbreak{} d\left ( { x,y,t } \right )\le\allowbreak{} E\left ( { x,y } \right )\to\allowbreak{} d\left ( { x,y,t } \right )$\nobreak\hspace{0pt},则显然\hspace{0pt}$\mathcal{C}_{ d } \left ( { E } \right )\ge\allowbreak{} \mathcal{C}_{ d } \left ( { F } \right )$\nobreak\hspace{0pt};

对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},由于
\begin{eqnarray*} \mathcal{C}_{ d } \left ( { E } \right ) &=& \bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { E\left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ), \\ \mathcal{C}_{ d } \left ( { F } \right ) &=& \bigvee_{ s>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { F\left ( { x,y } \right )\to d\left ( { x,y,s } \right ) } \right ) , \end{eqnarray*}
对\hspace{0pt}$\forall a\prec \mathcal{C}_{ d } \left ( { E } \right )\wedge\allowbreak{} \mathcal{C}_{ d } \left ( { F } \right )$\nobreak\hspace{0pt},\hspace{0pt}$\exists t,s>0$\nobreak\hspace{0pt},使得\hspace{0pt}$a\le\allowbreak{} \bigwedge_{ \left ( { x,y } \right )\in\allowbreak{} G\times G } \left ( { E\left ( { x,y } \right )\to\allowbreak{} d\left ( { x,y,t } \right ) } \right )$\nobreak\hspace{0pt},\hspace{0pt}$a\le\allowbreak{} \bigwedge_{ \left ( { x,y } \right )\in\allowbreak{} G\times G } \left ( { F\left ( { x,y } \right )\to\allowbreak{} d\left ( { x,y,s } \right ) } \right )$ ,

则对\hspace{0pt}$\forall x,y\in G$\nobreak\hspace{0pt},\hspace{0pt}$a\wedge E(x,y)\leq d(x,y,t)$且\hspace{0pt}$a\wedge F(x,y)\leq d(x,y,s)$\nobreak\hspace{0pt},令\newline \hspace{0pt}$r=\allowbreak{}max\left \{ \begin{array}{l} s,t \end{array} \right \}$\nobreak\hspace{0pt},则
\begin{eqnarray*} a\wedge \left ( { E\left ( { x,y } \right )\vee F\left ( { x,y } \right ) } \right ) &=& a\wedge \left ( { E\vee F } \right )\left ( { x,y } \right ) \\  &\le& d\left ( { x,y,t } \right )\wedge d\left ( { x,y,s } \right )\le d\left ( { x,y,r } \right ), \end{eqnarray*}
故\hspace{0pt}$a\le\allowbreak{} \left ( { E\vee\allowbreak{} F } \right )\left ( { x,y } \right )\to\allowbreak{} d\left ( { x,y,r } \right )$\nobreak\hspace{0pt},即\newline \hspace{0pt}$a\le\allowbreak{} \bigvee_{ r>0 } \bigwedge_{ \left ( { x,y } \right )\in\allowbreak{} G\times G } \left ( { \left ( { E\vee\allowbreak{} F } \right )\left ( { x,y } \right )\to\allowbreak{} d\left ( { x,y,r } \right ) } \right )$\nobreak\hspace{0pt},得证;

对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$\forall a\prec \mathcal{C}_{ d } \left ( { E } \right )\wedge\allowbreak{} \mathcal{C}_{ d } \left ( { F } \right )$\nobreak\hspace{0pt},\hspace{0pt}$\exists t>0,s>0$\nobreak\hspace{0pt},使得
\begin{eqnarray*} a &\le& \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { E\left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ),a \\  &\le& \bigwedge_{ \left ( { y,z } \right )\in G\times G } \left ( { F\left ( { y,z } \right )\to d\left ( { y,z,s } \right ) } \right ), \end{eqnarray*}
则对\hspace{0pt}$\forall x,y,z\in G$\nobreak\hspace{0pt},有\hspace{0pt}$a\wedge E(x,y)\leq d(x,y,t)$\nobreak\hspace{0pt},\hspace{0pt}$a\wedge F(y,z)\leq d(y,z,s)$\nobreak\hspace{0pt},故
\begin{eqnarray*} a\wedge \left ( { E\left ( { x,y } \right )\wedge F\left ( { x,y } \right ) } \right ) &\le& d\left ( { x,y,t } \right )\wedge d\left ( { x,y,s } \right ) \\  &\le& d\left ( { x,z,t+s } \right ),a\wedge \bigvee_{ y\in G } \left ( { E\left ( { x,y } \right )\wedge F\left ( { y,z } \right ) } \right ) \\  &\le& d\left ( { x,z,t+s } \right ), \end{eqnarray*}
\begin{eqnarray*} a &\le& \left ( { E\circ F } \right )\left ( { x,z } \right )\to d\left ( { x,z,t+s } \right ),a \\  &\le& \bigvee_{ r>0 } \bigwedge_{ \left ( { x,z } \right )\in G\times G } \left ( { E\circ F } \right )\left ( { x,z } \right )\to d\left ( { x,z,r } \right ), \end{eqnarray*}
得证\hspace{0pt}$\mathcal{C}_{ d } \left ( { E } \right )\wedge\allowbreak{} \mathcal{C}_{ d } \left ( { F } \right )\le\allowbreak{} \mathcal{C}_{ d } \left ( { E\circ F } \right )$\nobreak\hspace{0pt};

（5）对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},
\begin{eqnarray*} \mathcal{C}_{ d } \left ( { E ^ { -1 } } \right ) &=& \bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { E ^ { -1 } \left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ \left ( { y,x } \right )\in G\times G } \left ( { E\left ( { y,x } \right )\to d\left ( { y,x,t } \right ) } \right ) \\  &=& \mathcal{C}_{ d } \left ( { E } \right )\text{；} \end{eqnarray*}
下证\hspace{0pt}$\left ( { G,\mathcal{C}_{ d } } \right )$是一个左（右）[0,1]-模糊粗群,若\hspace{0pt}$d$是左不变的,则
\begin{eqnarray*} \mathcal{C}_{ d } \left ( { GE } \right ) &=& \bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { GE\left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { \bigvee_{ g\in G } E\left ( { gx,gy } \right )\to d\left ( { x,y,t } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { \bigwedge_{ g\in G } \left ( { E\left ( { gx,gy } \right )\to d\left ( { x,y,t } \right ) } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \left ( { \bigwedge_{ g\in G } \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { E\left ( { gx,gy } \right )\to d\left ( { x,y,t } \right ) } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \left ( { \bigwedge_{ g\in G } \bigwedge_{ \left ( { x',y' } \right )\in G\times G } \left ( { E\left ( { x',y' } \right )\to d\left ( { g ^ { -1 } x',g ^ { -1 } y',t } \right ) } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \left ( { \bigwedge_{ \left ( { x',y' } \right )\in G\times G } \left ( { E\left ( { x',y' } \right )\to d\left ( { x',y',t } \right ) } \right ) } \right ) \\  &=& \mathcal{C}_{ d } \left ( { E } \right ); \end{eqnarray*}
若\hspace{0pt}$d$是右不变的,则同理.

\textbf{定义3.1.4.}  \hspace{0pt}$\left ( { X,\mathcal{C}_{ X } } \right )$和\hspace{0pt}$\left ( { Y,\mathcal{C}_{ Y } } \right )$是两个格值模糊化粗群,\newline \hspace{0pt}$\left \{ \begin{array}{l} f_{ i } :\left ( { X,\mathcal{C}_{ X } } \right )\to\allowbreak{} \left ( { Y,\mathcal{C}_{ Y } } \right ) \end{array} \right \}_{ i\in\allowbreak{} I }$是一族映射,\hspace{0pt}$\left \{ \begin{array}{l} f_{ i } \end{array} \right \}_{ i\in\allowbreak{} I }$称为一致格值模糊化保有界的,若对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { X\times X }$\nobreak\hspace{0pt},\hspace{0pt}$\exists F\in\allowbreak{} L ^ { Y\times Y }$\nobreak\hspace{0pt},使得\hspace{0pt}$\mathcal{C}_{ X } \left ( { E } \right )\le\allowbreak{} \mathcal{C}_{ Y } \left ( { F } \right )$\nobreak\hspace{0pt},且对\hspace{0pt}$\forall i\in I$\nobreak\hspace{0pt},\hspace{0pt}$\left ( { f_{ i } \times f_{ i } } \right )\left ( { E } \right )\le\allowbreak{} F$\nobreak\hspace{0pt}.

\textbf{命题3.1.5.}  \hspace{0pt}$G$是一个群,\hspace{0pt}$\mathcal{C}$是\hspace{0pt}$G$上一个格值模糊化粗结构,则:

（1）\hspace{0pt}$\left ( { G,\mathcal{C} } \right )$是一个左格值模糊化粗群当且仅当\hspace{0pt}$s_{ G } ^{ \lambda }=\allowbreak{}\left \{ \begin{array}{l} s_{ g } ^{ \lambda }:g\in\allowbreak{} G \end{array} \right \}$是一致格值模糊化保有界的;

（2）\hspace{0pt}$\left ( { G,\mathcal{C} } \right )$是一个右格值模糊化粗群当且仅当\hspace{0pt}$s_{ G } ^{ \rho }=\allowbreak{}\left \{ \begin{array}{l} s_{ g } ^{ \rho }:g\in\allowbreak{} G \end{array} \right \}$是一致格值模糊化保有界的.

\textbf{证明：} （1）必要性 对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},由于\hspace{0pt}$\left ( { G,\mathcal{C} } \right )$是一个左格值模糊化粗群,则\hspace{0pt}$\mathcal{C}\left ( { E } \right )\le\allowbreak{} \mathcal{C}\left ( { GE } \right )$\nobreak\hspace{0pt},而对\hspace{0pt}$\forall g\in G$\nobreak\hspace{0pt},\hspace{0pt}$\left ( { s_{ g } ^{ \lambda }\times s_{ g } ^{ \lambda } } \right )\left ( { E } \right )\le\allowbreak{} GE$\nobreak\hspace{0pt},故\hspace{0pt}$s_{ G } ^{ \lambda }=\allowbreak{}\left \{ \begin{array}{l} s_{ g } ^{ \lambda }:g\in\allowbreak{} G \end{array} \right \}$是一致格值模糊化保有界的;

充分性 由于\hspace{0pt}$s_{ G } ^{ \lambda }=\allowbreak{}\left \{ \begin{array}{l} s_{ g } ^{ \lambda }:g\in\allowbreak{} G \end{array} \right \}$是一致格值模糊化保有界的,即对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$\exists F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},使得对\hspace{0pt}$\forall g\in G$\nobreak\hspace{0pt},\hspace{0pt}$\mathcal{C}\left ( { E } \right )\le\allowbreak{} \mathcal{C}\left ( { F } \right )$\nobreak\hspace{0pt},且\hspace{0pt}$\left ( { s_{ g } ^{ \lambda }\times s_{ g } ^{ \lambda } } \right )\left ( { E } \right )\le\allowbreak{} F$\nobreak\hspace{0pt},故
\begin{eqnarray*} GE\left ( { x,y } \right ) &=& \bigvee_{ g\in G } E\left ( { gx,gy } \right )=\bigvee_{ g\in G } \left ( { s_{ g } ^{ \lambda }\times s_{ g } ^{ \lambda } } \right )E\left ( { x,y } \right ) \\  &\le& F\left ( { x,y } \right ), \end{eqnarray*}
则\hspace{0pt}$\mathcal{C}\left ( { E } \right )\le\allowbreak{} \mathcal{C}\left ( { F } \right )\le\allowbreak{} \mathcal{C}\left ( { GE } \right )$\nobreak\hspace{0pt};

（2）与（1）的证明同理.


\section{格值模糊化群理想}
\vspace{0.2cm}
上一节中我们从粗结构出发定义了格值模糊化粗群,但一个自然的问题随之而来：是否存在一种代数对象能够完全刻画这类结构？受经典粗群理论中``群理想决定粗结构''这一深刻结论的启发,我们将在本节引入格值模糊化群理想的全新概念,并探索其与模糊粗群之间的内在联系.

\textbf{定义3.2.1.}  \hspace{0pt}$G$是一个群,\hspace{0pt}$G$上一个格值模糊化群理想是映射\hspace{0pt}$I:L ^ { G } \to M$\nobreak\hspace{0pt},满足：

（IM1）\hspace{0pt}$I\left ( { \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } } \right )=\allowbreak{}\top$\nobreak\hspace{0pt};

（IM2）\hspace{0pt}$\forall A,B\in L ^ { G }$\nobreak\hspace{0pt},\hspace{0pt}$A\le B$\nobreak\hspace{0pt},有\hspace{0pt}$I(B)\leq I(A)$\nobreak\hspace{0pt};

（IM3）\hspace{0pt}$\forall A,B\in L ^ { G }$\nobreak\hspace{0pt},\hspace{0pt}$I\left ( { A } \right )\wedge\allowbreak{} I\left ( { B } \right )\le\allowbreak{} I\left ( { A\vee\allowbreak{} B } \right )$\nobreak\hspace{0pt};

（IM4）\hspace{0pt}$\forall A,B\in L ^ { G }$\nobreak\hspace{0pt},\hspace{0pt}$I\left ( { A } \right )\wedge\allowbreak{} I\left ( { B } \right )\le\allowbreak{} I\left ( { AB } \right )$\nobreak\hspace{0pt},其中\newline \hspace{0pt}$AB\left ( { z } \right )=\allowbreak{}\bigvee_{ x,y\in\allowbreak{} G,xy=\allowbreak{}z } \left ( { A\left ( { x } \right )\wedge\allowbreak{} B\left ( { y } \right ) } \right )$\nobreak\hspace{0pt};

（IM5）\hspace{0pt}$\forall A\in L ^ { G }$\nobreak\hspace{0pt},\hspace{0pt}$I\left ( { A } \right )=\allowbreak{}I\left ( { A ^ { -1 } } \right )$\nobreak\hspace{0pt},其中\hspace{0pt}$A ^ { -1 } \left ( { x } \right )=\allowbreak{}A\left ( { x ^ { -1 } } \right )$\nobreak\hspace{0pt}.

\textbf{命题3.2.2.}  \hspace{0pt}$G$是一个群,\hspace{0pt}$I$是\hspace{0pt}$G$上一个格值模糊化群理想,定义\hspace{0pt}$\mathcal{C}_{ I } ^{ \lambda }:L ^ { G\times G } \to\allowbreak{} M$满足对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$\mathcal{C}_{ I } ^{ \lambda }\left ( { E } \right )=\allowbreak{}\bigvee_{ E\le\allowbreak{} E_{ A } ^{ \lambda } } I\left ( { A } \right )$\nobreak\hspace{0pt},其中\hspace{0pt}$E_{ A } ^{ \lambda }\left ( { x,y } \right )=\allowbreak{}A\left ( { x ^ { -1 } y } \right )$\nobreak\hspace{0pt},则\hspace{0pt}$\left ( { G,\mathcal{C}_{ I } ^{ \lambda } } \right )$构成一个左格值模糊化粗群.

\textbf{证明：} （ME1）由于
\begin{eqnarray*} E_{ \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } } ^{ \lambda }\left ( { x,y } \right ) \\  &=& \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } \left ( { x ^ { -1 } y } \right ), \end{eqnarray*}
当\hspace{0pt}$x=y$时,\hspace{0pt}$x ^ { -1 } y=e$\nobreak\hspace{0pt},则\hspace{0pt}$\chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } =\allowbreak{}\top$\nobreak\hspace{0pt},当\hspace{0pt}$x\ne y$时,\hspace{0pt}$x ^ { -1 } y\ne e$\nobreak\hspace{0pt},则\hspace{0pt}$\chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } =\allowbreak{}\bot$\nobreak\hspace{0pt},故\hspace{0pt}$E_{ \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } } ^{ \lambda }=\allowbreak{}\Delta _{ G }$\nobreak\hspace{0pt},则
\begin{eqnarray*} \mathcal{C}_{ I } ^{ \lambda }\left ( { \Delta _{ G } } \right ) &=& \bigvee_{ \Delta _{ G } \le E_{ A } ^{ \lambda } } I\left ( { A } \right ) \\  &=& \bigvee_{ E_{ \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } } ^{ \lambda }\le E_{ A } ^{ \lambda } } I\left ( { A } \right ) \\  &\ge& I\left ( { \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } } \right )=\top; \end{eqnarray*}


（ME2）对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$E\le F$\nobreak\hspace{0pt},由于\hspace{0pt}$\mathcal{C}_{ I } ^{ \lambda }\left ( { F } \right )=\allowbreak{}\bigvee_{ F\le\allowbreak{} E_{ A } ^{ \lambda } } I\left ( { A } \right )$\nobreak\hspace{0pt},且\hspace{0pt}$F\le E_{ A } ^{ \lambda }$\nobreak\hspace{0pt},则\hspace{0pt}$E\le\allowbreak{} F\le\allowbreak{} E_{ A } ^{ \lambda }$\nobreak\hspace{0pt},故\hspace{0pt}$\bigvee_{ E\le\allowbreak{} E_{ A } ^{ \lambda } } I\left ( { A } \right )\ge\allowbreak{} \bigvee_{ F\le\allowbreak{} E_{ A } ^{ \lambda } } I\left ( { A } \right )$\nobreak\hspace{0pt},即证\hspace{0pt}$\mathcal{C}_{ I } ^{ \lambda }\left ( { E } \right )\ge\allowbreak{} \mathcal{C}_{ I } ^{ \lambda }\left ( { F } \right )$\nobreak\hspace{0pt};

（ME3）对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},令\hspace{0pt}$E\le E_{ A } ^{ \lambda }$且\hspace{0pt}$F\le E_{ B } ^{ \lambda }$\nobreak\hspace{0pt},由于
\begin{eqnarray*} \left ( { E_{ A } ^{ \lambda }\vee E_{ B } ^{ \lambda } } \right )\left ( { x,y } \right ) &=& E_{ A } ^{ \lambda }\left ( { x,y } \right ) \\ \vee E_{ B } ^{ \lambda }\left ( { x,y } \right ) &=& A\left ( { x ^ { -1 } y } \right )\vee B\left ( { x ^ { -1 } y } \right ) \\  &=& \left ( { A\vee B } \right )\left ( { x ^ { -1 } y } \right )=E_{ A\vee B } ^{ \lambda }\left ( { x,y } \right ), \end{eqnarray*}
则\hspace{0pt}$E\vee\allowbreak{} F\le\allowbreak{} E_{ A } ^{ \lambda }\vee\allowbreak{} E_{ B } ^{ \lambda }=\allowbreak{}E_{ A\vee\allowbreak{} B } ^{ \lambda }$\nobreak\hspace{0pt},故
\begin{eqnarray*} \mathcal{C}_{ I } ^{ \lambda }\left ( { E\vee F } \right ) &=& \bigvee_{ E\vee F\le E_{ A\vee B } ^{ \lambda } } I\left ( { A\vee B } \right ) \\  &\ge& \bigvee_{ E\vee F\le E_{ A\vee B } ^{ \lambda } } \left ( { I\left ( { A } \right )\wedge I\left ( { B } \right ) } \right ) \\  &\ge& \bigvee_{ E\le E_{ A } ^{ \lambda },F\le E_{ B } ^{ \lambda } } \left ( { I\left ( { A } \right )\wedge I\left ( { B } \right ) } \right ) \\  &=& \bigvee_{ E\le E_{ A } ^{ \lambda } } I\left ( { A } \right )\wedge \bigvee_{ F\le E_{ B } ^{ \lambda } } I\left ( { B } \right ) \\  &=& \mathcal{C}_{ I } ^{ \lambda }\left ( { E } \right )\wedge \mathcal{C}_{ I } ^{ \lambda }\left ( { F } \right ); \end{eqnarray*}
（ME4）对\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},令\hspace{0pt}$E\le E_{ A } ^{ \lambda }$且\hspace{0pt}$F\le E_{ B } ^{ \lambda }$\nobreak\hspace{0pt},由于
\begin{eqnarray*} \left ( { E_{ A } ^{ \lambda }\circ E_{ B } ^{ \lambda } } \right )\left ( { x,z } \right ) \\  &=& \bigvee_{ y\in G } \left ( { E_{ B } ^{ \lambda }\left ( { x,y } \right )\wedge E_{ A } ^{ \lambda }\left ( { y,z } \right ) } \right ) \\  &=& \bigvee_{ y\in G } \left ( { B\left ( { x ^ { -1 } y } \right )\wedge A\left ( { y ^ { -1 } z } \right ) } \right ) \\  &=& \bigvee_{ y\in G } \left ( { B\left ( { x ^ { -1 } y } \right )\wedge A\left ( { \left ( { x ^ { -1 } y } \right ) ^ { -1 } \left ( { x ^ { -1 } z } \right ) } \right ) } \right ) \\  &=& \bigvee_{ w\in G } \left ( { B\left ( { w } \right )\wedge A\left ( { w ^ { -1 } \left ( { x ^ { -1 } z } \right ) } \right ) } \right ) \\  &=& \left ( { AB } \right )\left ( { x ^ { -1 } z } \right )=E_{ AB } ^{ \lambda }\left ( { x,z } \right ), \end{eqnarray*}
则\hspace{0pt}$E\circ F\le\allowbreak{} E_{ A } ^{ \lambda }\circ E_{ B } ^{ \lambda }=\allowbreak{}E_{ AB } ^{ \lambda }$\nobreak\hspace{0pt},故\hspace{0pt}$I(A)\wedge\allowbreak{} I(B)\leq\allowbreak{} I(AB)\leq\allowbreak{}\bigvee_{E\circ F\leq\allowbreak{} E_{AB}^{\lambda}}I(AB)=\allowbreak{}\mathcal{C}_{I}^{\lambda}(E\circ F)$\nobreak\hspace{0pt},则
\begin{eqnarray*} \mathcal{C}_{ I } ^{ \lambda }\left ( { E } \right )\wedge \mathcal{C}_{ I } ^{ \lambda }\left ( { F } \right ) \\  &=& \bigvee_{ E\le E_{ A } ^{ \lambda },F\le E_{ B } ^{ \lambda } } \left ( { I\left ( { A } \right )\wedge I\left ( { B } \right ) } \right ) \\  &\le& \mathcal{C}_{ I } ^{ \lambda }\left ( { E\circ F } \right ); \end{eqnarray*}
（ME5）\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},由于
\begin{eqnarray*} \left ( { E_{ A } ^{ \lambda } } \right ) ^ { -1 } \left ( { x,y } \right ) &=& E_{ A } ^{ \lambda }\left ( { y,x } \right )=A\left ( { y ^ { -1 } x } \right ) \\  &=& A\left ( { x ^ { -1 } y } \right ) ^ { -1 } =A ^ { -1 } \left ( { x ^ { -1 } y } \right )=E_{ A ^ { -1 } } ^{ \lambda }\left ( { x,y } \right ), \end{eqnarray*}
则\hspace{0pt}$\left ( { E_{ A } ^{ \lambda } } \right ) ^ { -1 } =\allowbreak{}E_{ A ^ { -1 } } ^{ \lambda }$\nobreak\hspace{0pt},令\hspace{0pt}$E ^ { -1 } \le\allowbreak{} E_{ A } ^{ \lambda }$\nobreak\hspace{0pt},\hspace{0pt}$B ^ { -1 } =A$\nobreak\hspace{0pt},则\hspace{0pt}$E ^ { -1 } \le\allowbreak{} E_{ B ^ { -1 } } ^{ \lambda }=\allowbreak{}\left ( { E_{ B } ^{ \lambda } } \right ) ^ { -1 }$\nobreak\hspace{0pt},即\hspace{0pt}$E\le E_{ B } ^{ \lambda }$\nobreak\hspace{0pt},故
\begin{eqnarray*} \mathcal{C}_{ I } ^{ \lambda }\left ( { E ^ { -1 } } \right ) &=& \bigvee_{ E ^ { -1 } \le E_{ A } ^{ \lambda } } I\left ( { A } \right ) \\  &=& \bigvee_{ E\le E_{ B } ^{ \lambda } } I\left ( { B ^ { -1 } } \right )=\bigvee_{ E\le E_{ B } ^{ \lambda } } I\left ( { B } \right ) \\  &=& \mathcal{C}_{ I } ^{ \lambda }\left ( { E } \right ); \end{eqnarray*}
最后再证明\hspace{0pt}$\left ( { G,\mathcal{C}_{ I } ^{ \lambda } } \right )$是一个左格值模糊化粗群,对\hspace{0pt}$\forall A\in L ^ { G }$\nobreak\hspace{0pt},令\hspace{0pt}$E\le E_{ A } ^{ \lambda }$\nobreak\hspace{0pt},则\hspace{0pt}$GE\le GE_{ A } ^{ \lambda }$\nobreak\hspace{0pt},由于
\begin{eqnarray*} GE_{ A } ^{ \lambda }\left ( { x,y } \right ) &=& \bigvee_{ g\in G } E_{ A } ^{ \lambda }\left ( { gx,gy } \right ) \\  &=& \bigvee_{ g\in G } A\left ( { x ^ { -1 } g ^ { -1 } gy } \right )=A\left ( { x ^ { -1 } y } \right )=E_{ A } ^{ \lambda }\left ( { x,y } \right ), \end{eqnarray*}
则
\begin{eqnarray*} \mathcal{C}_{ I } ^{ \lambda }\left ( { E } \right ) &=& \bigvee_{ E\le E_{ A } ^{ \lambda } } I\left ( { A } \right ) \\  &\le& \bigvee_{ GE\le E_{ A } ^{ \lambda } } I\left ( { A } \right )=\mathcal{C}_{ I } ^{ \lambda }\left ( { GE } \right ), \end{eqnarray*}
得证.

\textbf{注3.2.3.}  同理,我们可以定义一个右格值模糊化群粗结构\hspace{0pt}$\mathcal{C}_{ I } ^{ \rho }:L ^ { G\times G } \to\allowbreak{} M$\nobreak\hspace{0pt},满足对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$\mathcal{C}_{ I } ^{ \rho }\left ( { E } \right )=\allowbreak{}\bigvee_{ E\le\allowbreak{} E_{ A } ^{ \rho } } I\left ( { A } \right )$\nobreak\hspace{0pt},其中\hspace{0pt}$E_{ A } ^{ \rho }\left ( { x,y } \right )=\allowbreak{}A\left ( { yx ^ { -1 } } \right )$\nobreak\hspace{0pt},则\hspace{0pt}$\left ( { G,\mathcal{C}_{ I } ^{ \rho } } \right )$构成一个右格值模糊化粗群.

\textbf{命题3.2.4.}  \hspace{0pt}$\left ( { G,\mathcal{C} } \right )$是一个左格值模糊化粗群,定义\hspace{0pt}$I_{ \mathcal{C} } :L ^ { G } \to\allowbreak{} M$\nobreak\hspace{0pt},满足对\hspace{0pt}$\forall A\in L ^ { G }$\nobreak\hspace{0pt},\hspace{0pt}$I_{ \mathcal{C} } \left ( { A } \right )=\allowbreak{}\bigvee_{ A\le\allowbreak{} E\left[ e \right] } \mathcal{C}\left ( { E } \right )$\nobreak\hspace{0pt},其中\hspace{0pt}$E\left[ e \right]\left ( { x } \right )=\allowbreak{}E\left ( { e,x } \right )$\nobreak\hspace{0pt},则\hspace{0pt}$I_{ \mathcal{C} }$是一个格值模糊化群理想.

\textbf{证明：} （IM1）由于\hspace{0pt}$\Delta _{ G } \left[ e \right]=\allowbreak{}e$\nobreak\hspace{0pt},则\hspace{0pt}$I_{ \mathcal{C} } \left ( { e } \right )\ge\allowbreak{} \mathcal{C}\left ( { \Delta _{ G } } \right )=\allowbreak{}\top$\nobreak\hspace{0pt};

（IM2）对\hspace{0pt}$\forall A,B\in L ^ { G }$\nobreak\hspace{0pt},\hspace{0pt}$A\le B$\nobreak\hspace{0pt},则当\hspace{0pt}$B\le E\left[ e \right]$时,\hspace{0pt}$A\le B\le E\left[ e \right]$\nobreak\hspace{0pt},故
\begin{eqnarray*} I_{ \mathcal{C} } \left ( { A } \right ) &=& \bigvee_{ A\le E\left[ e \right] } \mathcal{C}\left ( { E } \right ) \\  &\ge& \bigvee_{ B\le E\left[ e \right] } \mathcal{C}\left ( { E } \right )=I_{ \mathcal{C} } \left ( { B } \right ); \end{eqnarray*}


（IM3）对\hspace{0pt}$\forall A,B\in L ^ { G }$\nobreak\hspace{0pt},\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$满足\hspace{0pt}$A\le E\left[ e \right]$及\hspace{0pt}$B\le F\left[ e \right]$\nobreak\hspace{0pt},则\hspace{0pt}$A\vee\allowbreak{} B\le\allowbreak{} E\left[ e \right]\vee\allowbreak{} F\left[ e \right]=\allowbreak{}\left ( { E\vee\allowbreak{} F } \right )\left[ e \right]$\nobreak\hspace{0pt},
\begin{eqnarray*} I_{ \mathcal{C} } \left ( { A } \right )\wedge I_{ \mathcal{C} } \left ( { B } \right ) &=& \bigvee_{ A\le E\left[ e \right] } \mathcal{C}\left ( { E } \right ) \\ \wedge \bigvee_{ B\le F\left[ e \right] } \mathcal{C}\left ( { F } \right ) &=& \bigvee_{ A\le E\left[ e \right],B\le F\left[ e \right] } \left ( { \mathcal{C}\left ( { E } \right )\wedge \mathcal{C}\left ( { F } \right ) } \right ) \\  &\le& \bigvee_{ A\vee B\le \left ( { E\vee F } \right )\left[ e \right] } \mathcal{C}\left ( { E\vee F } \right )=I_{ \mathcal{C} } \left ( { A\vee B } \right ); \end{eqnarray*}
（IM4）对\hspace{0pt}$\forall A,B\in L ^ { G }$\nobreak\hspace{0pt},\hspace{0pt}$\forall E,F\in\allowbreak{} L ^ { G\times G }$满足\hspace{0pt}$A\le E\left[ e \right]$及\hspace{0pt}$B\le F\left[ e \right]$\nobreak\hspace{0pt},令\hspace{0pt}$\forall \alpha$满足
\begin{eqnarray*} \alpha \prec I_{ \mathcal{C} } \left ( { A } \right )\wedge I_{ \mathcal{C} } \left ( { B } \right ) \\  &=& \bigvee_{ A\le E\left[ e \right] } \mathcal{C}\left ( { E } \right )\wedge \bigvee_{ B\le F\left[ e \right] } \mathcal{C}\left ( { F } \right ), \end{eqnarray*}
则\hspace{0pt}$\alpha \prec \bigvee_{ A\le\allowbreak{} E\left[ e \right] } \mathcal{C}\left ( { E } \right )$且\hspace{0pt}$\alpha \prec \bigvee_{ B\le\allowbreak{} F\left[ e \right] } \mathcal{C}\left ( { F } \right )$\nobreak\hspace{0pt},即\hspace{0pt}$A\le E\left[ e \right]$时\hspace{0pt}$\alpha \le\allowbreak{} \mathcal{C}\left ( { E } \right )$\nobreak\hspace{0pt},\hspace{0pt}$B\le F\left[ e \right]$时\hspace{0pt}$\alpha \le\allowbreak{} \mathcal{C}\left ( { F } \right )$\nobreak\hspace{0pt},则对\hspace{0pt}$\forall x,y\in G$\nobreak\hspace{0pt},\hspace{0pt}$A\left ( { x } \right )\le\allowbreak{} E\left[ e \right]\left ( { x } \right )=\allowbreak{}E\left ( { e,x } \right )$\nobreak\hspace{0pt},\hspace{0pt}$B\left ( { y } \right )\le\allowbreak{} F\left[ e \right]\left ( { y } \right )=\allowbreak{}F\left ( { e,y } \right )$\nobreak\hspace{0pt},又由于\hspace{0pt}$\left ( { G,\mathcal{C} } \right )$是一个左格值模糊化粗群,则
\begin{eqnarray*} \left ( { GF } \right )\left ( { x,xy } \right ) &=& \bigvee_{ g\in G } F\left ( { g ^ { -1 } x,g ^ { -1 } xy } \right )\ge F\left ( { e,y } \right ) \\  &\ge& B\left ( { y } \right ), \end{eqnarray*}
故
\begin{eqnarray*} \left ( { GF\circ E } \right )\left ( { e,xy } \right ) &=& \bigvee_{ z\in G } \left ( { E\left ( { e,z } \right )\wedge GF\left ( { z,xy } \right ) } \right ) \\  &\ge& E\left ( { e,x } \right )\wedge GF\left ( { x,xy } \right )\ge A\left ( { x } \right )\wedge B\left ( { y } \right ), \end{eqnarray*}
\begin{eqnarray*} \left ( { AB } \right )\left ( { xy } \right ) &=& \bigvee_{ x,y\in G } A\left ( { x } \right )\wedge B\left ( { y } \right ) \\  &\le& \left ( { GF\circ E } \right )\left ( { e,xy } \right )=\left ( { GF\circ E } \right )\left[ e \right]\left ( { xy } \right ), \end{eqnarray*}
由于\hspace{0pt}$\mathcal{C}\left ( { F } \right )\le\allowbreak{} \mathcal{C}\left ( { GF } \right )$\nobreak\hspace{0pt},则
\begin{eqnarray*} \alpha &\le& \mathcal{C}\left ( { E } \right )\wedge \mathcal{C}\left ( { F } \right )\le \mathcal{C}\left ( { E } \right )\wedge \mathcal{C}\left ( { GF } \right ) \\  &\le& \mathcal{C}\left ( { GF\circ E } \right )\le \bigvee_{ AB\le \left ( { GF\circ E } \right )\left[ e \right] } \mathcal{C}\left ( { GF\circ E } \right ) \\  &=& I_{ \mathcal{C} } \left ( { AB } \right ), \end{eqnarray*}


故\hspace{0pt}$I_{ \mathcal{C} } \left ( { A } \right )\wedge\allowbreak{} I_{ \mathcal{C} } \left ( { B } \right )\le\allowbreak{} I_{ \mathcal{C} } \left ( { AB } \right )$\nobreak\hspace{0pt};

（IM5）令\hspace{0pt}$A\le E\left[ e \right]$\nobreak\hspace{0pt},则对\hspace{0pt}$\forall x\in G$\nobreak\hspace{0pt},\hspace{0pt}$A\left ( { x } \right )\le\allowbreak{} E\left[ e \right]\left ( { x } \right )$\nobreak\hspace{0pt},故
\begin{eqnarray*} A ^ { -1 } \left ( { x } \right ) &=& A\left ( { x ^ { -1 } } \right )\le E\left[ e \right]\left ( { x ^ { -1 } } \right )\le GE\left ( { x,e } \right ) \\  &=& G\left ( { E\left ( { e,x } \right ) } \right ) ^ { -1 } =GE ^ { -1 } \left[ e \right]\left ( { x } \right ), \end{eqnarray*}
\begin{eqnarray*} I_{ \mathcal{C} } \left ( { A } \right ) &=& \bigvee_{ A\le E\left[ e \right] } \mathcal{C}\left ( { E } \right ) \\  &\le& \bigvee_{ A ^ { -1 } \le GE ^ { -1 } \left[ e \right] } \mathcal{C}\left ( { E } \right ) \\  &=& \bigvee_{ A ^ { -1 } \le GE ^ { -1 } \left[ e \right] } \mathcal{C}\left ( { E ^ { -1 } } \right ) \\  &\le& \bigvee_{ A ^ { -1 } \le GE ^ { -1 } \left[ e \right] } \mathcal{C}\left ( { GE ^ { -1 } } \right )=I_{ \mathcal{C} } \left ( { A ^ { -1 } } \right ). \end{eqnarray*}
\textbf{命题3.2.5.}  \hspace{0pt}$G$是一个群,\hspace{0pt}$\mathcal{C}$是\hspace{0pt}$G$上一个格值模糊化粗结构,若\hspace{0pt}$\left ( { G,\mathcal{C} } \right )$是一个左格值模糊化粗群,则\hspace{0pt}$\mathcal{C}=\allowbreak{}\mathcal{C}_{ I_{ \mathcal{C} } } ^{ \lambda }$\nobreak\hspace{0pt}.

\textbf{证明：} 由于
\begin{eqnarray*} \mathcal{C}_{ I_{ \mathcal{C} } } ^{ \lambda }\left ( { E } \right ) &=& \bigvee_{ E\le E_{ A } ^{ \lambda } } I_{ \mathcal{C} } \left ( { A } \right ) \\  &=& \bigvee_{ E\le E_{ A } ^{ \lambda } } \bigvee_{ A\le F\left[ e \right] } \mathcal{C}\left ( { F } \right ), \end{eqnarray*}
故只需证\hspace{0pt}$\mathcal{C}\left ( { E } \right )=\allowbreak{}\bigvee_{ E\le\allowbreak{} E_{ A } ^{ \lambda } } \bigvee_{ A\le\allowbreak{} F\left[ e \right] } \mathcal{C}\left ( { F } \right )$即可;

必要性 由于
\begin{eqnarray*} E_{ GE\left[ e \right] } ^{ \lambda }\left ( { x,y } \right ) &=& GE\left[ e \right]\left ( { x ^ { -1 } y } \right )=GE\left ( { e,x ^ { -1 } y } \right ) \\  &=& \bigvee_{ g\in G } E\left ( { g,gx ^ { -1 } y } \right )\ge E\left ( { x,y } \right ), \end{eqnarray*}
则
$$\mathcal{C}\left ( { E } \right )\le \mathcal{C}\left ( { GE } \right )\le \bigvee_{ E\le E_{ A } ^{ \lambda } } \bigvee_{ A\le F\left[ e \right] } \mathcal{C}\left ( { F } \right );$$
充分性 令\hspace{0pt}$E\le E_{ A } ^{ \lambda }$\nobreak\hspace{0pt},\hspace{0pt}$A\le F\left[ e \right]$\nobreak\hspace{0pt},则\hspace{0pt}$GE\le GE_{ A } ^{ \lambda }$\nobreak\hspace{0pt},所以对\hspace{0pt}$\forall x,y\in G$
\begin{eqnarray*} GE_{ A } ^{ \lambda }\left ( { x,y } \right ) &=& \bigvee_{ g\in G } E_{ A } ^{ \lambda }\left ( { gx,gy } \right ) \\  &=& \bigvee_{ g\in G } A\left ( { x ^ { -1 } g ^ { -1 } gy } \right )=A\left ( { x ^ { -1 } y } \right )=E_{ A } ^{ \lambda }\left ( { x,y } \right ), \end{eqnarray*}
\begin{eqnarray*} E_{ F\left[ e \right] } ^{ \lambda }\left ( { x,y } \right ) &=& F\left[ e \right]\left ( { x ^ { -1 } y } \right )=F\left ( { e,x ^ { -1 } y } \right ) \\  &\le& \bigvee_{ g\in G } F\left ( { gx,gy } \right )=GF\left ( { x,y } \right ), \end{eqnarray*}
即\hspace{0pt}$GE\le\allowbreak{} GE_{ A } ^{ \lambda }\le\allowbreak{} E_{ A } ^{ \lambda }\le\allowbreak{} E_{ F\left[ e \right] } ^{ \lambda }\le\allowbreak{} GF$\nobreak\hspace{0pt},故
\begin{eqnarray*} \bigvee_{ E\le E_{ A } ^{ \lambda } } \bigvee_{ A\le F\left[ e \right] } \mathcal{C}\left ( { F } \right ) &\le& \bigvee_{ GE\le GF } \mathcal{C}\left ( { F } \right ) \\  &\le& \bigvee_{ GE\le GF } \mathcal{C}\left ( { GF } \right )\le \mathcal{C}\left ( { GF } \right )\le \mathcal{C}\left ( { GE } \right ) \\  &=& \mathcal{C}\left ( { E } \right ). \end{eqnarray*}


\textbf{命题3.2.6.}  \hspace{0pt}$G$是一个群,\hspace{0pt}$I:L ^ { G } \to M$是\hspace{0pt}$G$上的一个格值模糊化群理想,则\hspace{0pt}$I=\allowbreak{}I_{ \mathcal{C}_{ I } ^{ \lambda } }$\nobreak\hspace{0pt}.

\textbf{证明：} 由于\hspace{0pt}$I_{ \mathcal{C}_{ I } ^{ \lambda } } \left ( { A } \right )=\allowbreak{}\bigvee_{ A\le\allowbreak{} E\left[ e \right] } \bigvee_{ E\le\allowbreak{} E_{ K } ^{ \lambda } } I\left ( { K } \right )$\nobreak\hspace{0pt},故只需证\newline \hspace{0pt}$I\left ( { A } \right )=\allowbreak{}\bigvee_{ A\le\allowbreak{} E\left[ e \right] } \bigvee_{ E\le\allowbreak{} E_{ K } ^{ \lambda } } I\left ( { K } \right )$即可;

必要性 由于\hspace{0pt}$E_{ A } ^{ \lambda }\left[ e \right]\left ( { x } \right )=\allowbreak{}E_{ A } ^{ \lambda }\left ( { e,x } \right )=\allowbreak{}A\left ( { e ^ { -1 } x } \right )=\allowbreak{}A\left ( { x } \right )$\nobreak\hspace{0pt},则\hspace{0pt}$E_{ A } ^{ \lambda }\left[ e \right]=\allowbreak{}A$\nobreak\hspace{0pt},故\hspace{0pt}$I\left ( { A } \right )\le\allowbreak{} \bigvee_{ A\le\allowbreak{} E\left[ e \right] } \bigvee_{ E\le\allowbreak{} E_{ K } ^{ \lambda } } I\left ( { K } \right )$\nobreak\hspace{0pt};

充分性 令\hspace{0pt}$A\le E\left[ e \right]$\nobreak\hspace{0pt},\hspace{0pt}$E\le E_{ K } ^{ \lambda }$\nobreak\hspace{0pt},则
\begin{eqnarray*} A\left ( { x } \right ) &\le& E\left[ e \right]\left ( { x } \right )=E\left ( { e,x } \right )\le E_{ K } ^{ \lambda }\left ( { e,x } \right ) \\  &=& E_{ K } ^{ \lambda }\left[ e \right]\left ( { x } \right )=K\left ( { x } \right ), \end{eqnarray*}
\begin{eqnarray*} \bigvee_{ A\le E\left[ e \right] } \bigvee_{ E\le E_{ K } ^{ \lambda } } I\left ( { K } \right ) &\le& \bigvee_{ A\le K } I\left ( { K } \right ) \\  &=& I\left ( { A } \right ). \end{eqnarray*}


\textbf{命题3.2.7.}  \hspace{0pt}$d:G\times G\times \left[ 0,\infty \right]\to\allowbreak{} \left[ 0,1 \right]$是一个左不变KM-模糊伪度量,定义\hspace{0pt}$I_{ d } :L ^ { G } \to\allowbreak{} \left[ 0,1 \right]$满足\hspace{0pt}$I_{ d } \left ( { A } \right )=\allowbreak{}\bigvee_{ t>0 } \bigwedge_{ x\in\allowbreak{} G } \left ( { A\left ( { x } \right )\to\allowbreak{} d\left ( { e,x,t } \right ) } \right )$\nobreak\hspace{0pt},则\hspace{0pt}$I_{ d }$是一个\hspace{0pt}$\left[ 0,1 \right]$-模糊群理想.

\textbf{证明：} （IM1）由于
\begin{eqnarray*} I_{ d } \left ( { \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ x\in G } \left ( { \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } \left ( { x } \right )\to d\left ( { e,x,t } \right ) } \right ), \end{eqnarray*}
则\hspace{0pt}$I_{ d } \left ( { \chi _{ \left \{ \begin{array}{l} e \end{array} \right \} } } \right )=\allowbreak{}\top$显然成立;

（IM2）对\hspace{0pt}$\forall A,B\in L ^ { G }$\nobreak\hspace{0pt},令\hspace{0pt}$A\le B$\nobreak\hspace{0pt},对\hspace{0pt}$\forall x\in G$\nobreak\hspace{0pt},有\hspace{0pt}$A\left ( { x } \right )\le\allowbreak{} B\left ( { x } \right )$\nobreak\hspace{0pt},则\newline \hspace{0pt}$A\left ( { x } \right )\to\allowbreak{} d\left ( { e,x,t } \right )\ge\allowbreak{} B\left ( { x } \right )\to\allowbreak{} d\left ( { e,x,t } \right )$\nobreak\hspace{0pt},故
\begin{eqnarray*} \bigwedge_{ x\in G } \left ( { A\left ( { x } \right )\to d\left ( { e,x,t } \right ) } \right ) \\  &\ge& \bigwedge_{ x\in G } \left ( { B\left ( { x } \right )\to d\left ( { e,x,t } \right ) } \right ), \end{eqnarray*}
即\hspace{0pt}$I_{ d } \left ( { A } \right )\ge\allowbreak{} I_{ d } \left ( { B } \right )$\nobreak\hspace{0pt};

（IM3）对\hspace{0pt}$\forall A,B\in L ^ { G }$\nobreak\hspace{0pt},则

（IM4）对\hspace{0pt}$\forall A,B\in L ^ { G }$\nobreak\hspace{0pt},由于\hspace{0pt}$d\left ( { e,yz,t } \right )\ge\allowbreak{} d\left ( { e,y,\frac { t } { 2 } } \right )\wedge\allowbreak{} d\left ( { e,z,\frac { t } { 2 } } \right )$\nobreak\hspace{0pt},则

{\setlength{\arraycolsep}{4pt}\begin{eqnarray*} \left ( { AB } \right )\left ( { x } \right )\to d\left ( { e,x,t } \right ) &=& \left ( { \bigvee_{ \substack{ yz=x \\ y,z\in G } } A\left ( { y } \right )\wedge B\left ( { z } \right ) } \right )\to d\left ( { e,x,t } \right ) \\  &\ge& \bigwedge_{ \substack{ yz=x \\ y,z\in G } } \left ( { \left ( { A\left ( { y } \right )\to d\left ( { e,y,\frac { t } { 2 } } \right ) } \right )\wedge \left ( { B\left ( { z } \right )\to d\left ( { e,z,\frac { t } { 2 } } \right ) } \right ) } \right ), \end{eqnarray*}}
\begin{eqnarray*} I_{ d } \left ( { AB } \right ) &=& \bigvee_{ t>0 } \bigwedge_{ x\in G } \left ( { \left ( { AB } \right )\left ( { x } \right )\to d\left ( { e,x,t } \right ) } \right ) \\  &\ge& \bigvee_{ t>0 } \bigwedge_{ \substack{ yz=x \\ y,z\in G } } \left ( { \left ( { A\left ( { y } \right )\to d\left ( { e,y,\frac { t } { 2 } } \right ) } \right )\wedge \left ( { B\left ( { z } \right )\to d\left ( { e,z,\frac { t } { 2 } } \right ) } \right ) } \right ) \\  &\ge& I_{ d } \left ( { A } \right )\wedge I_{ d } \left ( { B } \right ); \end{eqnarray*}
（IM5）由于\hspace{0pt}$A ^ { -1 } \left ( { x } \right )=\allowbreak{}A\left ( { x ^ { -1 } } \right )$\nobreak\hspace{0pt}，则

\begin{eqnarray*} I_{ d } \left ( { A ^ { -1 } } \right ) &=& \bigvee_{ t>0 } \bigwedge_{ x\in G } \left ( { A ^ { -1 } \left ( { x } \right )\to d\left ( { e,x,t } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ x\in G } \left ( { A\left ( { x ^ { -1 } } \right )\to d\left ( { e,x,t } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ x ^ { -1 } \in G } \left ( { A\left ( { x ^ { -1 } } \right )\to d\left ( { e,x ^ { -1 } ,t } \right ) } \right ) \\  &=& I_{ d } \left ( { A } \right ). \end{eqnarray*}


\textbf{命题3.2.8.}  \hspace{0pt}$d:G\times G\times \left[ 0,\infty \right]\to\allowbreak{} \left[ 0,1 \right]$是一个左不变KM-模糊伪度量,则\hspace{0pt}$\mathcal{C}_{ d } =\allowbreak{}\mathcal{C}_{ I_{ d } } ^{ \lambda }$\nobreak\hspace{0pt},其中对\hspace{0pt}$\forall E\in\allowbreak{} L ^ { G\times G }$\nobreak\hspace{0pt},\hspace{0pt}$\mathcal{C}_{ d } \left ( { E } \right )=\allowbreak{}\bigvee_{ t>0 } \bigwedge_{ \left ( { x,y } \right )\in\allowbreak{} G\times G } \left ( { E\left ( { x,y } \right )\to\allowbreak{} d\left ( { x,y,t } \right ) } \right )$\nobreak\hspace{0pt}.

\textbf{证明：} 由于
\begin{eqnarray*} \mathcal{C}_{ I_{ d } } \left ( { E } \right ) &=& \bigvee_{ E\le E_{ A } ^{ \lambda } } I_{ d } \left ( { A } \right ) \\  &=& \bigvee_{ E\le E_{ A } ^{ \lambda } } \bigvee_{ t>0 } \bigwedge_{ z\in G } \left ( { A\left ( { z } \right )\to d\left ( { e,z,t } \right ) } \right ), \end{eqnarray*}
即证对\hspace{0pt}$\forall t>0$\nobreak\hspace{0pt},有
\begin{eqnarray*} \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { E\left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ) \\  &=& \bigvee_{ E\le E_{ A } ^{ \lambda } } \bigwedge_{ z\in G } \left ( { A\left ( { z } \right )\to d\left ( { e,z,t } \right ) } \right ), \end{eqnarray*}
（充分性）对\hspace{0pt}$\forall A\in L ^ { G }$\nobreak\hspace{0pt},令\hspace{0pt}$A\left ( { z } \right )=\allowbreak{}GE\left ( { e,z } \right )$\nobreak\hspace{0pt}，其中\hspace{0pt}$GE\left ( { x,y } \right )=\allowbreak{}\bigvee_{ g\in\allowbreak{} G } E\left ( { gx,gy } \right )$\nobreak\hspace{0pt},由于\hspace{0pt}$GE$是左不变的，则\hspace{0pt}$GE\left ( { x,y } \right )=\allowbreak{}GE\left ( { e,x ^ { -1 } y } \right )=\allowbreak{}A\left ( { x ^ { -1 } y } \right )=\allowbreak{}E_{ A } ^{ \lambda }\left ( { x,y } \right )$\nobreak\hspace{0pt},因此\hspace{0pt}$E\le GE=E_{ A } ^{ \lambda }$\nobreak\hspace{0pt},又由于\hspace{0pt}$\mathcal{C}_{ d } \left ( { E } \right )=\allowbreak{}\mathcal{C}_{ d } \left ( { GE } \right )$\nobreak\hspace{0pt},则
\begin{eqnarray*} I_{ d } \left ( { A } \right ) &=& \bigvee_{ t>0 } \bigwedge_{ z\in G } \left ( { A\left ( { z } \right )\to d\left ( { e,z,t } \right ) } \right ) \\  &=& \bigvee_{ t>0 } \bigwedge_{ z\in G } \left ( { GE\left ( { e,z } \right )\to d\left ( { e,z,t } \right ) } \right ), \end{eqnarray*}
令\hspace{0pt}$z=x ^ { -1 } y$\nobreak\hspace{0pt}，则\hspace{0pt}$d\left ( { e,z,t } \right )=\allowbreak{}d\left ( { x,y,t } \right )$且\hspace{0pt}$GE\left ( { e,z } \right )=\allowbreak{}GE\left ( { x,y } \right )$\nobreak\hspace{0pt},故
\begin{eqnarray*} \bigwedge_{ z\in G } \left ( { GE\left ( { e,z } \right )\to d\left ( { e,z,t } \right ) } \right ) \\  &=& \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { GE\left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ), \end{eqnarray*}
上式两边对\hspace{0pt}$t$取上确界,则\hspace{0pt}$I_{ d } \left ( { A } \right )=\allowbreak{}\mathcal{C}_{ d } \left ( { GE } \right )=\allowbreak{}\mathcal{C}_{ d } \left ( { E } \right )$\nobreak\hspace{0pt},故\hspace{0pt}$\mathcal{C}_{ I_{ d } } ^{ \lambda }\left ( { E } \right )=\allowbreak{}\bigvee_{ E\le\allowbreak{} E_{ A } ^{ \lambda } } I_{ d } \left ( { A } \right )\ge\allowbreak{} \mathcal{C}_{ d }$\nobreak\hspace{0pt};

（必要性）对\hspace{0pt}$\forall A\in L ^ { G }$\nobreak\hspace{0pt},若满足\hspace{0pt}$E\le E_{ A } ^{ \lambda }$\nobreak\hspace{0pt},则对\hspace{0pt}$\forall x,y\in G$\nobreak\hspace{0pt}，\hspace{0pt}$E\left ( { x,y } \right )\le\allowbreak{} E_{ A } ^{ \lambda }\left ( { x,y } \right )=\allowbreak{}A\left ( { x ^ { -1 } y } \right )$\nobreak\hspace{0pt},由于\hspace{0pt}$d\left ( { e,x ^ { -1 } y,t } \right )=\allowbreak{}d\left ( { x,y,t } \right )$\nobreak\hspace{0pt},因此对\hspace{0pt}$\forall t>0$\nobreak\hspace{0pt},
\begin{eqnarray*} \bigwedge_{ z\in G } \left ( { A\left ( { z } \right )\to d\left ( { e,z,t } \right ) } \right ) \\  &\le& A\left ( { x ^ { -1 } y } \right )\to d\left ( { e,x ^ { -1 } y,t } \right )\le E\left ( { x,y } \right )\to d\left ( { x,y,t } \right ), \end{eqnarray*}
\begin{eqnarray*} \bigwedge_{ z\in G } \left ( { A\left ( { z } \right )\to d\left ( { e,z,t } \right ) } \right ) \\  &\le& \bigwedge_{ \left ( { x,y } \right )\in G\times G } \left ( { E\left ( { x,y } \right )\to d\left ( { x,y,t } \right ) } \right ), \end{eqnarray*}
两边对\hspace{0pt}$t>0$取上确界，则\hspace{0pt}$I_{ d } \left ( { A } \right )\le\allowbreak{} \mathcal{C}_{ d } \left ( { E } \right )$\nobreak\hspace{0pt},故\hspace{0pt}$\mathcal{C}_{ I_{ d } } ^{ \lambda }\left ( { E } \right )=\allowbreak{}\bigvee_{ E\le\allowbreak{} E_{ A } ^{ \lambda } } I_{ d } \left ( { A } \right )\le\allowbreak{} \mathcal{C}_{ d }$\nobreak\hspace{0pt}.


\chapter{总\ \ 结}
\vspace{0.2cm}
本文在完全分配格\hspace{0pt}$L$和\hspace{0pt}$M$的框架下提出了格值模糊化粗群, 研究了它与KM-模糊伪度量之间的联系, 并通过格值模糊化群理想给出了左、右格值模糊化粗群的代数刻画. 这些结果将经典粗群与群理想之间的对应关系推广到双格值模糊化环境.
