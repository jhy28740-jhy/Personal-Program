# 淮南市公务员考试备考计划

数学专业硕士应届生专属备考指南

## 📋 项目简介

这是一份针对数学专业硕士应届生的淮南市公务员考试备考计划，包含：

- **目标选定**：6个精选岗位（国考+省考，主攻+备选）
- **备考指南**：专业优势分析、薄弱环节补充、备考策略
- **备考计划**：6个月详细学习计划、每日作息建议

## 🎯 目标岗位

### 第一梯队（主攻）
1. 中国人民银行淮南市分行 - 金融数据分析岗（国考）⭐⭐⭐⭐⭐
2. 淮南市统计局（市直） - 统计建模与数据分析（省考）⭐⭐⭐⭐⭐
3. 八公山区统计局 - 综合统计岗（省考，应届专属）⭐⭐⭐⭐

### 第二梯队（备选）
4. 淮南市税务局系统 - 一级行政执法员（国考，应届专属）⭐⭐⭐⭐
5. 淮南市公安局 - 大数据分析专项岗（省考）⭐⭐⭐⭐
6. 淮南市发改委 - 机关综合岗（省考）⭐⭐⭐⭐

## 💡 核心优势

- ✅ 数量关系和资料分析模块：天然优势，目标90%+正确率
- ✅ 逻辑判断：严密的数学逻辑思维
- ✅ 申论数据分析：快速提取和分析统计数据
- ⚠️ 需补充：言语理解、常识判断、政治素养

## 📅 时间规划

- **第1-2个月**：基础入门，建立知识框架
- **第3-4个月**：专项突破，强化薄弱模块
- **第5个月**：真题刷题，提高速度和准确率
- **第6个月上半**：国考冲刺（11月考试）
- **国考后-次年2月**：省考准备
- **次年3月**：省考冲刺（4月考试）
