## 三、3个Demo案例（拿来展示）

### Demo 1：电商竞品价格监控

**场景：** 淘宝卖家想每天自动抓取3个竞品的价格、销量、评价数，生成对比表。

**交付物：**
```
竞品监控系统/
├── monitor.py          # 爬虫脚本（自动抓取）
├── config.json         # 配置文件（竞品链接）
├── 每日价格报表.xlsx   # 自动生成的Excel
└── 使用说明.md         # 一键运行教程
```

**功能亮点：**
- 每天自动运行（Windows任务计划/cron）
- 价格变动超过10%自动微信提醒
- 历史数据自动存档，可查看趋势

**报价：** ¥1200（3个竞品），每增加1个竞品+¥200

---

### Demo 2：销售数据自动报表

**场景：** 小企业每月从ERP导出原始数据，需要整理成"销售月报"（各产品销量、客户排名、同比环比）。

**交付物：**
```
销售报表生成器/
├── generate_report.py   # 一键生成脚本
├── template.xlsx        # Excel模板（带图表）
├── 示例-原始数据.csv    # 输入格式示例
└── 示例-生成报表.xlsx   # 输出示例
```

**功能亮点：**
- 拖入原始CSV，自动生成美化版Excel（含图表）
- 自动计算同比环比、Top10客户、产品占比
- 一键发送到老板邮箱

**报价：** ¥800

---

### Demo 3：批量图片处理

**场景：** 电商需要把1000张商品图压缩到500KB以内、统一尺寸、加水印。

**交付物：**
```
图片批量处理工具/
├── batch_process.py     # 批量处理脚本
├── 处理前/              # 原图文件夹
├── 处理后/              # 输出文件夹
└── 使用说明.txt
```

**功能亮点：**
- 支持压缩、裁剪、加水印、格式转换
- 1000张图3分钟处理完
- 保留原图，输出到新文件夹

**报价：** ¥300（首次），后续同类需求¥100/次
