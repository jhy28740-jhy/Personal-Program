# 竞品价格监控系统 - 使用说明

## 📋 功能介绍

这是一个自动化的电商竞品价格监控工具，可以：
- ✅ 自动抓取竞品价格、销量、评分
- ✅ 生成美观的Excel对比报表
- ✅ 价格变动超过阈值自动预警
- ✅ 保存历史数据，追踪价格趋势

---

## 🚀 快速开始

### 第一步：安装依赖

```bash
pip install pandas openpyxl
```

### 第二步：运行监控

```bash
python monitor.py
```

就这么简单！脚本会自动：
1. 抓取竞品数据（Demo版使用模拟数据）
2. 生成 `竞品价格报表.xlsx`
3. 追加到 `价格历史.xlsx`

---

## ⚙️ 配置文件

首次运行会自动创建 `config.json`：

```json
{
  "products": [
    {
      "name": "竞品A - 无线蓝牙耳机",
      "url": "https://example.com/product-a",
      "price": 299.00,
      "sales": 2850,
      "rating": 4.8
    }
  ],
  "alert_price_change": 10
}
```

**修改配置：**
- `products`: 添加你要监控的竞品信息
- `alert_price_change`: 价格变动预警阈值（百分比）
