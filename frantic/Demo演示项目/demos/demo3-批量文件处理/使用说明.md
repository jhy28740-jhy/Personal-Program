# 批量图片处理工具 - 使用说明

## 📋 功能介绍

一键批量处理大量图片，支持：
- ✅ 图片压缩（减小文件体积，保持画质）
- ✅ 尺寸调整（统一尺寸，保持比例）
- ✅ 添加水印（品牌保护）
- ✅ 格式转换（JPG/PNG/WebP等）
- ✅ 显示压缩率统计

---

## 🚀 快速开始

### 第一步：安装依赖

```bash
pip install pillow
```

### 第二步：准备图片

把要处理的图片放到 `输入图片/` 文件夹

**没有图片？** 脚本会自动创建3张示例图片供测试

### 第三步：运行处理

```bash
python batch_process.py
```

处理后的图片会保存到 `输出图片/` 文件夹

---

## ⚙️ 配置选项

首次运行会生成 `config.json`：

```json
{
  "input_folder": "输入图片",
  "output_folder": "输出图片",
  "operations": {
    "compress": true,          // 是否压缩
    "quality": 85,             // 压缩质量 (1-100)
    "resize": false,           // 是否调整尺寸
    "target_width": 1920,      // 目标宽度
    "target_height": 1080,     // 目标高度
    "watermark": false,        // 是否加水印
    "watermark_text": "© 2024 我的品牌",
    "convert_format": null     // 转换格式 (jpg/png/webp)
  }
}
```

### 常用配置示例

#### 场景1：电商图片压缩（保持质量）
```json
{
  "compress": true,
  "quality": 90,
  "resize": false,
  "watermark": false
}
```

#### 场景2：统一尺寸+加水印
```json
{
  "compress": true,
  "quality": 85,
  "resize": true,
  "target_width": 800,
  "target_height": 600,
  "watermark": true,
  "watermark_text": "© 我的店铺"
}
```

#### 场景3：转换为WebP格式（更小体积）
```json
{
  "compress": true,
  "quality": 80,
  "convert_format": "webp"
}
```

## 💡 高级技巧

### 1. 分批处理大量图片

如果有几千张图片，建议分批处理：
```bash
# 每次处理100张
python batch_process.py
# 把处理完的从输入文件夹移走
# 放入下一批100张
```

### 2. 保留原图

输出文件夹和输入文件夹是分开的，原图不会被覆盖

### 3. 批量重命名

可以在脚本中添加重命名逻辑：
```python
output_filename = f"processed_{idx:04d}{output_ext}"
```

## ❓ 常见问题

**Q: 支持哪些图片格式？**  
A: JPG, PNG, BMP, GIF, WebP 都支持

**Q: 会损失画质吗？**  
A: quality=85 是最佳平衡点，肉眼几乎无差别，体积减少50-70%

**Q: 能处理RAW格式（相机原片）吗？**  
A: Demo版不支持，定制版可以

**Q: 一次能处理多少张？**  
A: 理论无限制，实测处理1000张约5分钟

**Q: 能加复杂水印（Logo图片）吗？**  
A: 可以，定制版支持图片水印、位置自定义

**Q: 处理后原图会被删除吗？**  
A: 不会，原图保留在输入文件夹，处理后的在输出文件夹
